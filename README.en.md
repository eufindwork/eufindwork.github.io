## 📌 Reading Guide

- **Information richness** (⭐ = very little → ⭐⭐⭐⭐⭐ = very rich): directly reflects how accessible public interview experiences / salary / process data are; not equivalent to "is this company good"
- **Non-EU visa**: whether intern visa sponsorship is offered to international students (Chinese / Indian etc. non-EU passports) or whether candidates already holding a student visa can apply
- **Interview difficulty**: composite of LeetCode question difficulty + depth of multi-round assessment + acceptance rate; 1 star = easy, 5 stars = extremely hard
- **Stipend range**: gross monthly salary (pre-tax), converted to local currency for the corresponding city; data may come from Levels.fyi / Glassdoor / TechPays, see each company file
- Any single-source stipend / process data is annotated in the original doc; **do not use for salary negotiation** before secondary verification
