## 2. 签证与国际学生政策

**核心结论: Blue Card sponsor 明确 + Graduate SWE 薪资充分符合阈值**

| 维度 | 政策 |
|------|------|
| 是否支持非EU学生 | **Yes** — Nextleveljobs 明确列入 Blue Card sponsor; 多个国际工程师入职案例 |
| 是否要求 work auth | **No** (公司全办 Blue Card) |
| 2026 Blue Card 阈值 | IT 短缺 €45,934/年 (新毕业 3 yr 内 + IT 学位 reduced €41,041.80); Graduate base €51,684 ≥ 阈值 |
| Werkstudent 是否办 visa | **No** — DE Werkstudent 仅限持德国学生签的在校生 |
| Praktikum (Pflicht/Freiwillig) 是否办 visa | Pflichtpraktikum (强制实习) 无需 work permit; Freiwilliges Praktikum 需要 — Trade Republic 通常走 Pflicht 路径 |
| 已知 sponsorship 案例 | Nextleveljobs 公开 sponsor list [来源 (实际打开过): https://nextleveljobs.eu/blog/visa-sponsorship/de]; LinkedIn 多个非欧国籍 SWE 入职 |
| 永居 / 公民 路径 | Blue Card 路径 21 个月 (B1 德语) / 27 个月 (无德语) 拿 PR, 全 EU 最快档之一 |

**对中国留学生的可行路径**:
1. **目标 Berlin 全职 SWE / Graduate Programme**: 直接申, Blue Card 公司全办, 流程 4-12 周
2. **已在 DE 念书**: Werkstudent 路径 (学期 20h/wk) 是低成本进入 + 转正路径
3. **不在 DE / EU**: 直接申 Graduate Programme, Blue Card 流程标准
4. **加分**: Java / Kotlin / Spring Boot 后端栈 + 金融/支付/合规 (KYC / AML) 背景
5. **避坑**: 申请前确认岗位是否真开 Blue Card sponsor (大部分 yes, 但偶有 EU-only 岗位)

## 3. 面试流程

> Glassdoor SWE 平均难度 2.8/5, 50% positive, 23 天 hire 周期 (Berlin 偏快档)

- **总轮数**: ~4-5 轮 (全职 SWE) / 3-4 轮 (Graduate Programme)
- **每轮形式**:
  1. **Initial Screening** (15-30 min): recruiter / HR call, role + visa + location fit
  2. **HM / Senior Engineer Chat** (45-60 min): past projects + Java/Kotlin / 后端栈深度
  3. **Take-home Assignment + Discussion** (typically 一次): 后端 coding task (e.g. 实现 REST API + 数据持久化), 完成后 1h 讨论 (架构选择, trade-off, 优化)
  4. **System Design** (60 min): 设计 fintech 场景 (e.g. 设计 trade execution engine / KYC pipeline / real-time price feed)
  5. **Product / Behavioral** (45-60 min): product mindset (fintech 用户场景 / 监管合规权衡), team fit
  6. **Final / Onsite Berlin** (offer 前): 部分岗位需 in-person 到 Berlin office (visa 候选人可远程)
- **题型分布**:
  - 后端: Java/Kotlin + Spring Boot 实现 (40%) / 系统设计 fintech 场景 (30%) / Product / fintech domain (20%) / BQ (10%)
  - 前端 (Level Up Coding 2025 实证 [来源](https://levelup.gitconnected.com/trade-republic-frontend-interview-experience-bc90ff24d544)): assignment-driven, React/TS, performance + state management 重点
- **难度评估**: Medium; LeetCode hard 比例低, take-home + system design 比重高 (fintech 行业惯例)
- **OA 是否存在**: 没有 HackerRank-style 限时 OA, 但 take-home assignment (通常 4-8h) 是标准环节

## 7. 踩坑与社区评价

### 流程层面
- **Take-home assignment 时间投入大**: 准备 8-12h, 不仅写代码还要写设计文档 + trade-off 说明
- **Product / fintech 知识是隐形门槛**: 不懂 broker 业务 / 监管 / 用户保护 会在 product 轮被刷
- **Berlin office bias**: 大部分岗位 hybrid (3 天 office), 远程极少; 申请前确认 location 政策

### 文化层面 (Glassdoor 综合)
- **正面**: "Great mission, smart team, real fintech impact"; 北欧 / 印度 / 中欧 多元化团队
- **负面**: "Process heavy" (监管行业), "stock options 缺乏 liquidity event"
- **整体评分**: ~3.5-3.8 / 5 (Berlin SWE reviews)

### 已知"坑"
1. **Stock 在 grad/junior 级别为 0**: 不要被 "Series D unicorn" 想象忽悠 base — Graduate base €51K, total €59K, 实际 stock $0/yr
2. **监管行业流程慢**: 决策链长, code review 严格 (金融监管 audit trail), 不适合"move fast break things" 性格
3. **Berlin 物价上涨**: 2026 Berlin 房租已显著上涨 (€20-€25/m² 市中心), Graduate base €51K 可支配中等
4. **Vienna / Paris 岗位机会少**: 想去这两个 site 难度大于 Berlin
5. **Graduate Programme rotation 不保证最终团队**: 12-18 个月轮岗后定岗, 想做特定方向 (e.g. AI agent) 需主动表达 + 内部 push

### 对国际学生友好度
- **政策上极友好**: Blue Card 公开 sponsor, Graduate 薪资符合阈值
- **实操上**: Berlin 国际化程度高 (英语工作环境), 流程透明
- **中国学生**: 公开案例多见; 后端 Java/Kotlin + fintech 背景是关键信号
- **新毕业 friendly**: Graduate Programme 是 EU fintech 少有的 cohort 通道
