## New Grad / Junior 岗位

> OpenAI 是少数还在做命名 Emerging Talent / Residency 的 frontier lab. 这是非EU学生进入 frontier 的稀缺入口.

- **常见岗位名**: Software Engineer, New Grad / Applied Engineering Emerging Talent; Research Engineer (Residency / Junior)
- **欧洲地点**: London 为主 (intern + new grad 都开过), Dublin commercial 类, Munich 工程也开但需 German, Paris 偏 GTM
- **是否有独立 Graduate Programme**:
  - **Emerging Talent Program** 包括 internships + co-ops + new grad full-time [来源 (实际打开过): https://openai.com/careers/emerging-talent/]

- **薪资范围**:
  - **Intern**: 数据有限. 业内估 SF SWE intern $50/hr+ (~$100K annualized); London/Dublin 折算估 £55-75/hr

  - **New Grad SWE (L2)**: SF L2 median $245K-$265K [https://www.levels.fyi/companies/openai/salaries/software-engineer/levels/l2]; London 折算 ~£200K-£250K TC (base £130K-£170K + PPU)
- **申请窗口**:
  - **Fall 2026 intern**: 2026 年初已开始 surveying (job posted in early 2026, applications rolling)
  - **Spring / Summer intern**: 通常前一年 Q3-Q4 开
  - **New grad full-time**: rolling, 通常秋季 cohort
- **面试流程差异 vs senior**:
  - Intern / new grad 更偏 coding (45-60 min × 2-3), 较少 deep system design
  - Senior 加 system design + project deep-dive + values
  - Take-home 48hr 项目对 intern 常见 [来源 (实际打开过): https://www.tryexponent.com/guides/openai-software-engineer-interview]

  - 国际生 friendliness: **London/Dublin 高 (sponsor 路径熟练), Munich 极低 (German B2+ 硬卡)**

## 2. 签证与国际学生政策

- **是否支持非EU学生**: **Yes** for UK / Ireland; **Conditional** for Munich (需德语), Paris (商业岗法语优先)
- **是否需要提前持有工作许可**: **No** — OpenAI 在 UK 持 Skilled Worker license, Ireland 走 CSEP
- **已知的 sponsorship 案例**:
  - Blind 多帖确认 OpenAI sponsor H1B + UK Skilled Worker [来源 (实际打开过): https://www.teamblind.com/post/does-openai-sponsor-h1b-visa-4o3ha6vf]
  - **Intern visa**: UK Tier 5 GAE / Standard Visitor; 申请前必须确认 visa status
  - Munich 工程 JD 写 German B2+ (软要求, 高频出现) — 不通德语应避开

## 3. 面试流程

- **总轮数**: 6-8 轮, 2 周-2 月 [来源 (实际打开过): https://igotanoffer.com/en/advice/openai-interview-process]
- **每轮形式**:
  1. **Recruiter screen** (30-45 min): 背景 + AGI safety motivation
  2. **2 × 60 min technical** (coding + system design, 同一天)
  3. **Take-home project** (48hr, "build something real", 评估 reliability + code quality + testing) [来源 (实际打开过): https://www.tryexponent.com/guides/openai-software-engineer-interview]
  4. **Virtual onsite 4-5 轮**: coding + system design + deep dive + 1-2 behavioral
  5. **Hiring committee + offer**
- **题型分布**: Coding 实战 40% (非 LeetCode, "time-based KV store / resumable iterator" 这类系统题), System design 25%, Deep dive on project 20%, Behavioral 15%
- **难度评估**: 难度 3.2/5, positive 33% (Glassdoor)
- **OA 是否存在**: 通常不发独立 OA, take-home 充当 (48hr)

## 6. 申请渠道与建议

- **官网投递**: https://openai.com/careers/search/ + https://jobs.ashbyhq.com/openai/ (Ashby ATS)
- **内推途径**: LinkedIn London 招聘官公开主动 source; 同样 Twitter / X 多 ML 大佬 host informal hiring threads
- **简历/背景要求**:
  - Intern: 顶校 CS + 至少 1 个高质量 open-source / ML 项目 + Python 强 + 对 LLM training/inference 有理解
  - New grad / Residency: 顶校 + 论文加分但非必须; "对 LLM 内部组件 (attention/KV cache/RLHF) 能讲清楚"
  - 强烈推荐先在 vLLM / transformers / TRL 提 1-2 个 merged PR

## 7. 踩坑与社区评价

- **Munich 卡德语**: Munich 工程 JD 高频出现 German B2+ — 不会德语别投 Munich, 申 London/Dublin
- **流程长且不可预测**: 2 周到 2 月, recruiter 回复速度参差; 不要单押 OpenAI, 同步投 Anthropic / DeepMind / Mistral
- **Take-home 强度高**: 48hr 项目耗时巨大, 提交后被 ghost 是常见抱怨 (Glassdoor 33% positive)
- **欧洲 intern 名额少**: 大头还是 SF; London Fall 2026 SWE Intern 是少数公开欧洲 req
- **Residency 非欧洲**: 仅 SF 提供, 想走 Residency 路径要准备美签
