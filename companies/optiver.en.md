## 3. Interview Process

| Round | Content | Duration | Notes |
|------|------|------|------|
| 0. OA 1 (mental math) | **80in8 (actually 50 questions / 8 minutes)** — integer / decimal / fraction arithmetic | 8 min | No skipping, no changes; wrong -2 correct +1; passing 55+, competitive 70+ |
| 1. OA 2 (SWE) | HackerRank 2 coding problems (1 OOP system design + 1 algorithm), C++/Java/Python | 120 min | 1point3acres 2026 batch reports system design is "news subscription system" |
| 1. OA 2 (QR) | HackerRank 1-2 probability + sequence | 75-90 min | Reports "problem description extremely long + difficulty insane"; QR 2026 OA includes sequence questions |
| 1.5. ZapN | 9 neural reaction mini-games (reaction speed / pattern recognition) | ~30 min | 2026 newly added second-round filter, speed-sensitive |
| 2. Phone / Coderpad | 1 senior engineer, live coding (circular buffer / LRU variant / queue) | 60 min | Heavy on communication + edge cases, not optimal LeetCode solution required |
| 3. Tech second round | System design (exchange / order book / FIX gateway), C++ memory model | 60 min | SWE only; QR goes stats / probability deep dive |
| 4. Super Day (Onsite Amsterdam) | 2 days — 2 tech rounds + culture fit + lunch + office tour | 2 days | Flights + hotel Optiver covers; usually 1 week offer / reject |

**Optiver-specific notes**:
- Mental math is **absolute elimination threshold** — even SWE roles must pass, not exempted because "I'm a coder not a trader"
- Official suggestion: zetamac / arithmetic.zetamac.com daily practice; 25-30 score per day target to 40-50 / 2 min
- 2026 reports: "OA difficulty insane" "Optiver 2026 QR Intern OA" multiple 1point3acres threads [Source (search result): https://www.1point3acres.com/bbs/thread-1145878-1-1.html]

## 7. Pitfalls and Community Reviews

- **80in8 / 50in8 is absolute elimination threshold**: WSO historic post "Optiver 80 in 8 numerical test seems impossible. Is it even possible to pass this test without luck?" — answer is practice; zetamac 60+ is admission ticket, fail without practice [Source (search result): https://www.wallstreetoasis.com/forum/trading/optiver-80-in-8-numerical-test-seems-impossible-is-it-even-possible-to-pass-this-test]
- **ZapN (2026 new) speed-sensitive**: 9 mini-games + 75 minute extreme, 1point3acres users report "slow reaction directly fail" [Source (search result): https://www.1point3acres.com/bbs/thread-1144268-1-1.html]
- **Bonus unstable**: company PnL down years (2018 / 2022 some desks) report bonus shrink 30-50%; Y1 base only 30-40%, negotiation cannot focus only on base
- **Culture leans "engineer + flat"**: no dress code, no cubicle, but high work intensity — weekend OT not enforced but common; international student feedback "fair hiring process, no discrimination against non-European undergrad"
- **Glassdoor 4.4/5 + high satisfaction**: but 30% ruling policy change is biggest concern for 2024+ joiners
- **International student friendliness**: ⭐⭐⭐⭐⭐ — Amsterdam is one of EU's most international offices, IND HSM 2 weeks, no Dutch required
