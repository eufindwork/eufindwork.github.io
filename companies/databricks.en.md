## 2. Visa and International Student Policy

- Databricks NL is IND **recognised sponsor**, full-time SWE conversion fully supports Kennismigrant + 30% ruling
- **Interns**:
  - EU/EEA → apply directly, no visa needed
  - Already studying at NL school as non-EU → study residence + Nuffic internship agreement (Databricks uses often)
  - Not at EU school, non-EU → needs GVVA, Databricks **supports but prefers long-term thesis intern**; 12-week short summer for non-EU overseas students has low sponsor willingness
- **Relocation**: Amsterdam intern offers usually include **one-way flight + corporate apartment / housing stipend** (12-week program designed to be self-contained); specific numbers not public
- **30% ruling**: Interns not eligible; full-time conversion Amsterdam SWE I starting salary usually above threshold, applies

## 3. Interview Process

Databricks process **long and strict**, one of the **lowest acceptance rate** companies on the list (same tier as Stripe / Citadel / top quant).

### Amsterdam SE Intern standard process (5–7 weeks, 4–5 rounds)
1. **HR / Recruiter Call** (30 min)
   - Experience + motivation + "Why Databricks" (**must answer**, expects specifics — Spark? Delta? MLflow? Mosaic?)
   - Project deep dive, qualifications check
2. **Karat Phone Screen** (60 min, **outsourced to Karat platform**)
   - Usually **2 questions (1 easy + 1 medium)**, some reports get 3 questions but not enough time
   - **Cannot use AI / Google** (Karat has video-recorded live proctor)
   - Question types: array / hashmap / linked list / tree, **clean code + test case mindset** preferred over passing cases
3. **Second round tech algorithm** (60 min, virtual, live coding + senior + intern joint interview)
   - LeetCode medium range, leans graph / DP / sliding window
   - **Must have follow-up**: optimize time/space, write tests, discuss edge cases
   - Some teams ask basic knowledge (hash table internal impl, generics, OOP concepts)
4. **Behavioral / Hiring Manager Round** (45 min)
   - "Why Databricks?" "Tell me about Databricks values"
   - Classic: "What negative feedback have you received?" (a 2025-10 report original)
   - Project deep dive + self-reflection + culture fit
5. **(Occasional) Second manager / extra tech round** — depends on team, intern doesn't always have

### Full-time / Senior comparison (for reference)
- Full-time process: HR + 2 phone screens + **5 onsite rounds** (~9–10 hours), much longer than intern
- Onsite includes: 2 coding (LeetCode medium/hard), 1 system design, 1 deep dive (Spark/distributed), 1 behavioral
- Feedback: "harder than Facebook / Google, hiring manager explicitly says 'looking for the best'"

### Question type focus
- **Algorithms**: LeetCode medium base, but requires **clean writing + one-pass + with tests**
- **Real tested**: Topological sort for job graph (2025-10 report), LeetCode classic graph questions
- **System Design (intern occasional, full-time required)**:
  - Design a simplified Spark scheduler
  - Design distributed file system metadata
  - Design Delta Lake concept (transaction log + parquet)
- **Spark/Distributed internals (later rounds)**:
  - Spark shuffle principles, partitioning, broadcast vs shuffle join
  - RDD vs DataFrame vs Dataset
  - Fault tolerance: lineage, checkpoint
- **Behavioral (Databricks 8 Behaviors)**: ownership, customer obsession, take risks, raise the bar

8. **Behavioral**: Prepare **"negative feedback"** story (high frequency), genuine + reflection + action
9. **EU student advantage**: No visa needed, significantly higher acceptance probability; non-EU students **strongly recommended to hold NL/EU degree + study residence** before applying

## 7. Pitfalls and Community Feedback

### Warnings
- **Process extremely strict**: 5–6 rounds, acceptance rate << 5%, multiple Blind posts complain "harder than Facebook/Google"
- **Long loop**: Full-time onsite 9–10 hours, intern loop also 5–6 hours virtual; massive time investment
- **Picky culture**: Hiring manager rejection style "looking for the best candidate", no mediocre offers
- **Question difficulty rising**: After 2024 mostly medium, follow-up requires writing tests + perf optimization + edge cases, not just "AC passes"
- **Can't use AI tools**: Karat proctoring strict, ChatGPT / Copilot can't help
- **Amsterdam intern slots few**: Estimated <20 per year cohort (vs hundreds in North America)
- **pre-IPO valuation volatility**: RSU value uncertain, early employees enjoy IPO upside, intern enjoys depending on join time

### Pros
- **Top brand**: Databricks resume credential = top AI/data company, jumping to Snowflake / Confluent / OpenAI / Anthropic all positive
- **Extremely high stipend**: One of highest on the list, Amsterdam intern enough to live well
- **Strong mentorship**: 12 weeks have clear project + mentor + cohort activities
- **High return offer rate**: Public reports show return rate **70%+** (incl. Amsterdam)
- **Cutting-edge tech stack**: Spark, MLflow, Mosaic AI (LLM training/serving), Unity Catalog
- **Amsterdam Zuidas location**: Modern office area, convenient public transit

### Pros and cons
- (+) Top tech + top stipend + top brand
- (+) High return offer rate, intern → full-time → senior path clear
- (-) Extreme process difficulty, prep time investment huge
- (-) Amsterdam slots few, lower probability for non-EU students
- (-) RSU value uncertain before IPO
