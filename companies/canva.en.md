## New Grad / Junior Roles

> Information density: ⭐⭐ (Canva London is 2024 newly built European HQ, engineering roles themselves extremely few, Grad / Junior data very sparse, mostly references from ANZ Sydney Grad scheme + UK licensed sponsor data)
> Difference from internship: internship only ANZ; **London Graduate SWE** is Canva's only visible entry-level path in Europe, but **Early Talent still mainly ANZ, London 2026/2027 Internship Program not publicly opened**

- **Common role names**: **Graduate Software Engineer** (London / Sydney) / **Software Engineer I (B1)** / **Associate Software Engineer**; ANZ has **Canva Engineering Graduate Program** + **Launchpad** (12-month professional development) [Source (verified opened): https://www.lifeatcanva.com/en/early-careers/]; **London has no official Graduate Program branding**
- **European locations**:
  - **London (33-35 Hoxton Square, Shoreditch)**: 2024 opened EMEA HQ, **~250 people** [Source (verified opened): https://www.lifeatcanva.com/en/locations/united-kingdom/]; engineering team includes engineers / PMs / data viz / ML Engineering Manager (Evaluations), etc.
  - **No other European cities** — Canva has no office in Berlin / Amsterdam / Paris; UK also includes Affinity (Nottingham) / Flourish / Pexels acquisition entities
  - Sharp contrast with internship location — 2026/2027 Internship Program still **only ANZ (Australia / New Zealand)** [Source (search result): https://www.lifeatcanva.com/en/early-careers/]
- **Standalone Graduate Programme**:
  - **ANZ: Yes** — Canva Engineering Graduate Program (rotational, Sydney) + Launchpad (12 months)
  - **London: No** — no official cohort program, follows standard SWE recruiting + Graduate label
- **Non-EU visa (full-time, London) — 2026 important update**:
  - **Canva UK Operations Limited is UK licensed sponsor**, holds **Skilled Worker visa + Global Business Mobility: Senior or Specialist Worker** dual route licence [Source (verified opened): https://huntukvisasponsors.com/company/canva-uk-operations-limited-qgi-cru5fq0]
  - **2024 full year only sponsored 16 people, of which 81% salary ≥£80K** [Source (verified opened): https://huntukvisasponsors.com/company/canva-uk-operations-limited-qgi-cru5fq0] — i.e. sponsor vast majority via **Senior or Specialist Worker route**, applicable to senior not graduate
  - Official Early Talent page (2026-05 verified read) **has no explicit visa sponsor policy**, also **no public prohibition** (not fully consistent with previous "Early Talent roles do not offer visa sponsorship" rumor, 2026 wording appears neutralized) [Source (verified opened): https://www.lifeatcanva.com/en/early-careers/]
  - **Practical conclusion**: London Grad SWE via Skilled Worker route extremely low probability (sponsor slots almost all for senior), most realistic path for Chinese new grad still: UK Master → **Graduate Visa (PSW, 2-year work right)** → Canva recruit → outstanding performance then transfer to sponsor
  - **30% ruling / similar system**: UK has none, full tax
- **Salary range (base, gross/year)**:
  - **London Graduate SWE**: **£55K-£65K base + RSU** (Canva pre-IPO RSU, double-trigger); public data points < 5
  - **Sydney Graduate SWE (B1, comparison)**: **AU$74.9K base + AU$14.5K stock ≈ AU$89.4K total** (Levels.fyi 2026-05) [Source (search result): https://www.levels.fyi/companies/canva/salaries/software-engineer]; equivalent £40K-£45K, lower than London
  - **Equity**: Canva is pre-IPO private company, RSU is **double-trigger** (IPO + vest dual trigger); 2024 secondary tender offer valuation ~$32B, liquidity window limited
  - Plus UK standard ~5% pension + 30 days PTO + £1,000 wellbeing stipend
- **Application window**: London Grad SWE via regular recruiting entry rolling release, **no fixed cohort**; ANZ 2026/2027 Internship Program open [Source (search result): https://www.lifeatcanva.com/en/early-careers/]; missing London window not recoverable (since total slots themselves few)

## 2. Internship Roles & Directions

> **Important reminder**: As of 2025-2026 public recruiting page, nearly all Canva Software Engineering Internships are listed in Sydney/Manila/Wuhan, **London currently has no official SWE Internship entry**. Canva officially has stated Early Talent **does not provide London/Europe visa sponsorship**, requires own work right.

| Role category | Recruiting location | Tech direction |
|---|---|---|
| SWE Intern - Product Engineering | Sydney | Web frontend / editor rendering |
| SWE Intern - Infrastructure | Sydney | K8s, Service Mesh, Observability |
| SWE Intern - Data Science / ML | Sydney | Recsys, Search, ML Platform |
| Graduate SWE (London) | London | Full-stack, via regular campus recruiting not internship entry |

## 3. Application Requirements & Visa

- **Education**: Penultimate year undergraduate / graduate
- **Work Right (core pain point)**:
  - ANZ Internship only accepts PR / citizens / student visa → overseas students not studying in Australia basically no entry
  - London if open Graduate / Intern, Canva UK Ltd is Skilled Worker licensed employer, but Early Talent wording explicit **no sponsor**
  - Therefore **international students wanting London internship can basically only use Student Visa while studying in UK**
- **Salary**: ANZ Intern AU$80-95k pro-rated; London Grad SWE estimated £55-65k base + RSU

## 4. Interview Process (based on ANZ Internship)

```
Apply → Recruiter screens resume (Resume + short essay / short question)
     → HackerRank OA (1-2 LC Medium)
     → Video interview: behavioral 15 min + technical 45-50 min (LC + code walkthrough)
     → Hiring Manager Behavioral + Project Deep Dive
     → Wait ~3 weeks for Offer
```

Average from first contact to Offer **68 days**, interview pace slower than FAANG.

## 6. Culture & Reputation

- **Positive**: Design + engineering fused, strong product culture; Slack friendly, flat management; London office in Shoreditch creative district
- **Challenges**: Engineering roles highly concentrated in Sydney, London currently more like sales + business hub; London engineering promotion channel unequal in resource allocation to Sydney HQ
- **Glassdoor rating**: Overall 4.2/5 (Sydney data mostly), Work-Life balance rating high

## 7. Key Preparation Checklist

1. **Canva product familiarity**: Try Magic Design / Magic Write, have own usage stories
2. **LC Medium frequency**: array / string / tree; don't grind on hard
3. **Behavioral questions**: STAR template; "why Canva" focus on mission ("empower the world to design")
4. **Portfolio (frontend direction)**: GitHub small projects, strong design UI, big plus
5. **Think about products**: Interview often asks "how to improve a Canva feature"
