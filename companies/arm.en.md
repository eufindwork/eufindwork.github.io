Arm is the flagship brand of UK "hard tech" internships, with an **extremely mature placement culture**, complete 3 / 6 / 12-month programmes + a 2-year Part-time Undergraduate Programme. Historically heavy hiring of Chinese / Indian students.

## 3. Application Requirements and Visa

- **Degree**: STEM degree in progress, Bachelor / Master both OK; CS / EE / Physics background
- **Visa keys**:
  - Arm UK is a Skilled Worker licensed sponsor
  - **Most placements accept international students (Student Visa work rights)** — historically extremely open to Chinese / Indian students
  - 12-month placement requires legal work rights in UK during study / residence (Tier 4 / Student Visa)
  - Non-UK students needing sponsorship can pursue GAE / T5 for some roles but difficulty is high
- **Salary (Glassdoor / Indeed)**:
  - SWE Intern: average ~£25,566/year pro-rated
  - 25-75 percentile: £19.3k - £34.9k
  - Some Master / 12-month placements can reach £30k+

## 4. Interview Process

```
1. Online Application + CV + Cover Letter
2. Online Assessment (HireVue recording + personality / logic test)
3. Technical / Recruiter chat (30-45 min)
4. Technical interview (1-2 panel rounds)
   - SWE: C / C++ questions, memory management, linker, Linux systems programming
   - Silicon: Verilog, pipeline hazards, CDC, setup/hold
   - ML: framework details (PyTorch internals), model quantization, kernel fusion
5. Manager + Behavioral final round
```

Typically **3-5 weeks** to complete, rolling assessment, first-come-first-evaluated.

## 6. Culture and Reputation

- **Positive**:
  - **Excellent mentor system**: 95% of interns report significant skill growth
  - Strong engineering depth — touch real silicon production flow
  - Top-tier WLB: 9-5 rhythm, flexible hours, Cambridge city suits studying
  - High conversion rate — large Intern → Graduate Programme pipeline
  - International-student friendliness top-tier in the industry
- **Challenges**:
  - Slow promotion — career growth lags vs Big Tech
  - Salary ceiling below FAANG
  - Some teams have legacy C++03 / Perl code

## 7. Key Preparation Checklist

### Software / Compiler / Tools direction
1. **C / C++ deep dive**: pointers, memory alignment, smart pointer, RAII, Rule of Five
2. **OS / Linux systems programming**: fork/exec, signal, mmap, syscall
3. **DSA**: LC Easy-Medium, tree / graph traversal high-frequency
4. **Compiler basics (relevant roles)**: LLVM IR, SSA, register allocation
5. **Architecture knowledge**: ARM ISA basics, pipeline, cache, memory hierarchy

### Silicon / Hardware direction
1. **Verilog / SystemVerilog**: clock domains, blocking / non-blocking, CDC, metastability
2. **Digital logic**: setup/hold, state machines, PLL
3. **EDA tools**: Synopsys (DC, PrimeTime), Cadence Innovus basics

### ML direction
1. **PyTorch internals**: autograd, CUDA kernel, custom op
2. **Quantization / pruning**: INT8 quantization, QAT vs PTQ
3. **Compiler for ML**: TVM, MLIR, Triton
