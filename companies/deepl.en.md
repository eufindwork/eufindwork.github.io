## 3. Interview Process

> Glassdoor SWE: difficulty 3/5, 60% positive, average 20 days hire cycle (Cologne); company-wide 47 interview entries, average hire cycle 20 days

- **Total rounds**: ~4-5 rounds (full-time SWE) / 2-3 rounds (Praktikum / Werkstudent)
- **Each round format** (based on Glassdoor 2025 Cologne SWE interview):
  1. **Screening Call** (30 min): recruiter, role + visa + timeline
  2. **Technical Background** (1 hr): past projects + tech stack (Python / React / Backend) deep dive
  3. **Live Coding** (60-90 min):
     - Backend: database design + API + algorithms (state management, async, performance)
     - Frontend: React state management (Redux/Zustand) + global state + app architecture
  4. **System Design** (60 min, mid/senior): design translation service / inference platform / multilingual routing etc.
  5. **Culture / Team Fit** (45 min)
- **Question type breakdown**:
  - Backend SWE: Coding (40%) / DB / API design (25%) / System design (20%) / BQ (15%)
  - Frontend SWE: React + state management (40%) / Coding (30%) / Component design (20%) / BQ (10%)
  - ML Engineer: NLP / transformer implementation (35%) / Python coding (30%) / Domain (translation / MT eval / BLEU) (20%) / Culture (15%)
- **Difficulty assessment**: Medium (LC Easy-Medium body, Hard rare); emphasizes product engineering + practical engineering ability
- **OA exists**: No standardized OA; live coding replaces

### Feedback speed
- Some candidates report "professional and effective communication and fast feedback"
- But also "after applying, more than two weeks before response" cases — pace unstable

## 7. Pitfalls and Community Feedback

### Process level
- **Feedback speed unstable**: Some cases "fast and reactive", but also "2+ weeks waiting response"; manage expectations
- **DE administrative process**: Onboarding docs / Blue Card application / banking / Anmeldung need 2-4 weeks, don't panic
- **Live coding focuses on product engineering**: Don't treat DeepL as FAANG grinding type, emphasize practical engineering ability + system understanding

### Culture level (Glassdoor)
- **Positive**: "International team", "Clear mission (language no barrier)", "Solid product"
- **Negative**: Some Berlin reviews mention "middle management process heavy", "slow decision making" (big company-ization)
- **Overall rating**: ~3.7-4.0 / 5

### Known "pitfalls"
1. **Stock at entry-level near 0**: Levels.fyi verified base = total, RSU $0; don't get fooled by unicorn valuation hype
2. **Cologne vs Berlin vs Munich culture differences**: Cologne more stable + ML center, Berlin international young, Munich high salary high cost of living
3. **NLP / MT niche**: Hiring prefers NLP background, pure generic SWE competition fierce
4. **2024-2025 growth slowing + OpenAI/Anthropic translation capability pressure**: Business moat shrinking, but enterprise B2B remains DeepL advantage
5. **Werkstudent only Germany student visa**: Don't assume having EU student visa means can do DE Werkstudent

### International student friendliness
- **EU nationality**: Extremely friendly
- **Chinese master / new graduate**: Extremely friendly — publicly sponsor, multiple cases
- **PhD NLP/MT/TTS background**: Top friendly, Cologne Research Scientist is EU NLP top opportunity
- **New graduate**: Friendly, but Levels.fyi shows grad SWE data points few, salary negotiation baseline weak
