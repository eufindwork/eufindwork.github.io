## NG (New Grad / Junior 全职) 路径

- **岗位命名**: **Prosus AI Traineeship** (核心 entry program) + **Junior Cybersecurity Specialist** (当前 active) + 标准 IC (Machine Learning Engineer / Backend / Frontend / Infrastructure / MLOps Engineer — 但全 senior 标签)
- **是否有独立 cohort program**: **Yes — Prosus AI Traineeship**
  - **对象**: MSc / PhD 应届毕业生 ready to transition from academia to industry
  - **结构**: **4 天 hands-on AI 开发 + 1 天 dedicated professional growth** (training, mentor, structured learning)
  - **业务**: 给 Prosus 投资组合公司 (Delivery Hero / iFood / OLX / Stack Overflow / Swiggy / PayU 等) 提供 production AI 系统
  - **薪资**: **€3,500/月 + relocation support to Amsterdam** [来源 (实际打开过): https://jobs.eu.lever.co/prosus/05dbb818-d2b4-4512-9865-7415321c9d49]
- **起薪 (base + bonus + equity)**:
  - **Traineeship**: €3,500/月 = **€42K/年 (12 月制, 不计 holiday allowance)**, 折算后 **超 reduced HSM €2,801/月 阈值 (NL master grad)**, 但未达标准 HSM <30 €4,357 阈值 — 暗示 Traineeship 路径主要适合 NL master grad 或已有 NL 居留者
  - **Junior FT (e.g. Junior Cybersecurity)**: 公开数据稀缺 (Levels.fyi 无 Prosus 单独条目, 推断 €55-75K base); 业内 AMS Junior SWE 中位 **€78,751-€134,109** range [来源 (搜索结果): https://www.levels.fyi/t/software-engineer/locations/greater-amsterdam-area]
  - **Senior ML Engineer LLM**: 当前 active req, 推断 €100-140K base + bonus + Prosus stock (NYSE/Euronext: PRX, 流动性高)
- **Sponsor 政策 (FT)**: 
  - **Traineeship €3,500/月** = €42K/年, **达到 reduced HSM €33,612/年 (€2,801/月)** for NL master grad — 即官方 stipend 已 calibrated 到 reduced HSM 阈值, 暗示**面向 NL master grad** 设计
  - 标准 HSM <30 阈值 €4,357/月 (= €52.3K/年) Traineeship 不达标; 但 Senior IC 起薪 €100K+ 远超
  - 提供 **relocation support** (明文) → IND Recognised Sponsor 几乎确定
- **申请窗口**: rolling 全年; Lever 平台 17 个 AMS 开放岗 (含 1 ML Eng Intern + 1 Junior Cybersec + 多个 Senior IC) [来源 (实际打开过): https://findmethatdamjob.nl/companies/prosus/]
- **流程差异 vs intern**: Traineeship 比 Intern 多 1-2 轮 (含 hiring manager + leadership 终面), 总 4-5 轮; Senior IC 走标准 5-6 轮含 system design

## 2. 签证与国际学生政策

- **是否支持非EU学生**: Conditional 
  - **Intern**: 推断**不主动办 visa**, 偏好 NL 在读学生 (走学生签 + Nuffic)
  - **Traineeship**: 明文 "relocation support to Amsterdam" → **支持** (但 €3,500/月 = reduced HSM 阈值, 主要适合 NL master grad)
  - **Senior IC**: 标准 HSM Kennismigrant
- **Intern vs FT sponsor 差异**: 显著 — intern 路径几乎不办, Traineeship/FT 走完整 HSM 流程
- **已知 sponsorship 案例**: 无直接 1point3acres / Reddit / Blind 实证; 官方 Traineeship 页 "relocation support" 是最强 secondary signal
- **2026 阈值**: NL Kennismigrant <30 **€4,357/月** / 30+ €5,942/月 / **NL master grad reduced €2,801/月** [来源 (实际打开过): https://www.jobbatical.com/blog/netherlands-highly-skilled-migrant-salary-thresholds-2026]
- **30% ruling**: Traineeship base €42K/年 — 2026 ruling 阈值 <30 €46,107, **不达标**; 但 Senior IC 起薪 €70K+ 普遍达标

## 3. 面试流程

- **总轮数**: **3 轮 (标准 IC/Intern)** / **4 轮 (PM / Trainee leadership 岗)** — 比之前推断的 4-5 少 1 轮; Glassdoor 2025-07 AMS sample 实证 3 轮 [来源 (实际打开过): https://www.glassdoor.com/Interview/Prosus-Netherlands-Interview-Questions-E3405593.htm]
- **每轮形式 (标准 IC/Intern 3 轮)**:
  1. **Online screening / Recruiter call** (30 min — motivation + 简历 + visa 状态)
  2. **Technical interview 1** (LC Medium / ML 概念 / PyTorch + Huggingface 框架细节 / system design 基础)
  3. **Technical interview 2 (含 live practical case task)** — **不是 multi-day take-home**, 而是面试当场的 1-round case (product-flavored ML case, e.g. "给一个 OLX 反欺诈用例, 设计 ML 方案 + A/B test 实验"); 评估 product thinking + stakeholder management + culture fit
- **额外轮 (PM / Trainee / Leadership 岗)**: 4 轮 — 多 1 轮 hiring manager + leadership (PDT Lead / Trainee program lead), 90% motivation + behavioral, 经典题 "Describe a past AI/ML project + your contribution from PM perspective"
- **题型分布**: **behavioral / motivation ~50%** (Prosus 加权异常高) + ML / case ~30% + 算法 ~10% + product / stakeholder ~10%
- **难度评估**: **2.6/5** (Glassdoor 平均), 50% rate positive, 明显低于 Booking / Optiver / Adyen [来源 (实际打开过): https://www.glassdoor.com/Interview/Prosus-Netherlands-Interview-Questions-E3405593.htm]
- **Apply → outcome timeline**: **2-4 周** (2025-02 sample 2 周走完, 2025-07 sample 4 周)
- **OA 是否存在**: **不存在独立 OA**; case 是 live 1-round 面试内的 practical task, 不是发回家做的 multi-day take-home

- **Take-home / case 具体题型**: 原题未公开; 据 JD 与 sample 推断:
  - **product-flavored ML case** (而非纯 LeetCode), e.g. "Given a fraud / recommender / search use case at OLX / iFood / Stack Overflow, propose ML approach + 实验设计"
  - **A/B test 设计 + LLM eval + prompt engineering** 高概率出现 (JD 第一原则: "build solutions that win in A/B tests")
- **常见拒因**:
  - **"pace can be relentless"** — 部分人不适应 fast-moving 节奏 ([Glassdoor reviews](https://www.glassdoor.com/Reviews/Prosus-Netherlands-Reviews-E3405593.htm))
  - **culture fit 加权异常高** — "alignment with company culture" 反复出现; tech bar 过线不够, behavioral 翻车直接挂
  - **Behavioral 准备不足** — 2022 PM 案例 90% motivation/behavioral, sample 显示这是主轴
  - **Stakeholder management** 被点名 — 仅 talk tech 不够, 要展示"如何向 non-tech 业务方沟通 ML 价值"

> **中文社区 (1point3acres / 知乎 / 牛客) 面经匮乏** — Prosus 在中文圈知名度低 (大家更熟 Naspers / Tencent 股权关系, 不知道有独立 AI team); Reddit r/cscareerquestionsEU 也少见 Prosus 帖
> 建议第一手 Glassdoor + LinkedIn 校友主动 reach out + 听 Euro Beinat / Paul van der Boor 的 [MLOps Community 2024-11 talk](https://home.mlops.community/public/videos/prosus-15000-colleagues-use-ai-agents-every-day-paul-van-der-boor-and-euro-beinat-2024-11-15)

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐⭐⭐

- **Intern 可行性**: **零摩擦** — UvA 在读 + NL student visa, 学生签 16h/wk 学期 / 40h/wk 假期直接 cover, Nuffic convention 走完即可. Prosus HQ Gustav Mahlerplein **离 UvA Roeterseiland 校区骑车 ~25 分钟 / metro 15 分钟**. ML Engineering Intern LLM R&D 当前 active, 直接 Lever 申请
- **FT (Traineeship) 可行性**: **零摩擦** — 毕业走 zoekjaar, Traineeship €3,500/月 = €42K/年, **超 reduced HSM €2,801/月 阈值**. 公司提供 relocation support (UvA 在 AMS, relocation 对你不必要但说明 sponsor 流程成熟). 30% ruling 不适用 (base 不到 €46K), 这是唯一负面点
- **FT (Senior IC) 可行性**: **零摩擦** — 起薪 €100K+ 远超所有阈值, 但你应届可能直接 senior IC 困难
- **预计摩擦**: 
  - Intern: 零
  - Traineeship: 零
  - Senior IC: 零 (但 bar 高, 应届较难)
- **UvA 优势**:
  - **AMS 同城**: 0 relocation cost / time
  - **UvA AI Master / Data Science Master 校友在 PDT 应该有一定数量** (Dutch top universities 是 Prosus 主源)
  - **AMS UvA student community** (Picnic / Booking / Adyen / Mollie / Bunq / Prosus AI / Nebius) 互相 referral 文化强 — 一个 offer 通常导出多个 offer
- **方向 fit**: 你之前 ⭐ Nebius (AI infra) + Mistral (foundation LLM) — Prosus 是 **AI 应用到投资组合公司**, 与 Nebius/Mistral 互补 (你三家都申覆盖 infra + foundation + application 全栈)
- **建议申请时间窗**:
  - **Intern (ML Eng LLM)**: 立刻申 — Lever active, 滚动评估, 抢手岗位名额满即关
  - **Traineeship**: 毕业前 6 mo 申 (rolling, 但 onboarding 排期通常需提前)
  - **Junior Cybersecurity**: 现 active, 如方向匹配可申
