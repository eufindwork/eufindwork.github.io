## Intern 路径

- **岗位命名**: "Software Engineering Internship" / "Technology Summer Internship" — Hatfield (12 weeks, summer)
- **时长**: 10-12 weeks summer (June-Aug)
- **申请窗口**: 10-12 月开放, 1-2 月发 offer
- **薪资 (stipend gross/月 GBP)**: ~£2,500-£3,000/月 (= ~£30K p.a. prorated)
- **资格**: 在读本科 (penultimate year) / 硕士 CS / Robotics / Math / Physics
- **Sponsor 政策 (intern)**:
  - UK Tier 4 / Student visa OK
  - **NL student visa**: 不能直接走 UK intern (公司不开 intern SW sponsor, 历史无案例)
  - Athens / Barcelona / Sofia / Krakow office: 历史无 intern posting 公开
- **流程**: CV → 视频面 (6 questions, 公司价值观) → online tests (situational judgment + numerical / multi-tasking) → assessment centre (group task + 2 technical tasks 包括 coding, **无 interview/presentation** for SWE candidates)
- **转 FT 率**: 中-高 (~50%), 设计目标 funnel to grad scheme

- **岗位命名**: 
  - **Software Engineering Graduate Programme** — Hatfield (核心) [来源 (实际打开过): https://www.brightnetwork.co.uk/graduate-jobs/ocado/software-engineering-graduate-2026]

  - **Finance Graduate** — FP&A / Tech Finance + ACA study

- **起薪 (base + bonus + RSU)**:
  - **Software Engineering Grad base**: £35K-£42K (Glassdoor 推算; GradSignal 列 £38-50K) [来源 (实际打开过): https://www.gradsignal.co.uk/blog/uk-tech-companies-visa-sponsorship-graduates-2026]
  - **Levels.fyi Ocado SWE UK overall**: £42K-£73K, median 通常 £45-55K (含 1-2 yr exp) [来源 (实际打开过): https://www.levels.fyi/companies/ocado-group/salaries/software-engineer]
  - **Glassdoor Hatfield Ocado Technology Grad SWE**: £31,720 (P25) - £42,347 (P75), avg £36,614 [实际打开过]
  - Bonus: 5-10% performance, 部分 share scheme (LSE 上市)
  - **TC**: ~£38K-£48K (含 bonus + share)
- **Sponsor 政策 (FT)**:
  - Ocado Group 持 Skilled Worker license (Ocado Innovation Limited / Ocado Operating Ltd / Ocado Retail Limited 各持牌) [来源 (实际打开过): https://worksponsors.co.uk]
  - 官方语言: "Ocado is able to offer visa sponsorship though they are only able to cover the company-specific costs" — 即不承担 visa 申请人的 IHS / visa fee

  - **Software Engineering Grad**: base £35-42K **卡 SW £41,700 阈值**, 多数需走 NEC (£33,400) + new entrant 70% 折扣 ~£34,580
  - 实际操作: 公司 case-by-case 决定是否 sponsor, 历史 grad cohort 中国际学生比例 ~10-15%
- **申请窗口**: **2025-12-14 开放** (官方 brightnetwork 列), 2026-2 月 deadline, 9 月 start
- **流程差异 vs intern**: 同样 assessment centre (group + 2 tech tasks), 加 1 轮 hiring manager 1:1

## 2. 签证与国际学生政策

- **2026 UK 阈值**: Skilled Worker £41,700, NEC £33,400, SOC 2134 Software Developer going rate ~£49,400
- **Ocado 持牌情况** [worksponsors.co.uk + huntukvisasponsors 实际打开过]:
  - Ocado Innovation Limited, Ocado Operating Ltd, Ocado Retail Limited 都持 Skilled Worker license, A-rated
- **关键问题**:
  - **Software Engineering Grad** (Tech): 可能 sponsor (base 卡 £41,700 阈值, 走 NEC + new entrant 折扣可过)
  - **Commercial Solutions Grad**: **明确不 sponsor** (huntukvisasponsors 标记) — base 低 + SOC 不 eligible
  - **Engineering Grad** (硬件): 部分 SOC code (机械 / 自动化 工程师) 可走, case-by-case
  - **Finance Grad / UX Grad**: 通常不 sponsor (ACA 路径 / UX SOC code 限制)
- **政策硬伤**: 公司只 cover "company-specific costs" — 不付 visa fee + IHS (£1,035/yr * 5 = ~£5K out-of-pocket for grad)
- **GBM 路径**: 不适用 (Ocado 是 UK 法人主体)
- **NL student visa**: UK intern 不开 sponsor, NL/EU office 无 intern posting

## 7. 踩坑与社区评价

- **股价长期低迷**: 2021 高点 £29, 2026 ~£3, sharesave 价值有限
- **Commercial Solutions Grad 是坑** for international student: 不 sponsor + 含 night shifts (CFC operation rotation)
- **Tech vs Retail 文化差异**: Ocado Technology (Hatfield 主楼) 偏 traditional UK eng 文化, WLB OK (~40h), 但晋升慢. Ocado Retail (M&S JV) 更 commercial
- **OSP 客户流失风险**: Norwegian Kroger 推迟 OSP 部署, Casino (法国) 已撤, 2023-2024 多个客户公开抱怨 — 影响 long-term tech roadmap
- **Hatfield 通勤**: 从 London Kings Cross 20-25 min train, 有 staff shuttle bus 从车站. 但 Hatfield 本身 boring, 多数员工 hybrid 住 London
- **优点**: 真正在做 large-scale robotics + warehouse automation, 学到 deep tech (1000+ bot 协调, real-time bin picking), 不是 typical CRUD app

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

- **核心 trade-off**: Ocado 是该 list 中**最 traditional UK grad scheme 风格** — 结构清晰但 sponsor 政策保守 + grad base 卡 SW 阈值
- **Intern 可行性**: **零**
  - UK intern 不开 sponsor, 历史无国际案例
  - EU office (Athens, Barcelona, Sofia, Krakow) 无 intern posting 公开
- **FT 可行性**:
  - **Software Engineering Grad ⭐ 可行**: 
    - Hatfield base £38-42K 卡 £41,700 SW 阈值 (需 NEC + new entrant 折扣)
    - Ocado 历史 sponsor 国际 grad ~10-15% cohort
    - Glassdoor + GradSignal 列为 active sponsor
    - 评估: **中** 可行性
  - **Commercial Solutions Grad**: **不要选** — huntukvisasponsors 明确标记不 sponsor
  - **Engineering Grad (硬件)**: case-by-case, 不建议博
  - **UX / Finance Grad**: 不 sponsor
- **EU office 路径**: 
  - Athens / Barcelona / Sofia / Krakow 有 SWE FT 岗 — 对 EU passport 友好
  - NL student 毕业后用 zoekjaar 转 EU 路径可行 (西班牙 / 希腊 / 波兰 SWE 路径)
- **预计摩擦**: 
  - Hatfield SWE Grad: **中** (sponsor 可能 + base 卡线)
  - 其他 grad role: **极高** (堵死)
- **建议**: 
  - 只申 **Software Engineering Graduate Programme** (其他 grad 不要碰)
  - 申请直接在 cover letter 写 visa status 让 HR 决定 sponsor pipeline
  - 备选 EU office (Athens SWE / Barcelona SWE) — NL student 毕业后路径
  - **重要**: Ocado 不付 visa fee + IHS, 自己需要预留 ~£5K cash for visa
  - Backup: Snyk London (该 list 最稳), Datadog London (sponsor 友好)
  - **真实判断**: Ocado SWE Grad 适合作为 **中等优先级 backup**, 不要当 main pipeline (sponsor 概率 ~30-40%)
