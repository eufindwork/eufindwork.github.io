## 2. 签证与国际学生政策

**核心结论: 间接 sponsor 证据 + Industrial PhD 是独特国际生通道; 但中国籍直接案例稀少**

| 维度 | 政策 |
|------|------|
| 是否支持非EU学生 (全职) | **Conditional Yes** — Blue Card 阈值 €45,934 / Reduced €41,041.80, Aleph Alpha SWE base 估 €75-85K 充分符合; 但 Nextleveljobs 未列入 sponsor list, 案例间接 |
| 是否支持非EU学生 (PhD Intern) | **Likely Yes** — 走 DE 研究签 / Pflichtpraktikum, 通常无需 sponsor; 但 Industrial PhD 走 3 年 work contract 必须 sponsor |
| 是否要求 work auth | 全职 No (公司估办 Blue Card); Working Student Yes (需德国学生签) |
| 已知 sponsorship 案例 | LinkedIn 显示 Heidelberg site 多国籍工程师; 但中文 / Reddit / 1point3acres 无直接实证 |
| Industrial PhD 独特性 | 与 University of Heidelberg / MPI 联合培养, 公司付薪 + 大学正式 PhD 身份 — EU 罕见 |
| 2024-2025 layoff 影响 | 公司战略转型 + 部分 layoff 报道, 新 sponsor 节奏可能放缓 — 申请前与 HR 确认当前 hiring stance |
| Heidelberg 大学城 | 国际化程度高 (Uni Heidelberg + EMBL + MPI 集群), 配套良好 |

**对中国留学生的可行路径**:
1. **PhD 候选人**: 申请 **Industrial PhD** 是最强通道 — 3 年 sponsored, 公司 + 大学双导师, 顶会论文 + 工业经验双收
2. **已在 EU 念书 (master/PhD)**: 申 PhD Internship 或 AI Engineer 全职, 公司估办 Blue Card
3. **不在 EU 的 master/PhD**: 申 AI Software Engineer / AI Engineer 全职, 但准备面临 visa 流程, 案例少
4. **GTM Working Student**: 仅限持德国学生签的在读生
5. **2024-2025 layoff 风险**: 应聘前研究公司当前财务/战略状况 (LinkedIn 团队规模变化, 媒体最新报道)

## 3. 面试流程

> Glassdoor 综合: 难度 3/5, 44% positive — 中等难度, 流程相对快速 (反馈及时)

- **总轮数**: ~3-4 轮 (PhD Intern) / 4-5 轮 (全职)
- **每轮形式** (基于 Glassdoor Heidelberg 2024-10 SWE 面经 + 行业 NLP/LLM 公司 standard):
  1. **Recruiter Screening** (60 min): role + visa + research interest 对齐
  2. **Team Introduction Call** (30-45 min): meet potential team member, casual 介绍 + Q&A
  3. **Technical Interview** (90 min): 候选人介绍 past work / projects + 每个 part 后跟技术深度问 ("first interview is already half technical" — Glassdoor 原话) [来源: https://eujobs.co/career-guides/aleph-alpha-gmbh-career-guide]
  4. **Research Deep Dive / Coding** (60-90 min):
     - PhD Intern: 现有 research project 详解 + 与 Aleph Alpha 团队 mission 对齐讨论
     - 全职: Python + PyTorch 实现题 (transformer / training loop / sampling / RAG)
  5. **Culture / Leadership Chat** (45 min): mission alignment (sovereign EU AI, multilingual LLM 价值观)
- **题型分布**:
  - PhD Intern: Research / paper deep dive (50%) / 编程 implementation (30%) / domain (LLM training / multilingual) (20%)
  - 全职 SWE: Coding + PyTorch (40%) / 系统设计 (LLM inference / RAG / model evaluation) (30%) / Domain (NLP / LLM) (20%) / BQ (10%)
- **难度评估**: Medium - Medium-Hard; LeetCode hard 比例低, 重 ML / NLP 概念深度
- **OA 是否存在**: 不存在标准化 OA; 偶发 take-home (e.g. fine-tune 一个小模型 + 报告)
- **流程速度**: Glassdoor 反馈"fast and reactive with feedback after each stage" — DE tech 公司里偏快

## 7. 踩坑与社区评价

### 流程层面
- **"First interview 已经 half technical"** — 不要被 recruiter call 标签麻痹, 准备好讲 past work 技术细节
- **Industrial PhD 申请周期长**: 3-6 个月谈话 + topic 对齐 + 大学导师匹配, 不是常规快招
- **Referral 几乎必须**: 直接 cold apply 通过率低, 找内部 referral 大幅提升

### 文化 / 业务风险
- **战略转型 + 2024-2025 layoff**: 公司从纯 base model (与 OpenAI/Anthropic 同台) 转向 Enterprise GenAI 平台 + sovereign AI, 部分 Research team 缩减; 申请前研究当前 hiring 状态
- **Sovereign AI 定位**: 主要客户德国政府 / 银行 / 大型制造业, 业务节奏比纯研究 lab 慢但商业稳定性强
- **Heidelberg 地理位置**: 大学城, 国际化程度高但不是 Berlin/Munich 大都市, 配套适合长期生活
- **多语言模型 vs 英文 SOTA**: Pharia 系列 multilingual benchmark 强但英文 head-to-head 与 GPT-4 / Claude 仍有差距

### 已知"坑"
1. **Nextleveljobs sponsor list 未列入**: 间接信号公司 sponsor 节奏不如 Trade Republic / Celonis 公开; 申请前邮件确认
2. **Levels.fyi 数据极少 (n=3-5)**: 谈薪缺基准
3. **PhD Intern 必须 3rd year+**: 1st/2nd year PhD 不要浪费时间
4. **战略转型期**: 入职后 team / 产品方向可能调整, 心理准备
5. **德语友好**: 工作环境英语为主, 但德语 B1+ 在 GTM / Enterprise sales 岗有显著优势

### 对国际学生友好度
- **EU 国籍 + ML / NLP PhD**: 极友好
- **PhD 顶会一作 + multilingual NLP**: 友好, Industrial PhD 是稀有通道
- **中国籍 master / 新毕业**: 中等友好 — 案例间接但通道存在
- **中国籍 PhD / Industrial PhD candidate**: 高潜力 — 直接申, referral 提升
