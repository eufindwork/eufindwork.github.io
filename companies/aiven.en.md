## Intern Path

- **Position naming**: no formal cohort intern program; occasional thesis worker / summer trainee (mainly in Helsinki, via local university channels, Aalto / U Helsinki)
- **Length**: thesis 6 mo most common
- **Application window + deadline**: not public, inquire via campus fair / careers@aiven.io
- **Salary (stipend gross/month)**: not public; Helsinki tech intern market rate €2,500-3,500/month. Aiven FT median €55,483 → intern at 50-60% prorate ~€2,800/month reasonable [Source (verified opened): https://www.levels.fyi/companies/aiven/salaries/software-engineer/locations/greater-helsinki]. FT employees report €2,000/year personal learning stipend (Glassdoor review)
- **Eligibility (degree, local residency requirement)**: MSc CS / Data Eng in progress, **default requires existing FI residency / work permit**
- **Sponsor policy (intern)**: ❌ intern **not sponsored** (same model as Wolt / Supercell); cross-Europe internship not feasible
- **Process**: campus recruiting / referral mainly
- **FT conversion rate**: not public

- **Application window**: year-round rolling
- **Process differences vs intern**: full-time 4-6 rounds (recruiter → hiring manager → 2x technical → system design → values fit), intern usually 2-3 rounds

## 3. Interview Process

1. Recruiter screen (30 min)
2. Hiring manager call (45 min, role context + experience deep dive)
3. Technical screen (Live coding, Python/Java/Go, 60 min)
4. System design (SRE / Backend, 60 min) — Kafka / Postgres internals bonus
5. Values / culture fit (45 min, "Curiosity, Care, Together" three values)
6. Reference check + Offer

> Multi-source Glassdoor / LinkedIn alumni rate as "high tech bar, but transparent process; mostly hires mid-senior, few Junior slots".

## 8. For UvA Students (NL Student Visa) — Specific Assessment ⭐

- **Core trade-off**: already holding NL student visa → choosing Aiven means **giving up NL zoekjaar (€2,801 reduced HSM)**, switching to DE Blue Card (Berlin) or Finland Blue Card (Helsinki)
- **Intern feasibility**: ❌ **almost infeasible** — no formal intern program, thesis worker defaults to requiring local work permit, cross-Europe intern not sponsored
- **FT feasibility**:
  - **Berlin SRE/Backend → high** — DE Blue Card shortage occupation €45,934, JD explicit guaranteed; Aiven SRE starting salary should cover
  - **Helsinki → medium** — Finland Blue Card €47,244, Aiven Helsinki median €55K covers; but sponsor policy not public in JD, need to confirm at interview
- **Expected friction**:
  - Berlin → low (JD explicit + full relocation)
  - Helsinki → medium (FI work permit + Nordic relocation)
- **UvA advantage void**: this company is not in NL, no zoekjaar benefit, need to redo visa
- **Advice**:
  - If non-EU + want to do OSS data infra → **apply Berlin; sponsor is the strongest signal of the 7 firms**
  - If want to stay in Nordics → Helsinki is fallback, but proactively ask about sponsor
  - If user wants to continue NL path → this company **should not be prioritized**, JetBrains AMS / Booking / Nebius more aligned
