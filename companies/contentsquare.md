## 3. 面试流程

- **总轮数**: 4 轮, 平均 14 天 (有人 2-4 周) [来源 (实际打开过): https://www.glassdoor.com/Interview/Contentsquare-Software-Engineer-Interview-Questions-EI_IE1106723.0,13_KO14,31.htm]
- **每轮形式**:
  1. **Coding Game Challenge** — MCQ + problem-solving (类似 CodinGame), 第一步刷人
  2. Hiring manager screen (经验 + 期望)
  3. Manager interview (思维 + 技术 + design pattern)
  4. **Technical interview (90 min)** — live coding DSA + tech stack 题 (Node.js / TS)
- **题型分布**: Live coding 40% / Coding Game OA 25% / Design / 系统 20% / BQ 15%
- **难度评估**: **3.2/5 难度** (Glassdoor), medium DSA + 实战 Node.js/TS
- **OA 是否存在**: **Yes (Coding Game Challenge 是必经第一步)** — 类似 CodinGame / Codility
