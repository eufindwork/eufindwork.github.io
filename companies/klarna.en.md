## 2. Role Profile

### 2.1 Software Engineer Intern
- Tech stack: Java (main), Kotlin, Scala, Node.js / TypeScript, AWS (heavy), Kubernetes, Kafka, PostgreSQL, DynamoDB.
- Team directions: Payments core, Merchant, Consumer App, Shopping, Risk Platform, Internal Developer Platform.
- Expectations: solid algorithms/data structures, concepts of distributed systems/microservices/event-driven architecture, can deliver a service end-to-end in 6 weeks.

### 2.2 Data Science / ML Intern
- Tech stack: Python, SQL, Spark, AWS SageMaker, Airflow, PyTorch / scikit-learn / XGBoost.
- Team directions: real-time risk control (fraud / credit decisioning), Customer Lifetime Value, Return / Refund prediction, recommendations and Shopping, AI Assistant (GenAI).
- Expectations: can independently complete an end-to-end ML project (data exploration → feature engineering → model → evaluation → simple deployment); strong SQL + statistics fundamentals.

## 3. Interview Process

### 3.1 SWE / DS Intern general process

1. **Online Logic Test (Kattis Logic Test)** — first hard gate
   - 18 questions / 15 minutes, pure abstract reasoning (rotation, enclosure, increment/decrement, snake, merge/split), completely different from LeetCode style.
   - Key design: will redo in recruiter call video (same format) to verify consistency; large gap between the two will directly cut.
2. **Recruiter Call** (30 min) — background, motivation, visa, salary expectation, values (Krew).
3. **Take-home / Live Coding**
   - SWE: take-home project (usually write a small service + unit tests) or 60–90 min real-time programming; Java/Kotlin leaning.
   - DS / ML: 90 min Live Coding & Team Fit — given a toy dataset (sklearn style), free to choose any model, emphasizing "analysis process + explanation + visualization".
4. **Technical Deep-Dive Interview**
   - SWE: project deep dig + medium LC question + system design concepts (design idempotent payment, design retry / outbox pattern).
   - DS: ML conceptual Q&A (supervised learning/overfitting/regularization/tree models/embedding), often follow-up project details.
5. **Behavioral / Values (Krew) Interview**
   - Klarna values called **Krew**: Open / Tough / Driven / Sharp / Sincere / Sustainable / Smart.
   - Behavioral questions very specific (example you challenged manager; example you couldn't persevere; example you owned one broken thing).
6. **Hiring Manager + Team Fit**
   - Chat with specific team's lead + 1–2 engineers; often includes "if I gave you this ambiguous problem how would you handle it".
7. **Bar Raiser** (appears in some processes) — non-team senior re-review.

> Overall cycle: 6–7 rounds, average 36 days (jointaro / Glassdoor consolidated); DS process can reach 6 rounds / 2 months+.

## 5. Visa & Cross-Border Work

- **EU / EEA students**: free to work, no hour limit.
- **Non-EU studying in Sweden**: student residence permit generally allows full-time / part-time work during semester, doing internship within visa validity.
- **Overseas applicants**: Klarna historically very rarely sponsors visa for interns; can go via Internship/Trainee permit, but requires Migrationsverket approval 1–3 months.
- **Full-time graduates**: Work permit; salary far exceeds Migrationsverket minimum threshold, Klarna will proactively assist; EU Blue Card also viable (Sweden 2025 threshold about SEK 54,830/month).

| Stage | Time | Notes |
| --- | --- | --- |
| Job posting | Year-round rolling, main batches 9–11 months | Thesis internship best to apply before Dec |
| Application + Kattis test | Within 24h–72h | Don't delay, basically don't reopen after test link closes |
| Recruiter call | 1–2 weeks | Simultaneously confirm visa / schooling system |
| Take-home / Live coding | 2–4 weeks | Take-home recommend delivering within 1 week, ideally attach README + unit tests |
| Tech / Values / HM | 4–8 weeks | Multiple rounds, cross-week scheduling |
| Offer | 36 days average | Decision window usually 1–2 weeks |

Application tips:
- Pre-drill Kattis Logic Test on TSAtestprep / JobTestPrep / Psychometric-success; pattern fixed.
- Highlight **payments / risk control / recommendation / GenAI** related projects in resume; 2024–2025 strategic words are "AI assistant, cost-efficient operations, real-time risk, merchant growth".
- Behavioral interview prepare Krew values corresponding stories (Open / Tough / Driven / Sharp / Sincere / Sustainable / Smart), ideally 2 stories per value.
- Thesis internship particularly favorable for masters, can directly connect with team + school credits.
- Process long + easy to be ghosted: actively follow up, and run multiple companies simultaneously during waiting.

## 8. Key Risks / Notes

1. **AI replacement aftermath**: customer service / content / some frontend / Ops internships significantly reduced; for stable internship direction please apply to ML / Data Science / Risk / Payments Core.
2. **Process long + easy to ghost**: poor candidate experience is one of Klarna's public pain points; recommend simultaneously running other companies, actively follow up.
3. **Kattis Logic Test is hard gate**: completely different from algorithm questions, must pre-practice — otherwise 70%+ candidates fail this stage.
4. **Intensive behavioral interviews**: Krew values pervade all rounds; each interviewer scores Krew alignment from their angle.
5. **Limited visa support**: internships rarely sponsor; overseas candidates need to self-confirm status; thesis internship can leverage school visa channel.
6. **Pre-IPO volatility**: from 2025 Klarna prepared / launched US IPO, headcount and team priorities may adjust at any time, post-offer onboarding dates may be delayed.
