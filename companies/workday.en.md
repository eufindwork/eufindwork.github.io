## 1. Basic Info

- **European offices**: Dublin (EMEA HQ ⭐), London, Munich (DACH), Paris (France enterprise)
- **Role types**:
  - SWE (Java + Scala platform + Workday self-developed UML/MVC framework "Workday XpressO"), Data Eng, ML/Data Scientist
  - Applications Development Engineer (core Dublin role — uses Workday platform to develop modules)
  - Cloud Platform / Kubernetes / Infra
  - Support / Consulting / Implementation (many but not SWE)
- **Hiring cycle**: Workday Early Career Program **Sep start batch**, application **previous year Oct-Jan** (rolling); intern usually Summer start, application Jan-Mar
- **Important deadlines**: Graduate Sep 2026 should already be closed; Sep 2027 cohort application 2026-10 → 2027-01 (historical pattern)

## Intern Path

- **Role names**: **Software Engineering Intern** / **Co-op** / **Internship (Dublin)** — some teams also hire Data Eng / Cloud Ops intern
- **Duration**: 12-week Summer Intern, or 6 mo Co-op (occasional)
- **Application window + deadline**: 2026 Summer application 2026-01 → 2026-03; 2027 Summer application 2026-10 → 2027-02 (rolling)
- **Salary (stipend gross/month)**: **Dublin SWE Intern €2,800-3,500/month** (Glassdoor + 1point3acres combined); provides housing stipend / some cohorts include housing
- **Eligibility (degree, local residency requirements)**:
  - Enrolled BSc / MSc CS or related
  - Prefer IE university collaborations, but EU + international student applications accepted (Workday widely hires on LinkedIn)
  - English fluent
- **Sponsor policy (intern)**:
  - **< 90 days (Summer 12-week)**: IE Atypical Working Scheme, exempt from permit, Workday assists with agreement
  - **≥ 90 days (Co-op)**: needs General Employment Permit, Workday historically sponsors individual cases but not guaranteed
- **Process**: OA → recruiter → 1 tech (UML / coding) → final panel — see Section 3
- **Conversion rate to FT**: Workday intern → FT conversion high (60-70%, Glassdoor combined)

## 2. Visa & International Student Policy

- **Does it support non-EU students**: ✅ Yes (FT, IE Trusted Partner); intern depends on duration
- **Intern vs FT sponsor differences**:
  - **Intern < 90 days**: Atypical Working Scheme, exempt from permit
  - **Intern ≥ 90 days**: needs GEP, Workday case sponsor
  - **FT**: CSEP, Workday covers all, 2-4 weeks
- **Known sponsorship cases**: Workday Dublin has many international engineers (China/India/Brazil), LinkedIn + Reddit multiple cases; Jointaro 2025-07 Dublin SWE interview report contains sponsor discussion [Jointaro Workday Dublin (verified opened): https://www.jointaro.com/interviews/companies/workday/experiences/software-engineer-dublin-dublin-july-29-2025-declined-offer-neutral-c5a1f065/]
- **2026 thresholds**:
  - **Ireland CSEP**: **€40,904/year (from 2026-03)** — Dublin P1 base €55K+ far exceeds
  - Spouse Stamp 1G works
  - 21 months later Stamp 4 (PR 5 years)

## 3. Interview Process

| Stage | Content | Duration |
|------|------|------|
| 1. OA / Recruiter call | TA, motivation, visa, comp expectation | 30 min |
| 2. Tech 1 - UML / Architecture | **UML diagramming 1-hour** (Workday specialty, not LC) | 60 min |
| 3. Hire manager | Experience + Workday Core Values (EE: Employees, Customer Service, Innovation, Integrity, Fun, Profitability) | 30-45 min |
| 4. Onsite / Virtual full loop | **5-hour full set**: 30 min cultural + 45 min architecture (walk through projects) + 1-2 tech coding | 5 hours |

**Workday unique aspect**: Heavy UML / OOP design modeling (Workday platform is metadata-driven, candidate needs to demonstrate ability to use UML to express domain model). Not a traditional LeetCode algorithm heavy company. [Glassdoor Workday Grad Apps Dev Interview (verified opened): https://www.glassdoor.com/Interview/Workday-Graduate-Applications-Development-Engineer-Interview-Questions-EI_IE197851.0,7_KO8,50.htm]

Average cycle **4 weeks** (some cases 2 months)

## 7. Pitfalls & Community Reviews

- **UML interview trap**: Many candidates treat Workday as LC company grinding questions, but actually heavy on OO design; **must grind OO design questions** (Grokking the OOD interview)
- **Self-developed framework learning curve**: Workday XpressO / metadata-driven, ~3-6 months onboarding to be fully productive; some feel transferable skills limited
- **Dublin office size**: ~2000 employees, is Dublin's 3rd largest tech employer (after Google/Microsoft), Chinese/Indian colleague community very active
- **WLB review**: Glassdoor 4.0+/5, "great salary, benefits, employee programs"; but some teams cross-timezone (Pleasanton CA HQ) early meetings
- **Layoffs**: 2024 Q1 layoff ~3% (~170 globally), Dublin minimally affected; 2025 stable
- **Compensation stable but not top**: Dublin P1 ~€63K vs Google Dublin L3 ~€105K, but sponsor practical easier than Google
- **CSEP to Stamp 4 path**: 21 months later apply Stamp 4, 5 years PR — IE is one of shortest PR paths within EU

## 8. For UvA Students (NL student visa) — Specific Assessment ⭐

### Intern feasibility
- **Summer Intern Dublin (12 wk, < 90 days)**: ✅ medium-high feasible — IE Atypical Working Scheme exempt from permit, consistent with HubSpot path. **Workday friendly to UML-prepared candidates, international student hiring history active**
- **Co-op (6 mo)**: ⚠️ high friction, > 90 days needs GEP
- **Apply during NL period**: completely possible — Summer Intern aligns perfectly with UvA summer (Jun-Aug)

### FT feasibility
- **Graduation get Grad Apps Dev Dublin**: ✅ highly feasible — Workday Trusted Partner / CSEP active, P1 starting €55K+ meets threshold, process 2-4 weeks
- **NL zoekjaar conflict**: Workday **has no office in NL**, user needs to give up zoekjaar; but CSEP Stamp 4 5-year PR is more lenient than NL Kennismigrant 5-year PR (Stamp 4 spouse full work rights + 21 months accelerated)

### Estimated friction
- Summer Intern Dublin: **low**
- FT Dublin: **low**

### Advice
- **First choice strategy**: **Sep 2027 Graduate cohort** (application 2026-10 first week)
  - Prep: 2026 summer grind OOD questions (Grokking the OOD), Java/Scala project portfolio
  - UML is core differentiator, don't treat Workday as LC company
- **Second choice**: **Summer 2027 Intern Dublin** (application 2027-01, uses Atypical Working Scheme) → conversion FT
- **Salary expectation**: Dublin P1 ~€63K TC, lower than Big Tech Dublin (Google L3 ~€105K), but sponsor practicality + conversion rate + Stamp 4 PR path compensate
- **Alternative**: similar enterprise SaaS, **Salesforce Dublin** also Trusted Partner active; but Workday Early Career Program more structured
