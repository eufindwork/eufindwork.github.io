## Intern 路径

> ⚠️ **匮乏**: Mollie 没有公开的 "Internship" 命名通道, 官方 careers 页 [jobs.mollie.com/departments/engineering] 仅列 Graduate / II / Senior / EM. Glassdoor 上偶有 "Intern" / "Werkstudent" 历史 listing, 多为合作大学 (UvA / TU Delft / VU) 内部 referral, 非公开招聘.

- **岗位命名**: 无固定命名; 历史上出现过 "Engineering Intern" / "Werkstudent Engineering"
- **时长**: 通常 4-6 个月 (荷兰高校标准 stage)
- **申请窗口 + deadline**: 无公开窗口; 建议直接联系 talent@mollie.com 或通过 UvA / TU Delft career service
- **薪资 (stipend gross/月)**: 无公开数据; 荷兰 fintech 行业内 intern 通常 €500-1000/月
- **资格**: 默认要求**已在 NL 在读** (走学生签 + Nuffic convention)
- **Sponsor 政策 (intern)**: 不办 work permit; 仅接收已有 EU work rights 或 NL student visa 学生
- **流程**: CV → recruiter 电话 → 1 轮技术 → 1 轮 culture fit (相比 Grad 流程压缩)
- **转 FT 率**: 无公开数据; Glassdoor 评论显示 intern → Grad 桥接案例存在但非常规

## 2. 签证与国际学生政策

- **是否支持非EU学生**: Yes (IND Recognised Sponsor)
- **Intern vs FT sponsor 差异**:
  - Intern: 不办 work permit, 要求 candidate 已有 NL 学生签 / EU work rights (Nuffic convention 走完即可)
  - FT (Graduate / IC): 办 Kennismigrant
- **已知 sponsorship 案例**: Dwayne Gefferie (NL fintech recruiter) 公开点名 Mollie 为 sponsor [来源 (实际打开过): https://www.linkedin.com/posts/dwaynegefferie_why-dutch-fintechs-adyen-mollie-and-bunq-activity-7185920215904309248-s52u]
- **2026 阈值**: NL Kennismigrant <30 €4,357 / 30+ €5,942 / **NL master grad reduced €3,122**
- **30% ruling**: 2024 起 5 年期 30%→27%→20%→15% 阶梯下调, 2027 起进一步收紧. Grad base €71.4K 满足条件 + 居住地 ≥150km from NL border 可申

## 6. 申请渠道与建议

- **官网投递**: https://jobs.mollie.com/departments/engineering
- **内推途径**: LinkedIn 直搜 Mollie + 联系 talent acquisition, 或通过 NL 高校 (UvA / TU Delft / VU) career fair
- **简历/背景要求**:
  - Graduate: BSc / MSc CS, **fluent English (Dutch 非必须)**, 项目里展示 PHP / Java / Python 中至少 1 门深度
  - 加分项: fintech / payments 相关项目, OSS contributions, scalable systems 经验
- **建议**:
  - 关注 PHP — Mollie 核心栈历史上是 PHP (Symfony), 近年逐渐 Java / Python 迁移. Grad 入职后 rotation 可能需要适应多语言
  - **Lisbon office 招聘量最大** (9 positions vs Amsterdam 4), 若想增加 Mollie 概率可考虑 Lisbon (但薪资低且非 NL)

## 7. 踩坑与社区评价

- **Glassdoor 4.6/5** (253 reviews, 92% recommend) — 极高 [来源 (实际打开过): https://www.glassdoor.com/Reviews/Mollie-Reviews-E1366725.htm]
- **Pros**: great culture, friendly colleagues, good work-life balance, growth opportunities
- **Cons**: 
  - "heavy on-site expectation for low pay" — 较多 on-site (Amsterdam HQ), 远程灵活度低于 Adyen
  - "no compelling growth path communicated beyond vague 'maybe after 6 months SME program'" — 内部晋升路径模糊
  - 招聘流程偏长
- **薪资 vs Adyen/Booking**: 同级别 base 比 Adyen 低 15-25%, 比 Booking Compass 略低
- **股权**: private company, equity 不流动, 直到 IPO 才能变现

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

- **Intern 可行性**: **中** — Mollie 没有公开 intern listing, 但作为 UvA 在读学生 + NL student visa, 学生签 16h 学期 / 40h 假期可直接 cover, Nuffic convention 走完即可, **无需公司额外 visa 办理**. 建议通过 UvA career service 直接联系 talent@mollie.com 询问 spontaneous stage application
- **FT 可行性**: **零摩擦** — 毕业走 zoekjaar 1 年, Grad offer base €71.4K 远超 reduced HSM €3,122/月 阈值, 也超标准 HSM €4,357. 公司是 IND Recognised Sponsor, 流程成熟
- **预计摩擦**: 
  - Intern: 中 (因为无公开通道, 需自己 outreach)
  - FT: 零
- **UvA 优势**:
  - Mollie HQ 在 Keizersgracht 313 (Jordaan), **UvA Roeterseiland 校区骑车 15 分钟**
  - UvA 校友在 Mollie 有一定数量 (NL fintech 圈紧密), LinkedIn 校友搜索可找
- **建议申请时间窗**:
  - Graduate Program: **2026 年 12 月 – 2027 年 3 月** 关注 2027 cohort 开放
  - 普通 II / Senior: rolling, 任何时候可申
