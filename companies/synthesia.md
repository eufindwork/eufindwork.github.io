## 3. 面试流程

- **总轮数**: 3-5 轮 (intern/junior 3, mid+ 4-5)
- **每轮形式**:
  1. **Recruiter screen** (30 min): 背景 + 动机 + visa status (会直接问)
  2. **Hiring Manager interview** (45-60 min): 不太 technical, 项目细节 + cultural fit
  3. **Technical exercise** — 设计 video ingestion + annotation pipeline (组件 / I/O / 工具) [来源 (实际打开过): https://www.glassdoor.com/Interview/Synthesia-Interview-Questions-E4421112.htm]
  4. **Director / Founder round** (mid+ 才有)
- **题型分布**: System / pipeline design 40% / Project deep-dive 30% / Coding 20% / BQ 10%
- **难度评估**: 整体 straightforward (Glassdoor "extremely personable" reviews), 难度中等 (~2.8/5)
- **OA 是否存在**: 部分岗有 take-home (CodeSignal / Coderpad), 非所有

## 6. 申请渠道与建议

- **官网投递**: https://www.synthesia.io/careers (Greenhouse ATS 后台)
- **内推途径**: 在 LinkedIn 找 Synthesia London engineers 直接 message — 公司公开 transparent, 内推回复率高
- **简历/背景要求**:
  - 强 SWE + 对 video / generative AI 兴趣 (能 demo)
  - 顶校加分但非必须 — Synthesia 看产品 sense + ship 速度
  - **关键: visa status 提前讲清** — 如果已在 UK on Graduate Route, 直接说; 海外 candidate 先邮件确认 sponsor 意愿
  - Frontend / Full-stack candidate (TypeScript + React + Next.js) 命中率较高 (产品是 web-based video editor)

## 7. 踩坑与社区评价

- **海外 from-scratch 申请命中率低** — 80% immigrant 是统计上的事实, 但他们大多已在 UK; 海外应届直接申建议先 cold email recruiter 确认 visa 意愿
- **流程快但反馈直接** — 26 天平均, Glassdoor 反映 hiring manager personable; 是 frontier 范围里相对舒服的流程
- **公司业务赛道窄但稳** — generative video B2B (marketing / training videos), 不像 Anthropic/OpenAI 追 AGI, 但 ARR 高且 cash-flow positive 临近; 不喜欢 enterprise B2B 的别投
- **国际学生 friendliness**: 中等. 80% immigrants 是真的, 但 majority 是 UK 在读转工签; 海外应届最好先来 UK 读 MSc
