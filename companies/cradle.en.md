  - **CH path (if you get Zurich offer)**: Quota-restricted non-European talent permit (annual quota), company must prove EU candidate not available; same conditions prioritize EU/EFTA → Chinese-passport Zurich SWE extremely hard, usually via ETH/EPFL studies + school-assisted transition

- **Hiring competition / international student friendliness**: Amsterdam extremely friendly (publicly uses Kennismigrant), Zurich extremely unfriendly (explicitly not sponsoring); overall deep tech, non-biology SWE can apply (company clearly hires for "great code") but ML/Scientist roles strongly require PhD

## 2. Visa and International Student Policy

**Core conclusion: Binary split — Amsterdam full sponsor, Zurich/US explicitly no sponsor**

| Dimension | Amsterdam (NL) | Zurich (CH) / US |
|------|----------------|------------------|
| Supports non-EU students | **Yes** — IND Kennismigrant directly arranged [Source (verified opened): https://siliconcanals.com/cradle-dutch-visa-international-talent-amsterdam/] | **No** — official quote "we currently can only consider candidates who have, or are able to independently obtain, a local work authorisation" [Source (verified opened): https://builtin.com/job/software-engineering-machine-learning-intern-f-m/6352947] |
| Work auth required | **No** (company handles all) | **Yes** (must self-arrange) |
| 2026 threshold | <30 €4,357/month, ≥30 €5,942/month (IND) | CH non-European quota; US uses H-1B / O-1 |
| Intern needs visa | **Conditional** — Amsterdam intern usually via school internship agreement; Cradle historical PhD Intern Zurich explicit self-sponsor | **No** |
| Known sponsorship cases | Silicon Canals founder publicly acknowledged + 10+ nationalities 70 people | Only EU/EFTA + holding CH B/C permit |

**Feasible paths for Chinese international students**:
1. **Target Amsterdam**: Directly apply Backend SWE / Scientist Amsterdam role, Cradle handles IND
2. **Already studying in EU**: Amsterdam intern via school tripartite agreement
3. **Already studying in CH (ETH/EPFL/UZH)**: Hold student permit to apply Zurich SWE/ML Intern (PhD preferred)
4. **Not in EU and want Zurich**: Almost closed off — only path is reach EU first to get work auth then transfer
5. **Recommendation**: Don't pick Zurich offer first, directly lock the Amsterdam channel

## 3. Interview Process

> **2026-06 retry**: Cradle official careers page explicit hiring practices — "only communicates via @cradle.bio email", "only makes job offers after meeting candidates in person at Zurich or Amsterdam office", "uses AI/ML to assist initial screening" (human-final decision) [Source (verified opened): https://www.cradle.bio/careers]. Glassdoor interview entries still very sparse; process above inferred from historical JDs + industry comparables + official practices, intern usually 3-4 rounds (incl. onsite final must be in-person).

- **Total rounds**: ~4-5 rounds (full-time SWE) / 3-4 rounds (intern)
- **Each round format**:
  1. **Recruiter Call** (30 min): role/site/visa fit
  2. **Hiring Manager / Tech Lead** (60 min): past projects + Python/Backend depth
  3. **Technical / Live Coding** (60-90 min): Python algorithms + system question (e.g. data pipeline / API design)
  4. **Take-home Assignment** (est. 4-8h): occasional, more common in ML roles (design protein library scoring / training loop)
  5. **Onsite Final** (Zurich or Amsterdam): must be in-person, multiple panel + founder/CTO chat
- **Question type breakdown**: Python + DS&A (40%) / system design + API/data pipeline (30%) / Domain (ML or biology — ML role only) (20%) / BQ (10%)
- **Difficulty assessment**: Medium - Hard; emphasizes "write readable code, be kind, work well in teams" (Cradle JD original)
- **OA exists**: No standardized OA; take-home assignment occasional, intern process usually no OA

### Important process notes
- **Communication only via @cradle.bio emails** (anti-phishing)
- **Offer only given after in-person meeting** — must visit Amsterdam or Zurich onsite
- **Never asks candidates to pay** for anything

## 7. Pitfalls and Community Feedback

### Process level
- **Zurich / US no visa**: ⚠️ **Key pitfall** — don't treat Zurich as backup, Chinese passport basically impossible to self-sponsor CH work permit
- **Offer must be onsite final**: Amsterdam / Zurich pick one, can't accept offer remote — need to consider onsite flight cost/visa
- **Strict anti-phishing**: Cradle publicly declares on careers page "only via @cradle.bio emails" — outreach from other emails is suspect
- **Deep tech NDA culture**: Interview/salary public data scarce, expectation management requires LinkedIn outreach

### Culture level
- **70 people 10+ nationalities**: Publicly diverse, English work environment
- **wet lab + ML hybrid culture**: SWE also needs to understand high-level protein engineering concepts
- **Index Ventures family**: Engineering culture leans Silicon Valley rigorous, not EU slow-paced

### Known "pitfalls"
1. **Zurich offer ≠ visa available**: Reiterating #1 above
2. **Levels.fyi has no independent salary data**: When applying/negotiating, Glassdoor / LinkedIn salary insights also sparse, information disadvantage
3. **Intern role PhD-only**: Master / Bachelor in progress basically can't access SWE/ML Intern; want summer internship go full-time Backend SWE is another path
4. **CH high cost of living**: Even CHF 130K base, Zurich actual disposable income lower than Berlin €80K
5. **wet lab in Amsterdam not Zurich**: Want to do protein engineering hands-on wet lab must pick Amsterdam site

### International student friendliness
- **Amsterdam extremely friendly**: Publicly uses Kennismigrant, Chinese passport applies directly
- **Zurich extremely unfriendly**: Explicit self-sponsor only
- **Intern channel narrow**: PhD-only + Zurich-only, master in progress basically only via full-time Backend SWE Amsterdam
