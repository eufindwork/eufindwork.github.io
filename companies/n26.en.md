## 2. Role Profile

### 2.1 Software Engineering Intern (Backend)
- Tech stack: **Kotlin (primary) + Java**, **Spring Boot**, **AWS (heavy)**, **Kubernetes**, **Kafka**, **Postgres + DynamoDB**, Terraform, Datadog.
- Architecture: pure microservices + event-driven (Kafka), compliance pipelines deployed independently (KYC / AML / fraud).
- Team directions: Payments core, Cards, Lending, Invest (stocks + crypto + funds), Customer Identity / KYC, Risk & Fraud, Internal Platform.
- Expectations: solid JVM, understanding of event-driven + idempotency / consistency; interest in banking domain / regulatory compliance.

### 2.2 iOS / Android Intern
- Tech stack: iOS = Swift (no Obj-C), Android = Kotlin (no Java legacy); pure native (not React Native / Flutter); modular monorepo + lots of multi-module Gradle / SPM.
- Team directions: Account, Card UX, Onboarding / KYC, Invest (incl. crypto / stocks UI), Internal SDK / Design System.
- Expectations: built complete iOS / Android apps, command modern architectures (MVVM / TCA / Compose / SwiftUI) + Concurrency.

### 2.3 Compliance / Risk / Fintech Operations Intern
- Team directions: Financial Crime, AML, KYC, Fraud Ops, Regulatory Reporting; lighter tech stack (SQL + Excel + some Python), but high banking domain knowledge required.
- Value: under continued BaFin regulatory pressure, this is one of the few directions where N26 HC is still expanding.

### 2.4 Werkstudent (in-school long-term part-time)
- N26's most common intern format; 20h/week; roles cover almost all teams: Engineering, Data, Product, Marketing, HR, Legal, Compliance.

## 3. Interview Process

### 3.1 General process (intern / early career)

1. **Recruiter Call** (30 min) — casual video, background, motivation (why fintech / why N26), values (**Courage / Simplicity / Empowerment**), visa, salary expectation.
2. **Technical Screen** (45-60 min)
   - SWE: HackerRank challenge (6 quiz-style + 1 coding task, 60 min); or live coding.
   - Mobile: take-home app (well-scoped problem, testing architecture / API / error states / best practices), usually submit in 3-7 days.
3. **Take-home Review** (45-60 min) — review submitted take-home with a senior engineer, deep dive on architecture and design decisions.
4. **Live Coding / Pair Programming** (45-60 min) — banking scenario: implement transaction processor / balance calculator with concurrent ops / account management service.
5. **System Design / Architecture** (45-60 min, some flows) — payment idempotency, SAGA / outbox, Kafka message consistency, KYC flow design.
6. **Hiring Manager + Values** (45-60 min) — alignment with N26's three core values; team fit.
7. **Final / Bar Raiser** (some flows)

Overall cycle: **25-35 days** (Glassdoor data, shorter than Klarna).

## 5. Visa and Cross-border Work

- **EU/EEA students / residents**: free to work; preferred group.
- **Non-EU studying in Germany**: student visa includes work rights (mandatory internship doesn't count toward 120/240 cap).
- **Overseas applicants**: internships not actively sponsored, N26 recruiter will explicitly confirm EU work rights during recruiter call.
- **Full-time graduates**: sponsors EU Blue Card (2025 threshold ~€45,300/year, N26 SWE starting salary usually meets); fintech industry overall sponsor-friendly.
- **Remote**: N26 internally allows cross-office between Germany / Vienna / Barcelona, but cross-EU outside not allowed.

## 6. Application Strategy & Timeline

| Stage | Time | Notes |
| --- | --- | --- |
| Job posting | Year-round rolling; 2025-2026 hc tight, some teams hiring freeze | Watch n26.com/careers + LinkedIn |
| Application screening | 1 week | Resume keywords: Kotlin / Spring Boot / Kafka / AWS / Swift / Kotlin (Android) / Banking domain |
| Recruiter call | 1 week | Confirm EU work rights + three values alignment |
| Take-home / HackerRank | 1-2 weeks | Take-home quality is core scoring |
| Tech rounds | 2-3 weeks | Live coding + system design 1 round each |
| HM | 1 week | Behavioral + values |
| Offer | 25-35 days | Shorter than Klarna, slightly faster than Zalando |

Application tips:
- **Take-home is core scoring**: production-quality code (unit tests, error handling, clean architecture, README explaining trade-offs) directly differentiates.
- Prepare banking domain Q&A: account / card / payment clearing / KYC / AML / PSD2 / Open Banking basics.
- N26's three values should map to concrete behaviors in your stories: **Courage** (dare to challenge / push risk but compliance-conscious decisions), **Simplicity** (cases of simplifying product / code / process), **Empowerment** (team empowerment / knowledge sharing).
- Awareness of **regulatory / compliance risk**: ability to discuss BaFin / ECB / PSD2 / DORA / MiCA / GDPR significantly boosts (even for engineering roles).
- 2025-2026 due to BaFin regulation + leadership change, tightening hc; non-engineering roles (Compliance / Risk) are among the few still hiring aggressively.

## 8. Key Risks / Notes

1. **BaFin regulatory uncertainty**: 2025 resumed special monitor + raised capital requirements + halted NL mortgages; team budget impacted; intern hc tightened.
2. **CEO transition period**: Co-founder Tayenthal stepping down, UBS executive Mike Dargan takes over 2026-04, strategy and org structure likely to adjust; start dates / team assignments after offer may shift.
3. **Does not sponsor intern visas**: overseas candidates rely on Master Thesis or first studying in Germany; recruiter will explicitly confirm.
4. **Take-home high bar**: take-home is graded strictly, requires unit tests + CI + README + design trade-off explanation; don't treat it as "homework-level".
5. **Banking domain is a clear plus**: ability to discuss KYC / AML / payment rail / PSD2 in resume or interview stories is significantly positive.
6. **Internalize the three values**: Courage / Simplicity / Empowerment is scored every round; not as flashy as Spotify Values, but weighted equally.
7. **HC uneven by role**: engineering / product / data teams generally tight 2024-2025; Compliance / Risk / Financial Crime still expanding.
