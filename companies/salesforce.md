## 3. 面试流程

- **总轮数**:
  - SWE Intern: 4 轮 (recruiter → OA → tech → panel)
  - Graduate Commercial: 3–4 轮 + **Assessment Day** (group exercise + presentation)
- **每轮形式 (Commercial Graduate)**:
  1. Online application + situational judgment test
  2. Recruiter call (motivation + market fit + language test for non-English markets)
  3. Hiring manager interview
  4. **Assessment Day** (group case study + 5-min individual presentation, in-office Dublin)
- **每轮形式 (SWE Intern)**:
  1. Recruiter
  2. HackerRank OA (LC Medium)
  3. Tech screen (CoderPad coding)
  4. Hiring manager + values panel
- **题型分布 (SWE)**: 算法 ~50% + system design ~20% + Salesforce 平台知识 (Apex / Lightning) ~10% + BQ ~20%
- **题型分布 (Commercial Grad)**: business case ~40% + presentation ~30% + BQ ~30%
- **难度评估**: SWE 偏 LC Medium, 不卷; Commercial Grad presentation 是 differentiator
- **OA 是否存在**: Yes (SWE), situational judgment test (Commercial)

## 7. 踩坑与社区评价

- **Graduate Path 命名易混淆**:
  - **Solution Engineering Path** (pre-sales engineer, technical demo)
  - **Sales Path** (pure sales)
  - **Rotation Program** (前 2-4 月 SE + 后续 sales)
  - 这三个不是同一岗! 看 JD 选 path 决定职业初期方向
- **语言市场要求严**: Italian Market 必须 native Italian; German Market 必须 C2 德语; 选错市场直接挂
- **August start vs September start**: 多 cohort start date 不同 (Sales German 是 August), 决定 visa 申请时间表
- **Assessment Day in-office Dublin**: 非 EU 候选人需自费机票去 Dublin 半 day; 部分 cohort 提供机酒 reimbursement, 申请时问清楚
- **SWE 不是 Dublin 主力**: Dublin Tower 大头是 commercial + cloud ops; pure SWE 数量 < Stripe Dublin; 想做 frontier eng 优先 Stripe
- **Agentforce 是 hot topic**: 2026 Salesforce 重点是从 Einstein → Agentforce 迁移, intern / new grad 接触 LLM / agent 项目机会高
- **国际生 friendliness**: ⭐⭐⭐⭐⭐ Trusted Partner + 大型 graduate cohort, 中印籍 Dublin 校友密度高
