## 3. 面试流程

- **总轮数**: 3-4 轮 (intern), 4-5 轮 (全职), ~2-4 周
- **每轮形式 (intern)**:
  1. Technical Recruiter call (30 min) — 介绍多个 internship subjects, 选择 topic
  2. **Take-home technical assessment** — 例如 API 实现最短路径 (Dijkstra / A*), 评估代码质量 + unit test + logging + secure headers [来源 (实际打开过): https://www.glassdoor.co.uk/Interview/Dataiku-Software-Engineer-Interview-Questions-EI_IE1037713.0,7_KO8,25.htm]
  3. Technical interview with engineer (deep-dive take-home, 1 hour)
  4. Final discussion + team fit
- **题型分布**: Take-home 50% / Live coding 25% / Architecture 15% / BQ 10%
- **难度评估**: 中. Take-home 注重 production-readiness (unit tests + logging + 文档), 不是 algo competition
- **OA 是否存在**: 通常无独立 OA, take-home 替代

## 7. 踩坑与社区评价

- Take-home 注重 production-readiness — 不写 unit test / logging 直接挂
- Paris office 在 Gare de Lyon, 周边 commute 方便
- Dataiku 是法国独角兽但**估值近期下调** (2024), hiring 略放缓 (相比 2022 peak)
- Junior SWE Paris 起薪 ~€50K — 比 Datadog Paris L1 (~€70K base) 低不少, 但 Dataiku stock + 学习曲线快是补偿
- 国际生友好 (全职 sponsor 顺), 实习要自带 student visa
