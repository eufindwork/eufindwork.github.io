# Improbable (London) Internship Intel

> **Language**: [中文](improbable.md) | English
>
> Improbable is a UK distributed simulation company founded in 2012, once valued at $2B+ for SpatialOS (massive multiplayer online game underlying tech). **Direction has been changing frequently in recent years**: games → defence → metaverse → Web3. In 2023 sold defence division (to NOIA Capital); 2024-2025 company focus shifted to M-Squared / Somnia metaverse and onchain games. **Intern hiring significantly shrunken, public 2024 / 2025 SWE Intern entry almost disappeared**. **Information scarce + company outlook uncertain**, proceed with caution.

## 3. Application Requirements & Visa

- **Education**: penultimate year undergraduate / master in school (CS / Math / Physics)
- **Technical requirements (historical)**: C++, Go, Python, Java, JavaScript, TypeScript at least two; gaming / distributed / simulation enthusiasts preferred
- **Visa**: Improbable Worlds Limited is Skilled Worker licensed employer, but interns mainly use Student Visa; international students historically hired, requires being UK student at the time
- **Salary (historical)**: monthly £3,000-£3,500 (3-6 month placement)

## 4. Interview Process (based on 2022-2023 historical signal)

```
1. Resume + coding challenge (HackerRank / CodeSignal)
2. Tech phone (45 min, DSA + Go or C++ basics)
3. Onsite / Virtual Final (2-3 rounds, 4-5h)
   - Algorithm / data structures
   - System design light (distributed state / consistency entry)
   - Team fit + Behavioural
```

## 6. Culture & Reputation — **Warning**

- **Positive (historical)**: high engineering bar, historically attracted many Cambridge/Imperial outstanding undergrads; good technical depth; demo strength (large-scale simulation)
- **Current challenges**:
  - **Multiple direction adjustments → high internal morale fluctuation**
  - 2023 sold defence → many engineers left for NOIA
  - Current focus Web3 / onchain unattractive to some candidates
  - Financials: 2023 fiscal year profit £11m, revenue £66m — numbers healthy but greatly shrunken from 2017 high
  - Glassdoor rating noticeably declining in recent years, from 4.0+ down to ~3.3-3.5

> Overall: **brand "halo" still there, actual opportunity and direction match needs self-check**.

## 7. Key Preparation Checklist (if still want to apply)

1. **Go language depth**: goroutine, channel, context, memory model
2. **Distributed consistency basics**: CAP, CRDT, State machine replication basic concepts
3. **C++ for game engines**: performance optimization, cache-friendly layout
4. **Web3 / Blockchain (new direction)**: Ethereum, smart contract, L2, Somnia project understanding
5. **Behavioral questions**: explain your own "why Improbable" — must have honest reason (metaverse / simulation / Web3 interest)
