## 3. 面试流程

- **总轮数**: 5 阶段 / 4-6 周 [来源 (实际打开过): https://www.finalroundai.com/blog/anthropic-interview-process]
- **每轮形式**:
  1. **Application screen + recruiter call** (30-45 min, 背景 + 动机 + AI safety 理解)
  2. **Take-home technical assessment** — 比如建 mini RAG pipeline 并写 trade-off doc [来源 (实际打开过): https://igotanoffer.com/en/advice/anthropic-interview-process]
  3. **2-3 轮 technical deep-dive** — live coding (CodeSignal / Colab), 实战题非 LeetCode 模板
  4. **Superday / panel** — 4-5 位面试官含资深 leadership, 含 values round
  5. **Offer + reference**
- **题型分布**: Coding 实战 (45%) / System design (15%) / ML 概念 (15%) / Values (25%) — Values 轮淘汰率最高
- **难度评估**: Glassdoor positive ~30-40%, 难度 3.5/5
- **OA 是否存在**: **Yes**, CodeSignal-style take-home, "practical & progressive" 非 algorithm trivia [来源 (实际打开过): https://igotanoffer.com/en/advice/anthropic-interview-process]

## 7. 踩坑与社区评价

- **没有 intern**: 学生唯一 strategy 是延迟入职 / 走 Research Residency-like 项目 (目前 Anthropic 无公开 residency, 只有 OpenAI 有)
- **Values 轮淘汰率最高** — Anthropic 招聘官明说 [来源 (实际打开过): https://blog.theinterviewguys.com/anthropic-interview-questions/]; 准备 AI safety / constitutional AI / RLHF / scalable oversight 的真实理解, 不要套话
- **AI 工具严格禁用** — 在 live interview 用 Cursor/Claude/ChatGPT = 立刻挂; 仅 take-home 有限允许
- **Paris/Munich 偏 commercial** — 想做 research 的优先 London/Zurich; Paris/Munich go-to-market / partnerships 为主
- **国际学生 friendliness**: 中高 (UK sponsor 没问题), 但 entry-level 命中率极低 → 务必同时投 OpenAI / Mistral / DeepMind / Cohere 等
