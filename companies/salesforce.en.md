## 3. Interview Process

- **Total rounds**:
  - SWE Intern: 4 rounds (recruiter → OA → tech → panel)
  - Graduate Commercial: 3-4 rounds + **Assessment Day** (group exercise + presentation)
- **Each round format (Commercial Graduate)**:
  1. Online application + situational judgment test
  2. Recruiter call (motivation + market fit + language test for non-English markets)
  3. Hiring manager interview
  4. **Assessment Day** (group case study + 5-min individual presentation, in-office Dublin)
- **Each round format (SWE Intern)**:
  1. Recruiter
  2. HackerRank OA (LC Medium)
  3. Tech screen (CoderPad coding)
  4. Hiring manager + values panel
- **Question type distribution (SWE)**: algorithms ~50% + system design ~20% + Salesforce platform knowledge (Apex / Lightning) ~10% + BQ ~20%
- **Question type distribution (Commercial Grad)**: business case ~40% + presentation ~30% + BQ ~30%
- **Difficulty assessment**: SWE leans LC Medium, not grindy; Commercial Grad presentation is the differentiator
- **OA exists**: Yes (SWE), situational judgment test (Commercial)

## 7. Pitfalls & Community Reviews

- **Graduate Path naming easily confused**:
  - **Solution Engineering Path** (pre-sales engineer, technical demo)
  - **Sales Path** (pure sales)
  - **Rotation Program** (first 2-4 months SE + later sales)
  - These three are not the same role! Read JD and choose path to determine early career direction
- **Language market requirements strict**: Italian Market must be native Italian; German Market must be C2 German; choosing wrong market directly fails
- **August start vs September start**: Multiple cohort start dates differ (Sales German is August), determines visa application timeline
- **Assessment Day in-office Dublin**: Non-EU candidates need to self-pay for ticket to Dublin for half day; some cohorts provide flight + hotel reimbursement, clarify when applying
- **SWE is not Dublin main strength**: Dublin Tower bulk is commercial + cloud ops; pure SWE count < Stripe Dublin; for frontier eng prefer Stripe
- **Agentforce is hot topic**: 2026 Salesforce focus is migration from Einstein → Agentforce, intern / new grad chance of touching LLM / agent project is high
- **International student friendliness**: ⭐⭐⭐⭐⭐ Trusted Partner + large graduate cohort, high Chinese/Indian Dublin alumni density
