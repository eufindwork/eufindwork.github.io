## 3. Interview Process

> **2026-06 retry**: Glassdoor Showpad Ghent SWE interview confirmed — typical 2-week process: initial Engineering Lead screen → Codility test → engineer interview at team; 2022 process detailed: 1) recruiter screen (motivation) → 2) hiring manager (behavioral + team dynamics) → 3) tech interview (knowledge + open-ended + case study) → 4) panel interview [Source (verified opened): https://www.glassdoor.com/Interview/Showpad-Software-Engineer-Interview-Questions-EI_IE683910.0,7_KO8,25.htm]. Average SWE hiring cycle ~20 days. Intern / junior data points still few, inferred as simplified FT.

- **Total rounds**: 4-5 rounds (FT)
- **Each round format**:
  1. Recruiter screening (30 min, motivation / visa)
  2. Tech screen (1h coding, usually HackerRank or CoderPad)
  3. Take-home or live system design (Backend / SRE mandatory, FE given component build task)
  4. Cross-functional / peer interview (1-2 engineers)
  5. Manager / values (culture, growth mindset)
- **Question type distribution**: algorithms ~30% + system / infra design ~30% + role-specific (Go / React / TF / K8s) ~30% + BQ ~10%
- **Difficulty assessment**: LeetCode Medium mostly, system design leans practical (microservices / event-driven / multi-tenant SaaS)
- **OA exists**: Yes (HackerRank tech screen)

## 7. Pitfalls & Community Reviews

- **Belgium high taxes**: brutto-net ratio is one of the worst in Europe (~45%-53% marginal tax), nominal salary looks high but take-home is weaker than Netherlands / Ireland
- **Ghent ≠ Brussels**: small city (~250k people), Chinese community extremely small, English daily-life OK but Dutch (Flemish) bureaucracy documents painful
- **Company medium size**: ~500 employees, don't expect FAANG-level comp; advantage is flat engineering culture, mid-junior gets broad exposure
- **AI is doing sales coaching / call summarization**, not frontier research, GenAI applicants should align expectations
- **International student friendliness**: ⭐⭐⭐⭐ visa explicit + relocation full package; but long-term PR Belgium is slow (5 years + B1 Dutch)
