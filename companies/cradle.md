## 2. 签证与国际学生政策

**核心结论: 二元分裂 — Amsterdam 全 sponsor, Zurich/US 明文不 sponsor**

| 维度 | Amsterdam (NL) | Zurich (CH) / US |
|------|----------------|------------------|
| 是否支持非EU学生 | **Yes** — IND Kennismigrant 直接办 [来源 (实际打开过): https://siliconcanals.com/cradle-dutch-visa-international-talent-amsterdam/] | **No** — 官方原话 "we currently can only consider candidates who have, or are able to independently obtain, a local work authorisation" [来源 (实际打开过): https://builtin.com/job/software-engineering-machine-learning-intern-f-m/6352947] |
| 是否要求 work auth | **No** (公司全办) | **Yes** (必须自办) |
| 2026 阈值 | <30 €4,357/月, ≥30 €5,942/月 (IND) | CH 非欧 quota; US 走 H-1B / O-1 |
| Intern 是否办 visa | **Conditional** — Amsterdam intern 通常走学校 internship agreement; Cradle 历史 PhD Intern Zurich 明文 self-sponsor | **No** |
| 已知 sponsorship 案例 | Silicon Canals 创始人公开承认 + 10+ 国籍 70 人 | 仅限 EU/EFTA + 持 CH B/C permit |

**对中国留学生的可行路径**:
1. **目标 Amsterdam**: 直接申请 Backend SWE / Scientist Amsterdam 岗, Cradle 全办 IND
2. **已在 EU 念书**: Amsterdam intern 走学校三方协议
3. **已在 CH 念书 (ETH/EPFL/UZH)**: 持学生 permit 可申 Zurich SWE/ML Intern (PhD 优先)
4. **不在 EU 且想去 Zurich**: 几乎封死 — 唯一路径是先到 EU 拿 work auth 再 transfer
5. **建议**: 不要先选 Zurich offer, 直接锁定 Amsterdam 通道

> 来源: cradle.bio + Silicon Canals + Built In 2025 SWE/ML Intern JD 原文

## 3. 面试流程

> **2026-06 retry**: Cradle 官方 careers page 明文 hiring practices — "only communicates via @cradle.bio email", "only makes job offers after meeting candidates in person at Zurich or Amsterdam office", "uses AI/ML to assist initial screening" (人工最终决策) [来源 (实际打开过): https://www.cradle.bio/careers]. Glassdoor 面经条目仍极稀; 上述流程基于历史 JD + 行业同档 + 官方 practices 推断, intern 通常 3-4 轮 (含 onsite final 必须线下).

- **总轮数**: ~4-5 轮 (全职 SWE) / 3-4 轮 (intern)
- **每轮形式**:
  1. **Recruiter Call** (30 min): role/site/visa fit
  2. **Hiring Manager / Tech Lead** (60 min): past projects + Python/Backend 深度问
  3. **Technical / Live Coding** (60-90 min): Python 算法 + 系统题 (e.g. data pipeline / API design)
  4. **Take-home Assignment** (估 4-8h): 偶发, ML 岗多见 (设计 protein library scoring / training loop)
  5. **Onsite Final** (Zurich 或 Amsterdam): 必须线下, multiple panel + 创始人/CTO chat
- **题型分布**: Python + DS&A (40%) / 系统设计 + API/数据管道 (30%) / Domain (ML or 生物 — 仅 ML 岗) (20%) / BQ (10%)
- **难度评估**: Medium - Hard; 强调"write readable code, be kind, work well in teams" (Cradle JD 原文)
- **OA 是否存在**: 没有标准化 OA; take-home assignment 偶发, intern 流程通常不 OA

### 重要 process notes
- **只通过 @cradle.bio 邮箱沟通** (反钓鱼)
- **Offer 只在 in-person meeting 后给** — Amsterdam 或 Zurich onsite 必须到
- **Never asks candidates to pay** for anything

> 来源: https://www.cradle.bio/careers (Important Notice 段落)

## 7. 踩坑与社区评价

### 流程层面
- **Zurich / US 不办 visa**: ⚠️ **关键踩坑** — 不要把 Zurich 当后备选项, 中国籍基本不可能 self-sponsor CH work permit
- **Offer 必须 onsite final**: Amsterdam / Zurich 二选一, 远程接 offer 不可 — 需考虑 onsite 机票成本/签证
- **反钓鱼严格**: Cradle 在 careers 页公开声明 "only via @cradle.bio emails" — 收到其他邮箱 outreach 一律可疑
- **deep tech NDA 文化**: 面经/薪资公开数据少, 期望管理要靠 LinkedIn outreach

### 文化层面
- **70 人 10+ 国籍**: 公开多元化, 英语工作环境
- **wet lab + ML 混合 culture**: SWE 也需要理解蛋白质工程 high-level concepts
- **Index Ventures 系**: 工程文化偏 Silicon Valley 严谨型, 不是 EU 慢节奏

### 已知"坑"
1. **Zurich offer ≠ 可办 visa**: 上述 #1 重提
2. **Levels.fyi 无独立薪资数据**: 申请前/谈薪时, Glassdoor / LinkedIn salary insights 也稀疏, 信息劣势
3. **Intern 岗 PhD-only**: Master / Bachelor 在读基本不开 SWE/ML Intern; 想暑期实习走 Backend SWE full-time 是另一条路
4. **CH 物价高**: 即便 CHF 130K base, Zurich 实际可支配低于柏林 €80K
5. **wet lab 在 Amsterdam 不在 Zurich**: 想做 protein engineering 上手 wet lab 必须选 Amsterdam site

### 对国际学生友好度
- **Amsterdam 极友好**: 公开走 Kennismigrant, 中国籍直接申
- **Zurich 极不友好**: 明文 self-sponsor only
- **Intern 通道窄**: PhD-only + Zurich-only, master 在读基本只能走全职 Backend SWE Amsterdam
