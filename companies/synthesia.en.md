## 2. Visa and International Student Policy

- **Supports non-EU students**: **Yes (conditional)** — A-rating Skilled Worker license, 16 CoS issued, but prefers those already in UK/EU
- **Requires existing work permit**: **No** (license can directly issue CoS), but ⚠️ **in practice often requires candidate already in UK on Graduate Route / Student visa**
- **Known sponsorship cases**:

## 3. Interview Process

- **Total rounds**: 3-5 rounds (intern/junior 3, mid+ 4-5)
- **Each round format**:
  1. **Recruiter screen** (30 min): background + motivation + visa status (will ask directly)
  2. **Hiring Manager interview** (45-60 min): not too technical, project details + cultural fit
  3. **Technical exercise** — design video ingestion + annotation pipeline (components / I/O / tools) [Source (verified opened): https://www.glassdoor.com/Interview/Synthesia-Interview-Questions-E4421112.htm]
  4. **Director / Founder round** (mid+ only)
- **Question type distribution**: System / pipeline design 40% / Project deep-dive 30% / Coding 20% / BQ 10%
- **Difficulty assessment**: overall straightforward (Glassdoor "extremely personable" reviews), medium difficulty (~2.8/5)
- **OA exists**: some roles have take-home (CodeSignal / Coderpad), not all

## 6. Application Channels and Advice

- **Official submission**: https://www.synthesia.io/careers (Greenhouse ATS backend)
- **Referral channels**: search Synthesia London engineers on LinkedIn and directly message — company is publicly transparent, referral reply rate high
- **CV/background requirements**:
  - Strong SWE + interest in video / generative AI (must be able to demo)
  - Top schools a plus but not required — Synthesia values product sense + ship speed
  - **Key: state visa status upfront** — if already in UK on Graduate Route, state directly; overseas candidates should email recruiter first to confirm sponsor willingness
  - Frontend / Full-stack candidates (TypeScript + React + Next.js) have higher hit rate (product is web-based video editor)

## 7. Pitfalls and Community Reviews

- **Overseas from-scratch application hit rate low** — 80% immigrant is a statistical fact, but most are already in UK; for overseas fresh grad direct application recommend cold emailing recruiter first to confirm visa willingness
- **Process fast but feedback direct** — 26 days average, Glassdoor reflects hiring manager personable; relatively comfortable process within the frontier range
- **Company business track narrow but stable** — generative video B2B (marketing / training videos), doesn't chase AGI like Anthropic/OpenAI, but high ARR and approaching cash-flow positive; don't apply if you don't like enterprise B2B
- **International student friendliness**: medium. 80% immigrants is true, but majority are UK enrolled transitioning to work visa; overseas fresh grads best to come to UK for MSc first
