## 1. 基本信息

- **欧洲办公室**: Amsterdam (HQ, Hoofddorp 园区, Schiphol 机场附近) / Düsseldorf / Paris
- **岗位类型**: Java backend (核心), Android / iOS, Data Engineer, ML Engineer, SRE, UX Designer
- **招聘周期**: rolling (Senior IC) + **2 个 cohort/年的 Tech Academy** (March + September intake)
- **重要截止日期**: 2026 September Tech Academy 已开放, 滚动审核 (CV 收满即关) [来源 (实际打开过): https://jobs.picnic.app/en/vacancies/JAU2ZUYC/graduate-programs/tech-academy-java-graduate-program/amsterdam/north-holland/netherlands]
- **IND Recognised Sponsor**: Yes (workwithvisa.com 官方收录) [来源: https://workwithvisa.com/companies/picnic]

## Intern 路径

- **岗位命名**: 
  - **UX Graduation Internship** (开放, 6 mo) [来源: https://jobs.picnic.app/en/]
  - 偶发 Software Engineering Internship / Data Internship (非常规)
  - **graduation 性质**: 必须配合 thesis 项目 (NL 高校最后一年标配 "afstudeerstage")
- **时长**: 6 个月 (graduation stage 标准)
- **申请窗口 + deadline**: rolling, 但 UX Grad Internship 通常配合 thesis 时间 (春季 / 秋季 intake)
- **薪资 (stipend gross/月)**: **€800/月 gross** (Glassdoor data, 历史 listing) — 标准 NL stage 薪资, 低于 Booking €1900 / Adyen €2400
- **资格**: 
  - **必须在 NL 在读** (Picnic graduation internship 默认绑定 NL 高校 thesis)
  - Bachelor / Master 最后一年
- **Sponsor 政策 (intern)**: **不办 work permit** — 默认要求 NL 学生签 + Nuffic convention
- **流程**: CV → recruiter call → coding challenge (Java / take-home) → on-site case + culture interviews (1 整天)
- **转 FT 率**: 估算 30-50% (UX Grad Intern 转 FT 案例多; SWE Intern 通常导向 Tech Academy)
- **踩坑**: 多 Glassdoor 评论提及 "process very lengthy for an intern application, requiring a test, mini-case study, and in-person office work day", "takes a lot of time, energy and money" — **不要为单一 intern offer 投入 100%**

## NG (New Grad / Junior 全职) 路径

- **岗位命名**: **Picnic Tech Academy - Java Graduate Program** (Amsterdam, 6 mo cohort 项目, 完成后转 FT) [来源 (实际打开过): https://jobs.picnic.app/en/vacancies/JAU2ZUYC/graduate-programs/tech-academy-java-graduate-program/amsterdam/north-holland/netherlands]
- **是否有独立 cohort program**: **Yes — Picnic Tech Academy**
  - **结构**: 6 mo 项目, 覆盖 Java Clean Code → Reactive Programming → MongoDB → Spring 6 / Kafka / Postgres / K8s / Terraform
  - **要求**: BSc / MSc CS / AI / IT / 相关, **0-1 yr 经验**, fluent English, 2026 September start
  - **Tech Stack**: Java 25, Spring 6, Reactor, RabbitMQ, Kafka, PostgreSQL, MongoDB, AWS, Docker, Kubernetes, Terraform, Vault
- **起薪 (base + bonus + equity)**:
  - **Tech Academy Grad total comp**: **€57K** (TechPays / Glassdoor entry-level avg) [来源: https://www.glassdoor.com/Salary/Picnic-Amsterdam-Salaries-EI_IE1040717.0,6_IL.7,16_IM1112.htm]
  - **Greater Amsterdam SWE range**: **€57.7K – €65.7K+** (Levels.fyi) [来源 (实际打开过): https://www.levels.fyi/companies/picnic/salaries/software-engineer/locations/greater-amsterdam-area]
  - **股权**: private (still pre-IPO, EQT / Hoogvliet 投资), equity 极少, 主要靠 base
  - 加 **25 天年假 + pension + free 周语言课程 + OpenUp 心理咨询 + 健身 + 健康午餐**
- **Sponsor 政策 (FT)**: NL Kennismigrant. **Tech Academy base ≈ €54K = €4,500/月**, 刚好满足 < 30 HSM 阈值 (€4,357). UvA master grad reduced HSM (€2,801) 完全无障碍.
- **申请窗口**: 2 个 intake/年 (March + September), 提前 4-6 个月开放
- **流程差异 vs intern**:
  - Tech Academy: 5 stages (CV → Phone → Interviews → **Assessment Day** → Offer)
  - Intern: 4 stages, 但 Assessment Day 强度类似

## 2. 签证与国际学生政策

- **是否支持非EU学生**: Yes
- **Intern vs FT sponsor 差异**:
  - Intern: 不办 (NL 在读 only)
  - FT (Tech Academy / Senior): 办 Kennismigrant + relocation package
- **已知 sponsorship 案例**:
  - workwithvisa.com 收录 Picnic + HSM sponsor + relocation 详情 [来源: https://workwithvisa.com/companies/picnic]
  - Picnic 官方 relocation 页 [来源 (实际打开过): https://jobs.picnic.app/en/relocation]: **flights for you + direct family + 1 month partner hotel + onboarding 期间住宿**
- **2026 阈值**: NL Kennismigrant <30 €4,357 / 30+ €5,942 / **NL master grad reduced €2,801**
- **30% ruling**: Tech Academy base 满足 + 海外招聘 + 居住 ≥150km 三条件可申

## 3. 面试流程

### Tech Academy (5 stages)

| 轮次 | 内容 | 时长 |
|---|---|---|
| 1 | CV screening | 1-3 天 |
| 2 | Phone screening (recruiter, English) | 30 min |
| 3 | Interview 1 (technical, Java basics + behavioral) | 60 min |
| 4 | **Assessment Day** (on-site Amsterdam): take-home presentation + culture fit + 多人小组案例 | 1 整天 |
| 5 | Offer | 1 周内 |

- 平均时长: **21.6 天** (Glassdoor)
- Java Developer 平均: 27 天

### Internship

类似 5 stages 但压缩, 通常 take-home + on-site day

## 6. 申请渠道与建议

- **官网投递**: https://jobs.picnic.app/en/
- **内推途径**: Picnic Tech 工程师在 LinkedIn 活跃, 直接 reach out; 也可通过 TU Delft / UvA / VU career events
- **简历/背景要求**:
  - **Java 项目深度** — 这是核心栈, 无 Java 经验大概率挂
  - 加分: Spring Boot, MongoDB / PostgreSQL, 分布式系统 (Kafka), 大学期间相关 internship
  - **Dutch 非必须**, English fluent
- **建议**:
  - **Tech Academy 是 Picnic entry-level 唯一稳定通道** — 其他 IC 岗几乎都要 5+ yr 经验, 即所谓 "Picnic 偏 senior 5yr+" 的来源
  - 准备 take-home + on-site 整日 — 这是 Picnic 招聘流程最重的部分, 不要低估
  - 关注 "scalable order routing" / "milk run optimization" 这类 Picnic 特有的 ops 算法话题 — 面试常考

## 7. 踩坑与社区评价

- **Glassdoor 3.3/5** (377 reviews) — 偏中游 [来源: https://www.glassdoor.com/Overview/Working-at-Picnic-EI_IE1040717.11,17.htm]
- **Pros**: 
  - "very straightforward process, everything clear"
  - "recruiters are very friendly and helpful"
  - 强工程文化 (Java 重度 + 良好 code review)
  - 完整 onboarding + mentor + buddy
- **Cons**:
  - 招聘流程**很长** — intern 投资回报率低
  - 偏 senior 招聘倾向, Tech Academy 是少数 entry 通道
  - Glassdoor 18.2% 正面 interview rating (相对低)
  - 难度 2.55/5 (中等)
- **薪资 vs Adyen/Booking**: Tech Academy €57K < Adyen Grad / Booking Compass Grad (€72K)
- **股权**: private, 不流动

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

- **Intern 可行性**: **零摩擦** — UvA 在读 + NL 学生签直接满足 graduation internship 要求 (NL 在读). 学生签 16h 学期 / 40h 假期 cover stage, Nuffic convention 走完, **公司无需办 work permit**
- **FT 可行性**: **零摩擦** — 走 zoekjaar 后申 Tech Academy / Junior Java, base €54K 远超 reduced HSM €2,801, 也超标准 HSM €4,357. relocation 已 cover (但 UvA 本地学生不需要)
- **预计摩擦**: **零** (两个路径都顺)
- **UvA 优势**:
  - Picnic HQ 在 Hoofddorp, 离 UvA 校区 ~20 km, 约 30-40 min 公交 / 单车不便, 但 Picnic 有 Amsterdam Centraal 班车
  - UvA / VU / TU Delft CS 校友在 Picnic 大量, 内推容易
  - **Tech Academy 是天然 fit** — UvA CS / AI master fresh grad 2026 sept 起步直接对接
- **建议申请时间窗**:
  - Tech Academy September 2026 intake: **2026 年 3-6 月**关注开放
  - Tech Academy March 2027 intake: **2026 年 10-12 月**关注开放
  - UX Graduation Internship: 配合 thesis schedule, 提前 4-6 个月申
