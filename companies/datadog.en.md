## 3. Interview Process

- **Total rounds**: 4-5 rounds, ~3-4 weeks [Source (verified opened): https://careers.datadoghq.com/candidate-experience/]
- **Each round format**:
  1. Recruiter screen (30-45 min) — introduce role + transparent list of subsequent steps
  2. **CoderPad online coding** — 2 Easy/Medium DSA, similar to HackerRank/LeetCode
  3. System design (Excalidraw, design secure / scalable systems)
  4. **In-person onsite (Paris/Madrid/Lisbon)** — half day: culture fit + tech presentation + system design
  5. Hiring manager / final
- **Question type breakdown**: DSA coding 40% / system design 30% / BQ 20% / domain (observability / distributed systems) 10%
- **Difficulty assessment**: Leans medium, practical-oriented (no competitive hard problems). Senior adds distributed systems depth
- **OA exists**: Yes — CoderPad async / live both possible, 2-3 algorithmic problems [Source (verified opened): https://ophyai.com/blog/company-guides/datadog-interview-guide]

## 7. Pitfalls and Community Feedback

- Process **very transparent**, recruiter proactively informing subsequent steps is a highlight
- Lisbon ~€92K median **far exceeds** Paris L1 €77K — same company location gap unusual (Lisbon because Datadog Lisbon primarily hires senior+, not because of city)
- September reqs open is the deadline — miss autumn cycle, wait until next year
- Datadog culture leans NY fast pace + frequent on-call, EU office slightly milder but still 24/7 ownership
- International student friendliness high (internship + full-time both sponsor)
