## 2. Role Profile

### 2.1 Backend Engineer Intern
- Tech stack: Java / Scala / Python / Go, Backend services mostly on GCP, event streams Kafka-centric, storage mixed Cassandra / BigQuery / PostgreSQL.
- Typical projects: playlist / recommendation / metadata / creator backend microservices, ad delivery backend, ETL data pipeline, internal platform tools.
- Key abilities: distributed systems basics, OO/functional design, Backstage (Spotify open source dev portal) related concepts bonus.

### 2.2 Machine Learning Engineer Intern
- Tech stack: Python, TensorFlow / PyTorch, Spark / Beam, Kubeflow, BigQuery, Vertex AI / in-house ML Platform.
- Typical projects: recommendation recall/ranking, content understanding (audio embedding), Search, Ads CTR/CVR, podcast discovery, A/B experimentation framework.
- Hiring blog notes internship "intentionally keeps exploratory" — specific projects evolve with team needs, emphasizing end-to-end thinking + fast AI learning.

### 2.3 Mobile (iOS / Android) Engineer Intern
- Tech stack: iOS mainly Swift (still some Objective-C), Android mainly Kotlin (some Java legacy); modular monorepo, Backstage engineering platform, Bazel / Gradle build.
- Typical projects: client feature surface (e.g. playlist, Home Feed, Now Playing), UI design system components, performance optimization, A/B framework integration.
- Key abilities: solid language fundamentals (runtime / memory / concurrency), UI architecture (MVVM / MVI / TCA-like), able to write real code in IDE and explain design trade-offs.

## 3. Interview Process

### 3.1 General Steps
1. **Recruiter Screen** (30 min) — background, motivation, feedback culture, visa / start time.
2. **Technical Phone Screen** (60 min) — 2 engineers, CV past project deep dive + 1 LeetCode Easy/Medium coding question.
3. **Final Loop** (4 rounds × 60 min, usually one/two day package):
   - Values (behavioral interview, strict scoring on Spotify values like ownership / collaboration / adaptability)
   - Algorithms & Data Structures (whiteboard/CoderPad medium questions)
   - System Design (intern usually high-level questions, e.g. design Playlist service, Recommendation data flow)
   - Case Study / IDE Interview (Mobile intern has IDE round: write code in Android Studio / Xcode real-machine style and share screen)
4. **Hiring Manager + Offer Discussion**

## 5. Visa & Cross-border Work

- **Sweden Stockholm**:
  - Non-EU enrolled students: if already hold *uppehållstillstånd för studier* (student residence permit), usually allowed full-time/part-time work during term, no hour limit; doing internship must ensure visa still valid.
  - Overseas applicants: Spotify explicitly does not sponsor work visa for interns; need to go via *Internship/Trainee permit* or student status converted to *Work permit*, reviewed by Migrationsverket, cycle 1-3 months, Spotify does not actively provide material support.
  - Full-time graduates: need Work permit, monthly salary must reach Sweden union collective agreement minimum (post-2024 ~SEK 28,480/month start, and Spotify actual offers far above this).
- **UK London**:
  - Student visa (Tier 4): ≤20h/week during term, full-time during vacation, compatible with 10-week summer internship.
  - Overseas applicants: Spotify doesn't initiate Skilled Worker Sponsor for interns; Graduate visa can cover 2 years post-graduation.
- **Cross-border/remote**: Spotify promotes "Work From Anywhere", but interns generally bound to specific office, cross-country remote extremely rare and requires legal/tax approval.

## 8. Key Risks / Tips

1. **Layoff shadow**: After 2023-2024 large layoffs, Stockholm intern spots shrunk, conversion opportunities decreased; prioritize Personalization / ML / Marketplace teams that are named as strategic direction.
2. **No visa sponsor**: Overseas applicants need to confirm in advance ability to legally work in Sweden / UK, recruiter repeatedly confirms during process.
3. **Behavioral interview weight high**: Values low score, even strong technical will be eliminated; prep STAR-format stories in advance, covering ownership / feedback / collaboration / adaptability.
4. **Process delays**: Being ghosted after phone screen is high-frequency Stockholm pain point, need to actively follow up, email recruiter every 1-2 weeks.
5. **Mobile IDE round difficulty**: Intern IDE round difficulty close to formal engineer, need to skillfully use IDE shortcuts, able to build mini Android / iOS app from scratch; completely different from "whiteboard algorithm" assessment direction.
6. **AI / GenAI internalization**: 2025 HR Blog reaffirms intern program transformation to AI era, CV with LLM / Agent / Embedding / vector retrieval projects has significant bonus.
