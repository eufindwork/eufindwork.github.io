## 3. Interview Process

> Galaxy: average 90-day hire cycle (Glassdoor data)

### Galaxy Graduate Programme Process (3 stages, Glassdoor proof)
1. **Recruiter Video Call** (30 min): introduce Galaxy program + assess alignment + candidate goal fit
2. **Galaxy Program Manager Interview** (60 min): understand candidate motivation, interest in process mining, business case discussion
3. **Senior Management Interview** (60 min): final fit + business questions + long-term development

### Full-time SWE Process
1. **Recruiter Screening** (30 min): role + Blue Card + location fit
2. **Hiring Manager** (60 min): past projects + tech stack (Java / Python / Kotlin / Go backend) depth
3. **Technical Coding** (60-90 min): algorithm + LeetCode Medium main; backend stack implementation
4. **System Design** (60 min): design process mining engine / event log processor / GenAI agent fabric
5. **Culture / Team Fit** (45 min): mission fit (data-driven enterprise transformation)

### Question Distribution
- Galaxy: Business case + motivation + product sense (60%) / industry understanding (process mining / ERP / SAP / consulting) (30%) / soft skills (10%)
- SWE full-time: Coding (40%) / System design (25%) / Java/Python/Kotlin backend (20%) / BQ + culture (15%)

### Difficulty Assessment
- Galaxy: Medium (not pure technical, heavy business sense + communication)
- SWE: Medium - Medium-Hard (LeetCode Medium main, some Hard, system design is mid+ key)

### OA
- Galaxy: No OA, direct interview
- SWE: Occasional HackerRank-style OA (Munich full-time IC1-IC3 process may appear)

### Process Speed
- Galaxy 90-day hire (Glassdoor data, slow) — multi-round program manager evaluation
- SWE full-time ~30-60 days

> Sources: Glassdoor Celonis Graduate Program Interview + interviewquery.com Celonis SWE Guide

## 7. Pitfalls & Community Reviews

### Process level
- **⚠️ Key pitfall: Intern / Werkstudent no visa** — students not in EU don't waste time applying, company explicitly rejects
- **Galaxy process 90 days**: Prepare for long wait + actively follow up (too long no contact loses talent)
- **Process mining industry understanding mandatory**: Not researching Celonis products + customer cases directly rejected

### Culture / business risk
- **Enterprise SaaS giant**: Process strict, not "move fast break things"; suitable for those who like structured + enterprise customer work
- **IPO candidate**: 2025-2026 media discussion of IPO, post-entry RSU upside potential large but has lock-up
- **GenAI transition period**: 2024-2025 push of GenAI agent fabric is company's new growth point, junior entry may catch this tech ramp-up wave
- **Munich vs Madrid vs London culture difference**: Munich strict + high salary + high prices; Madrid international + medium salary; London high prices + GTM heavy

### Known "pitfalls"
1. **Intern no visa (re-emphasized)**: Chinese non-EU students wanting summer internship at Celonis almost blocked, unless already studying in DE/ES/UK
2. **Galaxy rotation not guaranteed final placement**: After 12-24 months rotation, placement depends on program manager evaluation, want specific direction need to actively push
3. **Enterprise SaaS pace**: Decision chain long, code review strict, not suited for pure "research / exploration" personality
4. **Munich high prices**: Even IC1 base €69.8K, Munich actual disposable lower than Madrid / Berlin
5. **Galaxy average 90-day hire**: Don't treat Celonis as backup, process long + delay high

### International student friendliness
- **EU nationality**: Extremely friendly (full-time / Galaxy / intern all open)
- **Non-EU full-time / Galaxy candidates**: Extremely friendly — Blue Card public sponsor, Levels.fyi data clear, Galaxy is cohort channel
- **Non-EU students (wanting internship)**: ⚠️ Extremely unfriendly — explicit no visa
- **Chinese master / new graduate (studying in EU)**: Top friendly — via Werkstudent / Praktikum to Galaxy / full-time is clear path
