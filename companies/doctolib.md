## New Grad / Junior 岗位

- **常见岗位名**: Junior Software Engineer, Software Engineer (无独立 "Graduate" cohort 命名 — 直接走 Junior / L1 SWE), Apprentice → 全职转换, Working Student → Junior (Berlin)
- **欧洲地点**: Paris (主), Berlin (DE 团队约 200+ tech), Nantes (部分平台/data), 少量 Levallois
- **是否有独立 Graduate Programme**: **No** — 没有 cohort 命名 program. 主入口:
  - **Stage de fin d'études** (final-year M2 实习) → CDI 转正
  - **Apprenticeship / Alternance** (1-3 年学徒制) → CDI
  - **Working Student (Berlin)** 兼职 → Junior Engineer
- **非EU签证 (全职)**:
  - **France**: Passeport Talent – Salarié Qualifié €38,616/yr or French Tech Visa ~€43K/yr [来源 (实际打开过): https://www.eurotoptech.com/blog/visa-sponsorship-france-software-engineers-2026]; Doctolib 是 accredited employer

  - 工程岗薪资够触发两国 sponsor 通道, junior 边缘
- **薪资范围 (Levels.fyi + Glassdoor 实际)**:
  - **L2 SWE Berlin**: 中位 ~€61.3K TC (base ~€61K, equity ~$291, 无 bonus) [来源 (实际打开过): https://www.levels.fyi/companies/doctolib/salaries/software-engineer/levels/l2/locations/berlin-metropolitan-region]

## 3. 面试流程

- **总轮数**: 4-5 轮, 约 2 周走完 (2026 反馈) [来源 (实际打开过): https://www.glassdoor.com/Interview/Doctolib-Interview-Questions-E1018530.htm]
- **每轮形式**:
  1. Recruiter screen (30 min)
  2. **Take-home assignment** (基于 Doctolib 真实问题, 4-6 小时) — Doctolib 2024 已从 3 轮 live 砍到 1 轮 live + take-home [来源 (实际打开过): https://coderpad.io/case-study/how-doctolib-streamlined-its-hiring-process-to-save-hours-per-hire-and-keep-25-more-candidates-in-the-funnel/]
  3. Feature Building Interview (Doctolib 招牌, 现场扩展 take-home / 改 spec) [来源 (实际打开过): https://careers.doctolib.com/blog/hiring-advice/all-about-our-feature-building-interview/]
  4. System Design (Senior 才有, Junior 偶尔)
  5. Culture fit / Values (Doctolib values 强调 patient impact)
- **题型分布**: Take-home + feature building (60%) > System design (20%) > BQ (20%); 几乎不考算法 LeetCode hard
- **难度评估**: 中等. 偏工程实战 (Rails / TS), 不是算法竞赛风
- **OA 是否存在**: 通常无独立 OA, take-home 替代

## 7. 踩坑与社区评价

- 流程**快且透明** (2 周 vs 行业 4-6 周), 失败给 feedback 是亮点
- Feature building round 是杀手锏 — 不准备会被现场扩需求打懵
- Paris 与 Berlin 文化差: Paris 更 hierarchical, Berlin 更 flat
- Healthcare 受监管 → release 节奏比纯互联网慢, 适合追求长期稳定 + impact 的人
- 国际生友好度: 工程团队 25%+ 非本国籍, 实习需自己有 visa, 全职 sponsor 顺畅
