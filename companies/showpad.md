## 1. 基本信息

- **欧洲办公室**: Ghent (HQ, BE), London (UK), Munich (DE), 美洲 Chicago / Portland / SF
- **实习岗位类型**: 没有公开稳定的"intern" cohort, 工程岗主要是 mid–senior 招聘 (Backend / Frontend / Golang / SRE / Site Reliability); 学生岗一般通过 Ghent University / KU Leuven thesis 合作
- **实习时长**: thesis-style 3–6 个月 (case by case)
- **招聘周期**: Rolling, full-time 岗位常年开放, intern 看年级 + 学校 partnership

## New Grad / Junior 岗位

- **常见岗位名**: Software Engineer Frontend (mid-junior), Golang Software Engineer, Site Reliability Engineer (junior–senior range), Backend Developer
- **欧洲地点**: Ghent (主) / London / Munich
- **是否有独立 Graduate Programme**: **无** — 直接 hire to FT engineer ladder
- **非EU签证 (全职)**: Belgium **Single Permit** (combined work + residence) 或 **Highly Skilled Worker** 类别 (Flemish region 门槛 ~€48k brutto/年 — Ghent 在 Flanders, 适用), Showpad 在 Relocate.me 多岗位标 "visa sponsorships guaranteed"
- **薪资范围**: 公司不公开. Glassdoor Ghent SWE base €50k–€70k brutto, Senior €70k–€90k; SRE 类似; 比利时 net 因高税 (~45%+) 而打折严重
- **申请窗口**: Rolling
- **面试流程差异 vs 实习**: FT 走完整 4–5 轮 (recruiter → tech screen → 2x tech / system → manager / values); intern 通常 2–3 轮简化
- **录取竞争 / 国际生 friendliness**: ⭐⭐⭐⭐ — 比利时税高劝退部分申请者, 反而对国际生竞争压力小; "visa sponsorship guaranteed" 是难得的明文承诺

## 3. 面试流程

> **2026-06 retry**: Glassdoor Showpad Ghent SWE 面经 confirmed — typical 2-周 process: initial Engineering Lead screen → Codility test → engineer interview at team; 2022 流程更详: 1) recruiter screen (motivation) → 2) hiring manager (behavioral + team dynamics) → 3) tech interview (knowledge + open-ended + case study) → 4) panel interview [来源 (实际打开过): https://www.glassdoor.com/Interview/Showpad-Software-Engineer-Interview-Questions-EI_IE683910.0,7_KO8,25.htm]. 平均 SWE hiring 周期 ~20 天. Intern / junior 数据点仍少, 推断按 FT 简化版.

- **总轮数**: 4–5 轮 (FT)
- **每轮形式**:
  1. Recruiter screening (30 min, motivation / visa)
  2. Tech screen (1h coding, 通常 HackerRank 或 CoderPad)
  3. Take-home 或 live system design (Backend / SRE 必有, FE 给 component build task)
  4. Cross-functional / peer interview (1–2 个工程师)
  5. Manager / values (culture, growth mindset)
- **题型分布**: 算法 ~30% + system / infra design ~30% + role-specific (Go / React / TF / K8s) ~30% + BQ ~10%
- **难度评估**: LeetCode Medium 居多, system design 偏实际 (微服务 / 事件驱动 / 多租户 SaaS)
- **OA 是否存在**: Yes (HackerRank tech screen)

## 7. 踩坑与社区评价

- **比利时税高**: brutto–net 比是欧洲最差之一 (~45%–53% 边际税), nominal salary 看起来高但 take-home 弱于荷兰 / 爱尔兰
- **Ghent ≠ Brussels**: 城市小 (~25 万人), 中文社区极小, 英语日常 OK 但荷兰语 (Flemish) bureaucracy 文件痛苦
- **公司体量中等**: ~500 员工, 不要期待 FAANG 量级 comp; 优点是工程文化扁平, mid-junior 接触面广
- **AI 在做 sales coaching / call summarization**, 不是 frontier research, GenAI 求职者期待 alignment
- **国际生 friendliness**: ⭐⭐⭐⭐ visa 明文 + relocation full package; 但 long-term PR 比利时偏慢 (5 年 + B1 荷语)
