## 3. 面试流程

> Glassdoor: 难度 2.6/5, 50% positive, Summer Research Intern 流程约 2 个月

- **总轮数**: 全职 4-5 轮 / Intern 2-3 轮
- **每轮形式**:

### Summer Research Intern (Glassdoor 2023 实证 + 推断):
  1. **Online Application** → HR email
  2. **HR Round** (non-technical, 30 min): 学校 / 研究兴趣 / 时间表 / 动机
  3. **Technical Round** (60-90 min, with 2 team members): 物理 (量子力学基础 + 超导/transmon qubit / control theory / 量子算法) + 编程 (Python + Qiskit/Qrisp/PennyLane)
  4. **(可选) Research Talk** (30-60 min): 候选人介绍 thesis/research project

### 全职 SWE / QEC Engineer:
  1. **Recruiter Call** (30 min): role + location + visa fit
  2. **Hiring Manager** (60 min): past research/eng experience + 量子方向 alignment
  3. **Technical Coding** (60-90 min): Python 算法 + (针对 QEC) surface code / Pauli operators / stabilizer measurement 概念题
  4. **Research / Domain Deep Dive** (60-90 min): paper presentation 或 IQM 提供 case study 分析
  5. **Culture / Team Fit** (45 min): 跨国团队工作 / mission alignment

- **题型分布**: 量子物理 + control theory (30%) / Python + 量子 SDK (Qrisp/Qiskit) (30%) / 系统/算法 (20%) / Research / publications (10%) / Culture (10%)
- **难度评估**: Medium (Glassdoor 2.6/5); 物理 / QEC 概念题对非物理背景候选人是 hard, 算法题相对 standard
- **OA 是否存在**: 不存在标准化 OA; 但 take-home (QEC simulation / Qrisp circuit) 偶发

## 7. 踩坑与社区评价

### 流程层面
- **2 个月 intern 流程** — 比 FAANG intern 流程慢得多, 期望管理要做好
- **物理 + 编程双重门槛**: 纯 CS 背景 (无量子物理) 难度大; 反之纯物理 (无 Python/工程) 也难
- **Junior visa policy 不明确**: 官方只承诺 senior roles, junior 案例少, 申请前必须邮件 disclose
- **量子方向极 niche**: 公司业务理解门槛高 (transmon / QEC / 量子 advantage / NISQ era 限制), 非领域人很难自学到面试水平

### 文化 / 业务风险
- **量子计算商业化时间窗未定**: 行业整体 NISQ-era, fault-tolerant quantum computer 还需 5-10 年; IQM 商业收入主要来自硬件销售 + cloud (Resonance), 增长但路径长
- **欧洲 vs 美国 vs 中国 竞争**: IQM 是欧洲玩家代表 (vs IBM/Google/Microsoft 美国, vs Pasqal/Quantinuum 同欧洲, vs Origin/百度量子 中国)
- **Espoo 总部生活成本**: 不低 (FI 整体高税收), 但工程师 net 实际生活质量好

### 已知"坑"
1. **Junior visa 不保证**: 不要假设公司一定办, 接 offer 前确认
2. **多 site 协作**: Espoo + Munich + Paris 跨时区, async + travel 多
3. **量子算法 SWE 岗位需要物理 / 数学硬背景**: 纯 Python SWE 难以匹配
4. **Public salary 数据极少**: 谈薪缺基准, 行业内 networking 是唯一信息源
5. **公司 careers 域名变化**: meetiqm.com → iqm.tech (2025-2026), 注意书签 / referral link 失效

### 对国际学生友好度
- **EU / FI / DE / FR 国籍**: 极友好
- **量子物理 PhD (任何国籍)**: 友好, 官方 dozens of relocations 实证
- **中国籍 master / 新毕业**: 中等友好 — 已在 EU 念书优先, 不在 EU 难度大
- **纯 CS 背景**: 不友好 — 公司主力是量子专业人才, 普通 SWE 价值低
