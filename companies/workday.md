> **Language**: 中文 | [English](workday.en.md)

> 更新时间: 2026-06-01
> 一句话定位: US HCM/Finance ERP enterprise SaaS, Dublin EMEA HQ (~2000 员工), **Early Career intern/co-op + Graduate Program (UML/MVC 自研 framework)**, IE Critical Skills active sponsor, Java/Scala stack

---

## 1. 基本信息

- **欧洲办公室**: Dublin (EMEA HQ ⭐), London, Munich (DACH), Paris (France enterprise)
- **岗位类型**:
  - SWE (Java + Scala 平台 + Workday 自研 UML/MVC framework "Workday XpressO"), Data Eng, ML/Data Scientist
  - Applications Development Engineer (核心 Dublin 岗位 — 用 Workday 平台开发 modules)
  - Cloud Platform / Kubernetes / Infra
  - Support / Consulting / Implementation (较多但非 SWE)
- **招聘周期**: Workday Early Career Program **Sep 入职批次**, 申请 **前一年 Oct-Jan** (rolling); intern 通常 Summer 入职, 申请 1-3 月
- **重要截止**: Graduate Sep 2026 应已关闭; Sep 2027 cohort 申请 2026-10 → 2027-01 (历史规律)

---

## Intern 路径

- **岗位命名**: **Software Engineering Intern** / **Co-op** / **Internship (Dublin)** — 部分团队也招 Data Eng / Cloud Ops intern
- **时长**: 12-week Summer Intern, 或 6 mo Co-op (个别)
- **申请窗口 + deadline**: 2026 Summer 申请 2026-01 → 2026-03; 2027 Summer 申请 2026-10 → 2027-02 (rolling)
- **薪资 (stipend gross/月)**: **Dublin SWE Intern €2,800-3,500/月** (Glassdoor + 1point3acres 综合); 提供 housing stipend / 个别 cohort 包住
- **资格 (学历, 当地居留要求)**:
  - 在读 BSc / MSc CS 或相关
  - 优先 IE 大学合作, 但 EU + 国际生申请均受理 (Workday 在 LinkedIn 招聘范围广)
  - 英语流利
- **Sponsor 政策 (intern)**:
  - **< 90 days (Summer 12-week)**: IE Atypical Working Scheme, 免 permit, Workday 协助协议
  - **≥ 90 days (Co-op)**: 需 General Employment Permit, Workday 历史上 sponsor 个别情况但不保证
- **流程**: OA → recruiter → 1 tech (UML / coding) → final panel — 见 Section 3
- **转 FT 率**: Workday intern → FT conversion 高 (60-70%, Glassdoor 综合)

## NG (New Grad / Junior 全职) 路径

- **岗位命名**: **Graduate Applications Development Engineer** / **Software Engineer P1 (Associate)** / **Cloud Platform Engineer Grad**
- **是否有独立 cohort program**: ✅ 有 **Workday Early Career Program**, Sep 入职 cohort, 6-week onboarding + rotation
- **起薪 (base + bonus + equity)**:
  - **Dublin P1 (Graduate)**: median TC **€63,472** [Levels.fyi Workday P1 Dublin (实际打开过): https://www.levels.fyi/companies/workday/salaries/software-engineer/levels/p1/locations/greater-dublin-area]
  - **Dublin P2 (after 1-2 yrs)**: median TC **€93,539**
  - **Dublin P3 (Senior)**: median TC **€121,839**
  - **Dublin range overall**: €61.7K - €218K, median €123K [Levels.fyi Workday Dublin (实际打开过): https://www.levels.fyi/companies/workday/salaries/software-engineer/locations/greater-dublin-area]
  - 拆解 P1: base ~€55K + €4K bonus + €4-5K RSU/year ≈ €63K TC
- **Sponsor 政策 (FT)**: ✅ 明确 sponsor — IE Trusted Partner / Critical Skills active [Nextleveljobs IE Visa Sponsorship (实际打开过): https://nextleveljobs.eu/blog/visa-sponsorship/ie]; 走 **Critical Skills Employment Permit (CSEP)** 2-4 周
- **申请窗口**: Sep cohort 申请 Oct-Jan 前一年; 个别岗位 rolling 全年
- **流程差异 vs intern**: NG 加 1-2 轮 architecture + on-call expectation; intern 通常 3 轮

## 2. 签证与国际学生政策

- **是否支持非EU学生**: ✅ 是 (FT, IE Trusted Partner); intern 取决于时长
- **Intern vs FT sponsor 差异**:
  - **Intern < 90 days**: Atypical Working Scheme, 免 permit
  - **Intern ≥ 90 days**: 需 GEP, Workday 个案 sponsor
  - **FT**: CSEP, Workday cover 全部, 2-4 周
- **已知 sponsorship 案例**: Workday Dublin 大量国际工程师 (China/India/Brazil), LinkedIn + Reddit 多 case; Jointaro 2025-07 Dublin SWE interview report 含 sponsor 讨论 [Jointaro Workday Dublin (实际打开过): https://www.jointaro.com/interviews/companies/workday/experiences/software-engineer-dublin-dublin-july-29-2025-declined-offer-neutral-c5a1f065/]
- **2026 阈值**:
  - **Ireland CSEP**: **€40,904/年 (2026-03 起)** — Dublin P1 base €55K+ 远超
  - 配偶 Stamp 1G 工作
  - 21 个月后 Stamp 4 (PR 5 年)

## 3. 面试流程

| 阶段 | 内容 | 时长 |
|------|------|------|
| 1. OA / Recruiter call | TA, motivation, visa, comp expectation | 30 min |
| 2. Tech 1 - UML / Architecture | **UML diagramming 1-hour** (Workday 特色, 不是 LC) | 60 min |
| 3. Hire manager | 经验 + Workday Core Values (EE: Employees, Customer Service, Innovation, Integrity, Fun, Profitability) | 30-45 min |
| 4. Onsite / Virtual full loop | **5-hour 全套**: 30 min cultural + 45 min architecture (walk through projects) + 1-2 tech coding | 5 hours |

**Workday 独特之处**: 重 UML / OOP 设计建模 (Workday 平台是 metadata-driven, candidate 要展示能用 UML 表达 domain model). 不是传统 LeetCode 算法重度公司. [Glassdoor Workday Grad Apps Dev Interview (实际打开过): https://www.glassdoor.com/Interview/Workday-Graduate-Applications-Development-Engineer-Interview-Questions-EI_IE197851.0,7_KO8,50.htm]

平均周期 **4 周** (部分 case 2 个月)

## 7. 踩坑与社区评价

- **UML 面试 trap**: 很多 candidate 把 Workday 当 LC 公司刷题, 但实际重 OO design; **必须刷 OO design 题目** (Grokking the OOD interview)
- **自研 framework 学习曲线**: Workday XpressO / metadata-driven, 入职后 ~3-6 个月才能完全 productive; 部分人觉得 transferable skill 受限
- **Dublin office 规模**: ~2000 员工, 是 Dublin 第三大 tech employer (after Google/Microsoft), 中国/印度同事社群非常活跃
- **WLB 评价**: Glassdoor 4.0+/5, "great salary, benefits, employee programs"; 但部分团队跨时区 (Pleasanton CA HQ) 早会
- **Layoffs**: 2024 Q1 layoff ~3% (~170 人 globally), Dublin 受影响小; 2025 平稳
- **Compensation 稳定但非顶薪**: Dublin P1 ~€63K vs Google Dublin L3 ~€105K, 但 sponsor 实操比 Google 容易
- **CSEP 后 Stamp 4 路径**: 21 个月后申 Stamp 4, 5 年 PR — IE 是 EU 内 PR 路径最短国家之一

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

### Intern 可行性
- **Summer Intern Dublin (12 wk, < 90 days)**: ✅ 中-高可行 — IE Atypical Working Scheme 免 permit, 与 HubSpot 路径一致. **Workday 对 UML 准备充分的 candidate 友好, 国际生招聘历史活跃**
- **Co-op (6 mo)**: ⚠️ 高摩擦, > 90 days 需 GEP
- **NL 期间申请**: 完全可以 — Summer Intern 与 UvA 暑假完美对齐 (Jun-Aug)

### FT 可行性
- **毕业拿 Grad Apps Dev Dublin**: ✅ 高度可行 — Workday Trusted Partner / CSEP active, P1 起薪 €55K+ 满足阈值, 流程 2-4 周
- **NL zoekjaar 矛盾**: Workday 在 NL **无 office**, user 需放弃 zoekjaar; 但 CSEP Stamp 4 5 年 PR 比 NL Kennismigrant 5 年 PR 更宽松 (Stamp 4 配偶完整工作权 + 21 月加速)

### 预计摩擦
- Summer Intern Dublin: **低**
- FT Dublin: **低**

### 建议
- **首选策略**: **Sep 2027 Graduate cohort** (申请 2026-10 第一周)
  - 准备: 2026 暑假刷 OOD 题 (Grokking the OOD), Java/Scala 项目作品集
  - UML 是核心区分点, 不要把 Workday 当 LC 公司
- **第二选**: **Summer 2027 Intern Dublin** (申请 2027-01, 走 Atypical Working Scheme) → 转 FT
- **薪资期望**: Dublin P1 ~€63K TC, 低于 Big Tech Dublin (Google L3 ~€105K), 但 sponsor 实操 + 转正率 + Stamp 4 PR 路径补偿
- **替代**: 类似 enterprise SaaS, **Salesforce Dublin** 也是 Trusted Partner active; 但 Workday Early Career Program 更结构化
