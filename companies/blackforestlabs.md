## 2. 签证与国际学生政策

**核心结论: Yes, sponsor visas, BUT case-by-case (not guaranteed every role/candidate)**

| 维度 | 政策 |
|------|------|
| 是否支持非EU学生 | **Conditional Yes** — 官方原话 "sponsors visas" + "every effort to get you into US or Germany"; 但 "aren't able to sponsor every role and every candidate" [来源 (实际打开过): https://bfl.ai/careers] |
| 是否要求 work auth | **No** (若公司决定 sponsor) — 公司全办 Blue Card / H-1B / O-1 |
| Intern 是否办 visa | **N/A — 不招 intern** |
| 已知 sponsorship 案例 | 官方明文承诺; 团队公开 LinkedIn 显示 Freiburg site 有非欧国籍工程师; 无中国籍直接公开实证 |
| Relocation | 官方明文 "relocation bonus and support to make your move to Freiburg or San Francisco smooth"; 具体金额未公开 (业内同档 €5K-€15K lump sum 估) |
| Freiburg vs SF | 两边都 sponsor; Freiburg 走 Blue Card (流程 6-12 周); SF 走 H-1B (受 lottery 限制) 或 O-1 (顶会一作可走) |

**对中国留学生的可行路径**:
1. **唯一可行通道**: PhD 顶会一作 (NeurIPS / ICML / ICLR / CVPR / SIGGRAPH) + 投 MTS Freiburg
2. **加分项**:
   - Latent / Stable Diffusion / FLUX 相关开源贡献 (HuggingFace diffusers / ComfyUI / CivitAI ecosystem)
   - 训练 / 微调过 diffusion model (DDPM / SDXL / FLUX / SD3 系列)
   - VLM / multimodal foundation model 经验
3. **不可行**: Bachelor / Master 在读 / 0 publication — 不要浪费时间投, 公司明确 senior only
4. **SF 替代**: 走 O-1 visa (extraordinary ability), 一作顶会论文是关键证据

## 3. 面试流程

> **2026-06 retry**: BFL 官方 careers 仍无明文面经, 但 careers + a16z jobs 列出 hiring benefits: visa sponsor 明文 (DE 或 US relocation), $600/yr professional dev stipend [来源 (实际打开过): https://bfl.ai/careers + https://jobs.a16z.com/jobs/black-forest-labs]. Glassdoor / Taro 上仍**无公开 SWE 面经条目**; 以下流程基于行业同档 GenAI lab (Mistral / Cohere / Anthropic Research / DeepMind Research) 推断, 二次核实建议申前 LinkedIn DM 现 BFL employee.

- **总轮数**: ~5-6 轮 (MTS senior research / engineering 标准)
- **每轮形式** (推断):
  1. **Recruiter Call** (30 min): role + visa + location fit
  2. **Hiring Manager / Research Lead** (60 min): publications + 研究方向 alignment
  3. **Paper Deep Dive** (60-90 min): 候选人 first-author paper presentation + Q&A (顶会一作必备)
  4. **Coding** (60-90 min): PyTorch + diffusion / transformer 实现题; 可能现场写训练 loop / sampling loop
  5. **System Design / Infra** (60 min): 分布式训练 / large-scale data infra (针对 Infra MTS)
  6. **Founder / Leadership Chat** (45 min): mission fit + 长期愿景 (与 Robin Rombach / Andreas Blattmann 等 co-founder)
- **题型分布**: Research deep dive (40%) / Coding (PyTorch + diffusion implementation) (30%) / System design (20%) / Culture / mission (10%)
- **难度评估**: 顶尖难度 — 对标 DeepMind Research / OpenAI / Anthropic 入职门槛
- **OA 是否存在**: 无传统 OA; 但可能要求 take-home (e.g. 实现一个 mini diffusion training script)

## 7. 踩坑与社区评价

### 流程层面
- **公开数据极度稀疏**: 期望管理要做好, 不要预期 1 周内有反馈; 流程可能 4-8 周
- **"every effort but not guaranteed"**: visa sponsorship 不是 100%, 申请前要主动确认; 拿到 offer 后 visa 流程仍有 1-2 月 delay 可能
- **Mission/culture fit 是 hard filter**: BFL 强调"open source" (FLUX [dev] 开源) + "scientific rigor"; 纯商业 fine-tune farm 背景可能不匹配

### 文化 / 业务风险
- **赛道竞争激烈**: Stable Diffusion 3 (Stability AI), DALL-E 3 / Sora (OpenAI), Midjourney, Ideogram, Imagen (Google), Aurora (xAI), Recraft 等同台; FLUX 目前 quality SOTA 但 moat 在快速侵蚀
- **Stability AI 前车之鉴**: 原 Stability AI 经营崩盘 (核心团队 2024 出走创办 BFL), 警示 GenAI 创业 burn rate 风险; BFL 团队声誉强但商业模式 (API + 企业 license) 仍在验证
- **Freiburg 地理位置偏远**: 不是慕尼黑/柏林大城市, 配套不如; 但大学城 (University of Freiburg) 生活成本低 + 自然环境好
- **In-person bias**: 官方 "We prefer to be in-office" — 远程几乎不接受

### 已知"坑"
1. **Levels.fyi 无独立数据**: 谈薪缺基准, 容易被 lowball
2. **MTS 都是 senior 岗**: 不要因为是 startup 期待 "junior friendly" — 公司明确招资深 PhD
3. **Visa case-by-case**: 不保证, final 前必须 disclose 国籍 + visa status
4. **Freiburg 不是 Munich/Berlin**: 配偶就业 / 国际学校 / 大都市便利 都不如; 适合纯做研究人 / 自然爱好者
5. **SF 走 H-1B**: 2026 H-1B lottery 中签率 ~25%, 不保证一次成

### 对国际学生友好度
- **EU 国籍**: 极友好, Freiburg 直接入职
- **顶会一作 + 顶尖 PhD**: 友好, 走 O-1 (US) 或 Blue Card (DE)
- **新毕业 master / undergrad**: 几乎不友好 — 不要尝试, 公司无 junior pipeline
- **中国籍**: 顶会一作 PhD 路径可行 (Freiburg Blue Card), 否则封死
