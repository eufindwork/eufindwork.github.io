## Intern 路径

- **岗位命名**:
  - **Data Engineer Intern** [来源 (实际打开过): https://supercell.com/en/careers/data-engineer-intern/7a4a0a38-18e1-4c89-8bd4-7a0f0fb0dc59/]
  - **Data Analyst Intern**
  - **Analyst Intern** (general business / strategy)
  - Investments Intern, Event/Office Ops Intern (后者**不 sponsor relocation**, 明确说明)
- **时长**: **6-9 mo** 按 project
- **申请窗口 + deadline**: **2026-04-26 (deadline)** → 2026-08-24 (start)
- **薪资 (stipend gross/月)**: Levels.fyi summer 2023 报 **$19.38/hr = ~$3,359/月 ≈ €3,100/月** (intern range)
- **资格 (学历, 当地居留要求)**: 在读本/硕 (CS / Data / Stats); **default Finland 居留**
- **Sponsor 政策 (intern)**:
  - **EU/ETA 候选**: relocation 支持 (含 Relocation Team + family/pet 协助)
  - **非 EU 候选**: 仅 "truly exceptional" 候选会被 sponsor (案例较少)
  - **Event / Office Ops Intern**: **不** 给 relocation, 必须本地候选
- **流程**: Application → recruiter → take-home (Data 类) → technical / case → 2-3 轮 onsite
- **转 FT 率**: 高 — Supercell intern → FT 是核心 pipeline, 多 senior 都从 intern 出身

## NG (New Grad / Junior 全职) 路径

- **岗位命名**:
  - 无独立 grad cohort
  - Game Programmer / Data Engineer / Game Designer / Producer — 各 cell 独立 hire, 偏 senior
- **是否有独立 cohort program**: ❌ 无 (intern → FT pipeline 替代)
- **起薪 (base + bonus + equity)**:
  - Levels.fyi Supercell 样本极少 (公司隐私 + cell 自治)
  - Glassdoor Helsinki 数据点估算: SWE €70-90K base + 大年终 bonus + Supercell internal equity (dividends + refresh + liquidity)
  - 官方 [https://supercell.com/en/news/compensation-benefits/] 明文 "compensation includes annual bonus + equity with dividends, refresh grants, and liquidity" — equity 流动性是 Supercell 独有福利
  - Helsinki SWE 整体市场: 中位 €54.6K-97.3K, senior €71.7K-107K
- **Sponsor 政策 (FT)**:
  - ✅ 官方 sponsor + relocation 强 (Relocation Team 协助 family / pet)
  - Finland Blue Card €47,244 阈值, FT entry 必 cover
- **申请窗口**: 全年 rolling, 但 req 数量少 (公司 ~300 人精英 model)
- **流程差异 vs intern**: FT 更多 cell fit / culture rounds, 5-6 轮; 重 "small team big impact" 文化匹配

## 3. 面试流程

1. Application (CV + cover letter, Supercell 很重 cover letter)
2. Recruiter screen (30 min, 文化 fit 重)
3. Take-home (Data / Eng 类必备, 复杂度高)
4. Technical interview (60-90 min)
5. Cell visit / onsite (2-3 轮 + 与 cell 成员吃饭)
6. Offer (Supercell offer 决策 cell-level, 不走集中委员会)

> 多源 Glassdoor / Reddit: Supercell 招聘流程 "慢但深", cell 文化 fit 决定性强.

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

- **核心 trade-off**: 已在 NL 持学生签 → 选 Supercell 意味着 **放弃 NL zoekjaar (€2,801 reduced HSM)**, 换 Finland Blue Card / specialist permit
- **Intern 可行性**:
  - **非 EU → 低-中** — Supercell 明文 EU/ETA 优先; 除非你是 "truly exceptional" (ACM/IOI 金/顶 OSS), 否则别投
  - 推荐策略: 若你符合 "truly exceptional" 信号 → 强化 cover letter + 投 Data Engineer Intern (2026 deadline 已过, 等 2027 cohort)
- **FT 可行性**:
  - **Helsinki Data Engineer / SWE → 高** — sponsor 明文, 起薪 €80-100K 远超 Finland Blue Card 阈值
  - 难度在于 req 数量极少 + cell 文化 fit
- **预计摩擦**:
  - Intern → 高 (非 EU 默认拒)
  - FT → 中 (sponsor 简单, 但 cell fit + 极低录用率 是 bottleneck)
- **UvA 优势失效**: 这家不在 NL, 无 zoekjaar 福利
- **建议**:
  - **若 user 是 ML/Data + 顶尖学术背景 + 想做 gaming → Supercell 是 7 家中文化 + 薪资最强但最难进的; 值得作为 stretch target**
  - **若不符合 "truly exceptional" 信号 → 转投 Wolt FT 或 King Kingternship (Sweden) 更现实**
  - Intern 路径仅 EU/ETA + 顶尖背景才值得尝试
