## Intern Path

- **Role naming**: "Software Engineering Intern" / "Cloud Security Intern" / "Field Intern" — usually attached to London or Tel Aviv
- **Duration**: Summer 12 weeks (June-August) or 6-12 months placement
- **Application window**: opens October, rolling intake, Dec-Feb concentrated interviews, Apr-May offers
- **Salary (stipend gross/month GBP)**: ~£3,000-£3,500/month (London intern, equivalent to entry-level prorated)
- **Eligibility**: enrolled undergraduate / master's CS / Cybersec; preferred already in UK students (Tier 4)
- **Sponsor policy (intern)**:
  - Official emerging talent page: "Snyk can sponsor visas and provides a £5,000 tax free relocation package" — but **this mainly targets FT grad**, intern path less sponsored
  - UK Student visa (Tier 4) holders can work full-time in summer — recommended path
  - NL student visa cannot directly intern in UK; Snyk has no NL office (remote contract case-by-case)
- **Process**: Recruiter screen → take-home PR review (24-48h) → 1 tech discussion → behavioral; total ~3 weeks
- **FT conversion rate**: high (~50-60%), Snyk emerging talent designed as funnel

  - "Associate Security Researcher" — London
  - "Customer Solutions Engineer (Grad)" — London

- **Starting salary (base + bonus + RSU)**:

  - **London Median SWE TC**: £137,095 (incl. RSU / cash equity, ~3x Darktrace) [Source (verified opened): https://www.levels.fyi/en-gb/companies/snyk/salaries/software-engineer/locations/london-metro-area]
  - **Senior SWE London median TC**: £149,913
  - Grad / new hire band not easy to hit £137K directly — Levels.fyi sample leans SWE II/III, estimated grad TC ~£75-95K (base + 10% bonus + £25-40K phantom stock / pre-IPO RSU)
  - £5K relocation tax-free [official careers page]
- **Sponsor policy (FT)**:
  - Snyk Limited holds UK Skilled Worker license, A-rated [Source (verified opened): https://immigrationgpt.co.uk/company/snyk-limited]
  - Officially states "keen to support candidates who require visa sponsorship" [snyk.io/careers verified opened]
  - SW threshold £41,700 — London grad base £65K+ far exceeds, **passes safely**
  - SOC 2134 Software Developer going rate ~£49,400 — also passes
  - Not in GradSignal 2026 top 20 list (that list leans large companies), but huntukvisasponsors / immigrationgpt directly verifies license
- **Application window**: continuously open, Sep-Feb concentrated grad hire
- **Process differences vs intern**: one more round of system design + cross-team interview, total 4-5 rounds

## 2. Visa & International Student Policy

- **2026 UK thresholds**: Skilled Worker £41,700, NEC £33,400, SOC 2134 Software Developer going rate ~£49,400
- **Snyk Limited** Skilled Worker license verified — holds and active [immigrationgpt.co.uk/company/snyk-limited verified opened]
- **Official policy language**: "Snyk can sponsor visas and provides a £5,000 tax free relocation package to help with your move to London" — **explicitly written on careers page**, this counts as upper-tier friendly among UK companies
- **NL student visa user path**:
  - **Don't take intern path** (UK doesn't open intern sponsor, NL remote contract case-by-case)
  - **Apply grad SWE in London directly**, use £65K+ base for SW visa
  - Alternative: some remote-EU roles write "any EU location" — can ask NL remote (Snyk has few employees in NL)
- **GBM path**: not applicable (Snyk has no NL/DE legal entity as intra-company transfer origin)

## 3. Interview Process

| Stage | Content | Duration |
|------|------|------|
| 1. Recruiter screen | Role fit, visa status, motivation | 30 min |
| 2. Take-home PR review prep | Receive GitHub PR (NPM dependency tree), 24-48h prep | 24-48h |
| 3. Technical discussion | 45 min with senior eng, walk through PR + implement fix (recursive dependency bug) | 45 min |
| 4. Hiring manager + system design | Design SAST scanner subsystem | 60 min |
| 5. Cross-team / values | Behavioral, Snyk values (One Team, Care Deeply) | 45 min |

Total cycle 5-8 weeks [Source (verified opened): https://snyk.io/blog/your-engineering-interview-snyk/]

**Key differentiator**: **No LeetCode-style live coding** — entirely PR review + system design [Glassdoor + official blog consistent]

## 6. Application Channels & Advice

- **Official**: https://snyk.io/careers/ — direct "all-jobs" page: https://snyk.io/careers/all-jobs/
- **Emerging Talent**: page filter "Early Career"
- **Greenhouse**: many direct links, can subscribe alert
- **Advice**:
  - Snyk hires dev-first thinking — CV emphasizing your **debugging others' code / open source contribution / CVE submission** is more useful than LeetCode grind
  - When applying **directly write visa status + whether £5K relocation needed** — Snyk recruiter will actively route to sponsor pipeline
  - Take-home PR review prep: read Snyk OSS repos in advance (snyk/cli, snyk/snyk) to get familiar with codebase style
  - **Don't do LeetCode prep** — 100% waste of time; instead read npm dependency resolution, SAST basics, OWASP top 10
  - **Prefer London Associate SWE / SWE I**, skip senior band (difficulty gap large)

## 7. Pitfalls & Community Reviews

- **Advantages**:
  - WLB actually good (London team ~40h/week)
  - Tech stack modern (TypeScript/Go), not legacy C++ like Darktrace
  - Pre-IPO equity is a lottery — 2026 IPO rumored (but postponed once in 2024)
  - Glassdoor score 4.0/5
- **Disadvantages**:
  - Hiring timeline slow (5-8 weeks), easily ghosted when competing offers with Big Tech
  - Tel Aviv is R&D headquarters, London actually EMEA sales + few core eng
  - Remote-EU policy tightening (since 2024 most roles require in-office 3 days)
- **Layoffs**: 2024-01 laid off 14% (~200 people), 2024-11 another round — pre-IPO cash burn control, affects new hire confidence

## 8. For UvA Students (NL Student Visa) — Specific Assessment ⭐

- **Core trade-off**: This is the **most realistic UK option for NL students** in this list — because:
  - Officially explicit visa sponsor + £5K relocation
  - Grad base £65K+ far above £41,700 SW threshold, no need to gamble on NEC discount
  - Mainstream tech stack (TS/Go), short conversion period
- **Intern feasibility**: **Low-medium**
  - UK intern sponsor still rare — even Snyk prefers UK students
  - Exception: if you can get Snyk Tel Aviv intern (Israeli intern visa, but far away high cost)
  - **Advice**: skip intern, apply grad directly
- **FT feasibility**: **Medium-high** ⭐
  - SW £41,700 threshold: London base £65K+ safely passes
  - SOC 2134 going rate £49,400: still passes
  - Official sponsor policy explicit + £5K relocation = strong signal
  - Levels.fyi London median TC £137K (incl. pre-IPO equity)
- **Alternative NL path**:
  - Snyk no NL office, NL remote contracts extremely rare, **don't expect**
- **Expected friction**: **Medium** (lower than Darktrace / Sophos / Ocado, higher than pure NL companies)
- **Advice**:
  - **Priority = #1 in this list** (among UK companies)
  - When applying write directly in cover letter: "I'm an UvA Master's student, will need UK Skilled Worker sponsorship + relocation from NL. Aware of Snyk's published support."
  - Sep-Oct grad cohort window optimal
  - Parallel apply: Datadog (London, outside this list), Stripe Dublin (bypass UK)
