## Intern 路径

- **岗位命名**: 无正式 cohort intern program; 偶发 thesis worker / summer trainee (主要在 Helsinki, 走当地大学渠道, Aalto / U Helsinki)
- **时长**: thesis 6 mo 居多
- **申请窗口 + deadline**: 不公开, 通过校园 fair / careers@aiven.io 询问
- **薪资 (stipend gross/月)**: 未公开; Helsinki tech intern 市场行情 €2,500-3,500/月. Aiven FT 中位 €55,483 → intern 按 50-60% 折算 ~€2,800/月合理 [来源 (实际打开过): https://www.levels.fyi/companies/aiven/salaries/software-engineer/locations/greater-helsinki]. FT employee 提到公司每年 €2,000 personal learning stipend (Glassdoor review)
- **资格 (学历, 当地居留要求)**: MSc CS / Data Eng 在读, **默认要求已有 FI 居留 / 工签**
- **Sponsor 政策 (intern)**: ❌ intern **不 sponsor** (与 Wolt / Supercell 同 model); 跨欧实习不可行
- **流程**: 校园招聘 / 内推为主
- **转 FT 率**: 未公开

## NG (New Grad / Junior 全职) 路径

- **岗位命名**: 罕见独立 grad cohort; 主流是 "Software Engineer" / "Site Reliability Engineer" / "Backend Engineer" (mid-level), 偶发 Junior
- **是否有独立 cohort program**: ❌ 无
- **起薪 (base + bonus + equity)**:
  - Helsinki SWE 中位 **€55.5K total comp / 年** (range €43.9K-€55.5K+), 最高 reported €136,675 [来源 (实际打开过): https://www.levels.fyi/companies/aiven/salaries/software-engineer/locations/greater-helsinki]
  - Berlin 数据 Levels.fyi 样本少, 类比 Helsinki + 12-15% Berlin tech premium
  - equity: late-stage RSU / pre-IPO option (具体未公开)
- **Sponsor 政策 (FT)**:
  - **Berlin JD 明文 "full relocation assistance and visa sponsorships are guaranteed"** [来源 (实际打开过): https://relocate.me/germany/berlin/aiven/site-reliability-engineer-6242] → DE Blue Card 短缺 €45,934 阈值, IT 含
  - **Helsinki sponsor 政策未在 careers page 公开**, 但 LinkedIn jobs Finland 12 个 open req 多为 senior, 类比 Finnish tech market 中型公司 sponsor 率 ~50% (Wolt / Supercell 都 sponsor 全职), Aiven 大概率类似
- **申请窗口**: 全年 rolling
- **流程差异 vs intern**: 全职 4-6 轮 (recruiter → hiring manager → 2x technical → system design → values fit), intern 通常 2-3 轮

## 3. 面试流程

1. Recruiter screen (30 min)
2. Hiring manager call (45 min, role context + 经验深挖)
3. Technical screen (Live coding, Python/Java/Go, 60 min)
4. System design (SRE / Backend, 60 min) — Kafka / Postgres internals 加分
5. Values / culture fit (45 min, "Curiosity, Care, Together" 三 values)
6. Reference check + Offer

> 多源 Glassdoor / LinkedIn alumni 评 "tech bar 高, 但 process 透明; 招的多是 mid-senior, Junior 名额少".

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

- **核心 trade-off**: 已在 NL 持学生签 → 选 Aiven 意味着 **放弃 NL zoekjaar (€2,801 reduced HSM)**, 换 DE Blue Card (Berlin) 或 Finland Blue Card (Helsinki)
- **Intern 可行性**: ❌ **几乎不可行** — 无正式 intern program, thesis worker 默认要求当地工签, 跨欧 intern 不 sponsor
- **FT 可行性**:
  - **Berlin SRE/Backend → 高** — DE Blue Card 短缺职业 €45,934, JD 明文 guaranteed; Aiven SRE 起薪应 cover
  - **Helsinki → 中** — Finland Blue Card €47,244, Aiven Helsinki median €55K cover; 但 sponsor 政策 JD 未公开, 需面试 confirm
- **预计摩擦**:
  - Berlin → 低 (JD 明文 + relocation 整套)
  - Helsinki → 中 (FI 工签 + 北欧搬家)
- **UvA 优势失效**: 这家不在 NL, 无 zoekjaar 福利, 需重新做 visa
- **建议**:
  - 若是非 EU + 想做 OSS 数据基建 → **Berlin 投; sponsor 是 7 家中信号最强的一个**
  - 若想留北欧 → Helsinki 是 fallback, 但需主动问 sponsor
  - 若 user 想继续 NL 路径 → 此公司**不应优先**, JetBrains AMS / Booking / Nebius 更对口
