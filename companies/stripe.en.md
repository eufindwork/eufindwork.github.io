## 2. Visa and International Student Policy

- **Supports non-EU students**: **Yes** — Stripe is listed as Ireland CSEP **Trusted Partner** (alongside Google / Meta / Microsoft / Apple / Datadog / HubSpot / Salesforce / LinkedIn, priority 2–4 weeks vs standard 8–12 weeks) [Source (verified opened): https://www.eurotoptech.com/blog/visa-sponsorship-ireland-software-engineers-2026]
- **Requires existing work permit**: No — Stripe handles full CSEP process; **spouse Stamp 1G** applied simultaneously
- **Known sponsorship cases**:
  - Stripe Dublin historically stable sponsor for Chinese / Indian / US domestic new grads [https://nextleveljobs.eu/blog/visa-sponsorship/ie]
  - 1point3acres multiple posts confirm Chinese new grads landing smoothly via CSEP in Dublin [https://www.1point3acres.com/interview/company/stripe]
  - TCD intern → FT is standard pipeline
- **CSEP key numbers (2026)**: threshold €40,904; Trusted Partner processing 2–4 weeks; interns go via Atypical Working Scheme (CSEP exempt within 90 days)

## 3. Interview Process

- **Total rounds**: 5 rounds FT / 3–4 rounds intern
- **Each round format**:
  1. **HackerRank OA** (60 min, **1 question split into 3 sub-tasks**, progressive difficulty)
  2. Recruiter call (~20 min)
  3. **Technical phone screen** (CoderPad, integration / API design questions)
  4. **Onsite virtual loop** (4–5 rounds): 2x coding (Stripe-style "build a system in 90 min" — real business scenarios, not pure LC), 1x bug squash / integration, 1x system design (FT) / project deep-dive (intern), 1x BQ
  5. Hiring committee review
- **Question type distribution**: **Real business coding** ~60% (Stripe famous "build a billing system / rate limiter / idempotency layer" style) + system design ~20% + BQ ~20%
- **Difficulty assessment**: "Stripe-style" questions uncommon on LC — engineering-oriented, emphasizing ship-able code, not tricks; Glassdoor difficulty 3.2/5, 62% pass rate (above company average)
- **OA exists**: Yes, HackerRank 60 min, 1 question 3 progressive subtasks
- **Total duration**: New Grad average 22 days, overall 26 days

## 7. Pitfalls and Community Reviews

- **Stripe-style questions ≠ LeetCode**: don't just grind algorithms; practice "build a real system in 90 min" — search "Stripe interview problems" on github or join Taro
- **OA looks simple, actually has traps**: 60 min 1 question 3 subtasks, last 2 subtasks tight on time, design needs foresight (hardcoding sub-task 1 will block sub-task 3)
- **Dublin is a real eng hub**, not commercial — don't apply to wrong team (London also has eng but commercial dominates)
- **Trusted Partner advantage is real**: Chinese / Indian new grads September onboarding optimal; spouse Stamp 1G simultaneously
- **Stripe AI team**: hiring ML / Applied AI / Risk ML, 2026 hiring notably ramped up (Stripe is building payments fraud LLM models)
- **International student friendliness**: ⭐⭐⭐⭐⭐ — Chinese newcomer Dublin onboarding reports overall positive (1point3acres / 1mu3fd)
- **Common failure points**: bug squash round without reading doc / Stripe API usage (review key concepts at https://docs.stripe.com before interview)
