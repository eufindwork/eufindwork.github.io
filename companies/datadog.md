## 3. 面试流程

- **总轮数**: 4-5 轮, ~3-4 周 [来源 (实际打开过): https://careers.datadoghq.com/candidate-experience/]
- **每轮形式**:
  1. Recruiter screen (30-45 min) — 介绍角色 + 透明列后续步骤
  2. **CoderPad 在线 coding** — 2 道 Easy/Medium DSA, 类似 HackerRank/LeetCode
  3. System design (Excalidraw, 设计安全 / scalable 系统)
  4. **In-person onsite (Paris/Madrid/Lisbon)** — 半天: culture fit + tech presentation + system design
  5. Hiring manager / final
- **题型分布**: DSA coding 40% / system design 30% / BQ 20% / domain (observability / distributed systems) 10%
- **难度评估**: 偏 medium, 实用导向 (不考竞赛 hard). Senior 加 distributed systems 深度
- **OA 是否存在**: 是 — CoderPad 异步 / live 都可能, 2-3 algorithmic problems [来源 (实际打开过): https://ophyai.com/blog/company-guides/datadog-interview-guide]

## 6. 申请渠道与建议

- **官网投递**: https://careers.datadoghq.com/ (filter "Early Career" + location)
- **关键时机**: **9 月放 reqs**, 不要晚于 11 月投; intern + new grad 都 rolling 但秋招最稠密
- **内推途径**: Datadog 工程师 LinkedIn / 校友活动 (Paris X / Centrale / Polytechnique / Saclay 校友); 内推有 referral bonus
- **简历/背景要求**: CS / SE degree (or equivalent); 至少 1 段实习; 强系统/分布式背景加分; 英语 mandatory (CV 必须英文)

## 7. 踩坑与社区评价

- 流程**非常透明**, recruiter 主动告知后续步骤是亮点
- Lisbon ~€92K 中位**远超** Paris L1 €77K — 同公司 location gap 反常 (Lisbon 是因为 Datadog Lisbon 主要招 senior+, 不是因为城市)
- 9 月开 reqs 是死线 — 错过秋招要等到下一年
- Datadog 文化偏 NY 节奏快 + on-call 频繁, EU office 略缓和但仍 24/7 ownership
- 国际生友好度高 (实习 + 全职都 sponsor)
