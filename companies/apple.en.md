## 2. Visa & International Student Policy

- **UK (London / Cambridge)**:
  - Apple UK Limited is on UK Home Office **Register of Licensed Sponsors**, can handle Skilled Worker; but **internships don't go Skilled Worker**, usually use:
    - **Student visa allowed working hours** (in-school students / placement year module): most common
    - **Graduate visa**: post-graduation 2-year open period, can directly intern
    - **GAE (Government Authorised Exchange) visa**: short-term structured internship, Apple historically used this path
  - Non-EU students without RTW (right to work), Apple generally requires you to already be enrolled in UK school, separately applying for internship visa basically doesn't happen
- **Germany (Munich)**:
  - **EU Blue Card** is full-time path, not applicable to internships
  - Internships use **student work permit** (in-semester ≤20h/week, full-time during vacation) or **mandatory internship Pflichtpraktikum** (university required, smoothest to apply)
  - Non-EU students need German / EU school enrollment, Apple won't separately sponsor visa for interns
- **Conclusion**: Apple Europe internships very friendly to **international students already enrolled in European schools** (Chinese/Indian students via UK/DE universities), but **pure overseas application requiring sponsor for intern visa** is nearly impossible
- **Known sponsorship cases**: full-time SWE via Skilled Worker has public cases in London/Cambridge; intern-level public cases rare

## 3. Interview Process

### 3.1 SWE Intern (Munich / London) — Main Process

Total rounds: **3 major stages, usually 5-7 touchpoints**
1. **Recruiter Screening** (~30 min, English, occasionally German pleasantries): resume runthrough, project high-level, team interest, schedule
2. **Tech Screening** (~45-75 min): one round phone/Zoom technical interview, 1 coding question (LeetCode Medium mostly) + project deep dive + CS basics (OS/network/CA)
3. **Final Day / "Final Day Interviews"** (Munich pattern repeatedly confirmed):
   - **4 × 45-min back-to-back sessions** (virtual onsite or in-person)
   - Content: project discussion + computer architecture + LeetCode + team matching
   - **Meeting pace fast**, some interviewers only follow up without re-introducing themselves

Question type distribution (SWE intern):
- Algorithm: **40%** (LeetCode Easy/Medium primarily, Hard occasionally appears)
- System/CS basics: **25%** (process vs thread, OS, OOP, testing)
- Project deep dive: **25%**
- BQ / team matching: **10%**

Difficulty assessment: **2.9-3.2 / 5** (Glassdoor SWE Intern aggregate; interns report "moderately easy, but Final Day intensity high")

OA: **not mandatory**. Munich/London internally mostly use "tech screening" to replace standard OA, only a few online Hackerrank submission records

### 3.2 AIML / ML Intern (Cambridge UK / SaLT / SII)

- **R1**: 30-min Zoom, **research interest** + simple background, almost no code
- **R2** (full day / half day):
  - **30-min academic seminar**: candidate presents own research (PhD intern required)
  - **4 × 1-hour interview**:
    - **Coding**: LeetCode **Medium** difficulty, 1-2 questions; language unrestricted but Swift/Metal/CoreML bonus
    - **ML basics**: backprop, optimizer, transformer, attention, own topics (PrivML, NLU/NLG)
    - **Research deep dive**: PhD work details, hypothetical follow-up
    - **Team fit / BQ**

Question type distribution (ML intern):
- ML theory: **35%**
- Research / paper discussion: **30%**
- Algorithm coding: **20%**
- BQ: **15%**

OA: usually none, research path doesn't have OA

### 3.3 Silicon / Hardware Intern (Munich)

- **R1**: Recruiter screen
- **R2**: Tech phone screens — **analog design + digital design** dual track or single
- **R3**: Onsite **5-6 sessions**, each 45-60 min
  - Analog design (Op-Amp design often tested)
  - Digital / RTL / SystemVerilog / UVM (DV intern)
  - Computer architecture (pipelining, cache, virtual memory)
  - C/C++ programming
  - Project deep dive + BQ
- **Overall cycle**: **3 months** from first interview to offer, some candidates report 4 months

### 3.4 AIML Residency (atypical internship, but often confused)

- Interview: phone screen → 30-min research talk → **3 technical interviews**
- 100% Glassdoor positive (sample small)
- Difficulty score 3/5

## 7. Pitfalls & Community Reviews

- **Munich offer cycle long**: repeatedly confirmed pattern is "1-month interval × 3" — from first interview to offer letter actually 3-4 months. When holding other offers, **actively pushing recruiter** is common operation
- **Final Day intensity**: 4 × 45-min back-to-back + occasional early lunch/snack with hiring manager chat, tiring; 5-min mid-break normal
- **Team lock-in issue**: Apple internship is **team-based hiring** — even if technical interview passes, no team wanting you = also fail. **Multi-team simultaneous application** or stating flexible with recruiter important
- **Cambridge AIML extremely PhD-leaning**: Master/Bachelor difficulty extremely high; SaLT/SII almost all NLP/Speech PhD
- **Heavy confidentiality culture**: Apple in Europe doesn't allow intern to detail work on LinkedIn; also prohibits PR/blog. Affects portfolio display when later job hunting
- **International student friendliness**: ⭐⭐⭐ (medium) — those already studying in Europe OK, direct overseas application extremely difficult
- **Conversion rate**: Apple Europe conversion lower than North America — affected by tight headcount control, but return offer (next summer) cases many
