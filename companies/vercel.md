## Intern 路径

- **岗位命名**: "Engineering Summer Intern" [来源 (实际打开过): https://vercel.com/careers/engineering-summer-intern-5628292004]
- **时长**: 12 weeks summer (June-Aug)
- **申请窗口**: 11 月-2 月 (US/EU 同步, 单一窗口)
- **薪资 (stipend gross/月 GBP / EUR)**:
  - **US intern**: $9,500-$11,000/月 [Levels.fyi / Glassdoor 实数]
  - **London / Berlin intern**: 推算 £6,500-£8,000/月 (London) / €7,500-€8,500/月 (Berlin) — 比例对齐 US intern
  - 极高于 Sophos/Ocado intern, 因为 Vercel intern 总数极少 (~10-20/年 全球)
- **资格**: 在读本科 / 硕士, **极高 bar** — 通常要 GitHub / OSS contribution (Next.js, SWC, Turbopack repo PR 优先), 或 demo project (公开部署的复杂项目)
- **Sponsor 政策 (intern)**:
  - 历史 H-1B sponsor 主要美国, EU intern 无明确公开 sponsor 记录
  - UK Student visa (Tier 4) 持有人可走 — 但本人需已在 UK
  - **NL student visa**: 不能直接 intern UK / DE; Berlin Werkstudent 需 EU work right
- **流程**: 简历 → 90 min timed coding (CodeSignal-style, proctored, camera on) → 1-2 轮 tech + project discussion → behavioral; 总 ~3 周
- **转 FT 率**: 高 (~70%, intern 名额小, 目标就是 funnel)

## NG (New Grad / Junior 全职) 路径

- **岗位命名**: 
  - **无独立 "New Grad" track** — 直接挂 "Software Engineer" (无 level 标记)
  - Vercel 早期岗位极少, 主流 senior+ (Vercel 内部 level 大致映射 IC3-IC5)
  - 偶发 "Software Engineer, DX" / "Software Engineer, Experimentation" — London [来源 (实际打开过): https://www.glassdoor.co.uk/job-listing/software-engineer-experimentation-vercel-JV_IC2671300_KO0,33_KE34,40.htm]
- **是否有独立 cohort program**: **无**
- **起薪 (base + bonus + RSU)**:
  - **US New Grad TC**: $168K-$232K [来源 (实际打开过): https://6figr.com/us/salary/vercel--new-grad--cy]
  - **US SWE median TC**: $220K (P50) [Levels.fyi]
  - **London SWE base**: 估 £100-130K (Levels.fyi US median $220K 转 London 调整 ~50-60% = ~£100-130K), TC + RSU ~£140-170K
  - **Berlin SWE base**: 估 €110-150K, TC + RSU ~€150-180K
  - 实际 London / Berlin 公开数据少 (Levels.fyi 主要 US 样本), 推算从内部跨地区比例
  - **关键**: Vercel 不分 "junior", base 起步就是 senior 水准 — 但 bar 也是 senior 水准, 实际 grad 拿到 offer 极罕见
- **Sponsor 政策 (FT)**:
  - **Vercel UK Limited** 持 Skilled Worker license, A-rated [来源 (实际打开过): https://immigrationgpt.co.uk/company/vercel-uk-limited]
  - £100K+ base 远超 SW £41,700 阈值 + going rate £49,400 — **过门槛极轻松**
  - **DE Berlin**: Vercel GmbH 历史无明确 sponsor 信号, 推测可走 Blue Card (€45,934 shortage 阈值, Berlin SWE €100K+ 远超) — case-by-case
  - 实际限制是 **bar 而非 visa** — Vercel 一年 EU hire 个位数, 国际 grad 命中率 <1%
- **申请窗口**: 滚动开放, 无固定 cohort
- **流程差异 vs intern**: 5 轮 (recruiter, coding, sys design, hiring manager, cross-team), 3 周

## 2. 签证与国际学生政策

- **2026 UK 阈值**: Skilled Worker £41,700, NEC £33,400, going rate ~£49,400
- **2026 DE 阈值**: EU Blue Card shortage (IT) €45,934, 常规 €48,300
- **Vercel UK Limited** Skilled Worker license active [immigrationgpt 实际打开过]
- **Vercel GmbH**: 推测持牌但无公开 sponsor 记录 (small office)
- **关键 reality**: visa 不是瓶颈, **岗位数量 + bar** 才是. Vercel EU 总 headcount <100 (London ~30, Berlin ~30, remote ~30), 一年开 10-15 个新岗
- **NL student visa 路径**:
  - UK: 直接申 FT (intern 不开 sponsor), 需要 IC3-IC4 水平
  - DE Berlin: Blue Card 可走, 但岗位极少
  - NL remote: Vercel 部分 role 写 "EU-friendly remote" — 可问

## 3. 面试流程

|------|------|------|
| 1. Recruiter screen | 30 min, role fit + visa + your recent work walkthrough | 30 min |

## 7. 踩坑与社区评价

- **裁员**: 2023-04 + 2024-02 两轮小规模裁员, 但 2025-2026 强势 hire back (v0 + AI 产品爆发)
- **WLB 差异化**: SF / NY 文化激进 (60h/week), EU office 相对正常 (~45h)
- **股价**: pre-IPO, 2024 估值 $3.25B (B 轮), RSU 是 lottery — 2025-2026 传闻 IPO 但无 confirm
- **DX 极强**: 内部用自己的产品, dogfooding 文化, eng 满意度高 (Glassdoor 4.4/5)
- **EU 招聘节奏**: 单一 Engineering Summer Intern + 个位数 FT/年, 远不如 Cloudflare / Snyk 友好
- **Berlin office 状态**: 主要 product + design + DX, infra eng 多 SF; Berlin role 经常 "remote-friendly" 实际希望搬

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

- **核心 trade-off**: Vercel **不适合 UvA grad 用户**, 除非你是 Next.js core contributor 或个人项目极强
- **Intern 可行性**: **零-极低**
  - Engineering Summer Intern 全球~10-20 个名额, 多在 US
  - EU intern 历史无公开 sponsor 案例
- **FT 可行性**: **极低**
  - 岗位 bar 是 IC3-IC4 senior, grad 命中率 <1%
  - 即使 visa OK (Vercel UK 持 SW), 申请通过率极低
  - Levels.fyi London / Berlin 数据稀疏, 真实 EU 招聘几乎全是 senior+ hire
- **NL 路径**: Vercel **无 NL office**, NL remote case-by-case
- **DE 路径**: Berlin 可走 Blue Card, 但岗位少且 bar 高
- **预计摩擦**: **极高** (不是 visa 摩擦, 是 bar 摩擦)
- **建议**: 
  - **不要把 Vercel 列为 active pipeline** — UvA grad 难命中
  - 若 React / Next.js / Turbopack 深度强 (有 OSS PR), 投个 backup 试水
  - 平行申: Algolia (法国小独角兽, EU intern 友好), Datadog London (DX 友好 + EU grad cohort), Stripe Dublin (Engineering Rotational Program — 实际 EU intern 友好得多)
  - **真实建议**: 时间花 Snyk / Datadog / Stripe, 不要花在 Vercel
