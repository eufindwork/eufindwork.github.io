## Intern Path

- **Role naming**: 
  - **UX Graduation Internship** (open, 6 months) [Source: https://jobs.picnic.app/en/]
  - Occasional Software Engineering Internship / Data Internship (not regular)
  - **graduation nature**: must accompany thesis project (NL university final year standard "afstudeerstage")
- **Length**: 6 months (graduation stage standard)
- **Application window + deadline**: rolling, but UX Grad Internship usually aligned with thesis timing (spring / fall intake)
- **Salary (stipend gross/month)**: **€800/month gross** (Glassdoor data, historical listing) — standard NL stage salary, lower than Booking €1900 / Adyen €2400
- **Eligibility**: 
  - **Must be enrolled in NL** (Picnic graduation internship defaults to NL university thesis binding)
  - Bachelor / Master final year
- **Sponsor policy (intern)**: **does not handle work permit** — defaults to requiring NL student visa + Nuffic convention
- **Process**: CV → recruiter call → coding challenge (Java / take-home) → on-site case + culture interviews (1 full day)
- **Conversion to FT rate**: estimated 30-50% (UX Grad Intern conversion cases many; SWE Intern usually directed to Tech Academy)
- **Pitfalls**: many Glassdoor reviews mention "process very lengthy for an intern application, requiring a test, mini-case study, and in-person office work day", "takes a lot of time, energy and money" — **don't invest 100% on a single intern offer**

## NG (New Grad / Junior full-time) Path

- **Role naming**: **Picnic Tech Academy - Java Graduate Program** (Amsterdam, 6 month cohort program, converts to FT after completion) — the original dedicated listing link is dead (404, verified 2026-09-26); the program itself is still listed on the graduate-programs overview page [Source (verified opened): https://jobs.picnic.app/en/graduate-programs]
- **Whether there is a standalone cohort program**: **Yes — Picnic Tech Academy**
  - **Structure**: 6 month program, covers Java Clean Code → Reactive Programming → MongoDB → Spring 6 / Kafka / Postgres / K8s / Terraform
  - **Requirements**: BSc / MSc CS / AI / IT / related, **0-1 yr experience**, fluent English, 2026 September start
  - **Tech Stack**: Java 25, Spring 6, Reactor, RabbitMQ, Kafka, PostgreSQL, MongoDB, AWS, Docker, Kubernetes, Terraform, Vault
- **Starting salary (base + bonus + equity)**:
  - **Tech Academy Grad total comp**: **€57K** (TechPays / Glassdoor entry-level avg) [Source: https://www.glassdoor.com/Salary/Picnic-Amsterdam-Salaries-EI_IE1040717.0,6_IL.7,16_IM1112.htm]
  - **Greater Amsterdam SWE range**: **€57.7K – €65.7K+** (Levels.fyi) [Source (verified opened): https://www.levels.fyi/companies/picnic/salaries/software-engineer/locations/greater-amsterdam-area]
  - **Equity**: private (still pre-IPO, EQT / Hoogvliet invested), equity minimal, mainly base
  - Plus **25 days vacation + pension + free weekly language classes + OpenUp psych counselling + gym + healthy lunch**
- **Sponsor policy (FT)**: NL Kennismigrant. **Tech Academy base ≈ €54K = €4,500/month**, just meets <30 HSM threshold (€4,357). UvA master grad reduced HSM (€2,801) zero barrier.
- **Application window**: 2 intakes/year (March + September), opens 4-6 months ahead
- **Process differences vs intern**:
  - Tech Academy: 5 stages (CV → Phone → Interviews → **Assessment Day** → Offer)
  - Intern: 4 stages, but Assessment Day intensity similar

## 3. Interview Process

### Tech Academy (5 stages)

| Round | Content | Duration |
|---|---|---|
| 1 | CV screening | 1-3 days |
| 2 | Phone screening (recruiter, English) | 30 min |
| 3 | Interview 1 (technical, Java basics + behavioral) | 60 min |
| 4 | **Assessment Day** (on-site Amsterdam): take-home presentation + culture fit + multi-person group case | 1 full day |
| 5 | Offer | within 1 week |

- Average duration: **21.6 days** (Glassdoor)
- Java Developer avg: 27 days

### Internship

Similar 5 stages but compressed, usually take-home + on-site day

## 6. Application Channels and Suggestions

- **Official application**: https://jobs.picnic.app/en/
- **Referral channels**: Picnic Tech engineers active on LinkedIn, reach out directly; also via TU Delft / UvA / VU career events
- **Resume/background requirements**:
  - **Java project depth** — this is core stack, no Java experience high chance of rejection
  - Bonus: Spring Boot, MongoDB / PostgreSQL, distributed systems (Kafka), university-period relevant internship
  - **Dutch not required**, English fluent
- **Suggestions**:
  - **Tech Academy is Picnic's only stable entry-level channel** — other IC roles almost all require 5+ yr experience, source of "Picnic leans senior 5yr+"
  - Prepare take-home + on-site full day — this is the heaviest part of Picnic hiring process, don't underestimate
  - Focus on "scalable order routing" / "milk run optimization" Picnic-specific ops algorithm topics — frequently asked in interviews

## 8. For UvA Students (NL student visa) — Specific Assessment ⭐

- **Intern viability**: **zero friction** — UvA enrolled + NL student visa directly meets graduation internship requirements (NL enrolled). Student visa 16h semester / 40h vacation covers stage, Nuffic convention completes, **company doesn't need to handle work permit**
- **FT viability**: **zero friction** — via zoekjaar then apply Tech Academy / Junior Java, base €54K far exceeds reduced HSM €2,801, also exceeds standard HSM €4,357. relocation already covered (but UvA local students don't need it)
- **Expected friction**: **zero** (both paths smooth)
- **UvA advantage**:
  - Picnic HQ in Hoofddorp, ~20 km from UvA campus, ~30-40 min public transport / inconvenient by bike, but Picnic has Amsterdam Centraal shuttle
  - UvA / VU / TU Delft CS alumni many at Picnic, referrals easy
  - **Tech Academy is natural fit** — UvA CS / AI master fresh grad 2026 sept start directly connects
- **Recommended application timing**:
  - Tech Academy September 2026 intake: **monitor opening 2026 Mar-Jun**
  - Tech Academy March 2027 intake: **monitor opening 2026 Oct-Dec**
  - UX Graduation Internship: align with thesis schedule, apply 4-6 months ahead
