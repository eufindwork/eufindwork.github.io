## Intern Path

- **Role name**: **10-Week Summer Internship** — Backend / Frontend / Data Science / Data Analytics / Product Design
- **Duration**: 10 weeks, Jun-Aug
- **Application window + deadline**: usually early Oct opens → end of Dec closes, **rolling** (London/Tallinn engineering roles may close as early as Nov) [wise.jobs/early-careers (verified opened): https://wise.jobs/early-careers]
- **Salary (stipend gross/month)**: London ~£3,500-4,000/month pro-rated (calculated from L1 starting ~£50K); Tallinn ~€2,800-3,200/month (calculated from €40K) [Levels.fyi Wise L1 (verified opened): https://www.levels.fyi/companies/wise/salaries/software-engineer/locations/london-metro-area]
- **Eligibility (degree, local residency requirements)**: enrolled undergrad / master's / PhD, final 1-2 years before graduation, any CS-related major; doesn't require local residency (Wise sponsors intern visa, but prefers those who already have working rights)
- **Sponsor policy (intern)**: **London internship requires UK Skilled Worker Visa** or Tier 5 (Wise occasionally sponsors but not guaranteed, explicitly stated in JD); **Tallinn internship uses Estonian D-visa**, company assists with processing, flow relatively fast (Estonia e-Residency system has long supported foreign tech workers)
- **Process**: HireVue OA → 1 round technical (system design + coding, ~90min) → final round (1 hire manager + 1 peer) — see Section 3 below
- **Conversion rate to FT**: high internal conversion (community reports 60-70%), WiseStart cohort mostly intern conversion

## 2. Visa & International Student Policy

- **Does it support non-EU students**: ✅ Yes, all three locations sponsor (London prefers those with work rights, Tallinn/Budapest more flexible)
- **Intern vs FT sponsor differences**: London intern almost no sponsor (unless transferred from Wise internal other countries); Tallinn intern can sponsor D-visa but needs 3 months advance
- **Known sponsorship cases**: 1point3acres / Reddit multiple China/India international students entered Tallinn WiseStart, Estonian Type-D + Residence permit (TRP) using e-Residency to accelerate [Reddit r/Estonia + r/cscareerquestionsEU multiple cases]
- **2026 thresholds**:
  - **UK Skilled Worker** £41,700 (NEC £49,400 from 2026-04); Wise London L2 starting £55K+ far exceeds
  - **Estonia D-visa**: tech workers no fixed threshold, but usually needs ≥ Estonian average salary ×1.5 (~€2,500/month)
  - **Hungary**: EU Blue Card threshold ~€55,800/year (2026), Wise Budapest L2 ~€45K base, **may be at limit**, need to confirm

## 3. Interview Process

| Stage | Content | Duration |
|------|------|------|
| 1. OA | HireVue video questions (behavior) + coding (medium LC, Java/Kotlin/Python choose any) | 60 min |
| 2. Tech 1 | System Design (design a payment/remittance related system, e.g. "design a money transfer service") | 90 min |
| 3. Tech 2 | Coding pair + code review on existing PR | 60 min |
| 4. Hire Manager + Peer | Behavioral, culture fit, rotation preference | 90 min |

System Design is the **core differentiator**, Wise emphasizes "product engineer" thinking — not pure architecture question, must include product trade-off [wise.jobs/system-design-interviews (verified opened): https://wise.jobs/system-design-interviews]

## 7. Pitfalls & Community Reviews

- **Salary vs Big Tech**: London Wise L2 (~£77K TC) significantly lower than Meta/Google same level (£100K+), but WLB good, remote flexible
- **Sponsor not guaranteed**: even if company is in sponsor list, JD may still write "must have right to work" — read carefully before applying
- **Tallinn remote culture**: hybrid 3 days office, some teams 100% on-site (especially platform); those expecting fully remote will be disappointed
- **2024-2025 layoff**: Wise had ~150 layoffs in 2025 Q1 (mainly ops/customer support), engineering teams basically unaffected [Reddit r/Wise]
- **Estonia e-Residency cannot directly work**: e-Residency only allows establishing company, work still needs D-visa + TRP, don't confuse

## 8. For UvA Students (NL student visa) — Specific Assessment ⭐

### Intern feasibility
- **London Summer Intern**: ❌ high friction — UK Skilled Worker intern sponsor rare, Wise JD states "right to work required". Even if sponsored, GUP (Graduate UK Programme) usually prioritizes UK local students.
- **Tallinn Summer Intern**: ⚠️ possible — Wise sponsors Estonian D-visa, but user needs to leave country during UvA summer (Jun-Aug) to Estonia. NL student visa doesn't allow long-term work in third country (needs separate Estonian short-term work permit). **Theoretically feasible, practically complex, not recommended**.

### FT feasibility
- **Graduation get WiseStart London**: UK Skilled Worker, £41,700 threshold, Wise L2 starting £55K+ far exceeds, process 4-8 weeks, **feasible**.
- **Graduation get WiseStart Tallinn**: Estonia D-visa + TRP, 2-3 months, **feasible** — Estonia actual take-home excellent, but city size limited.
- **NL zoekjaar conflict**: WiseStart Feb/Sep cohort both need to arrive by start date, fits zoekjaar job search window. But Wise **has no office in NL**, user needs to give up zoekjaar and go to third country visa.

### Estimated friction
- Intern: **high** (London no sponsor, Tallinn complex)
- FT London: **low-medium** (Skilled Worker clear, Wise has lots of operations, but need to give up zoekjaar)
- FT Tallinn: **medium** (Estonia D-visa smooth, but city size / language / Chinese community small)

### Advice
- **Priority strategy**: directly apply **2026 Sep cohort WiseStart London**, start date ~2026-09; backup Tallinn cohort.
- **Not recommended**: intern → conversion path, because intern stage visa too complex. Wise campus grad channel actually friendlier to international students.
- **Timeline**: 2026-09 application window opens → first week submit resume (rolling closes) → OA same month → 11-12 interviews → 2027-02 or 2027-09 start.
