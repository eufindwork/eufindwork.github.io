# Criteo (Paris) — Internship Intel

> **Language**: [中文](criteo.md) | English
>
> French AdTech global player, Paris HQ, publicly listed (NASDAQ: CRTO). Internship-friendly, many SWE / ML / Data roles, process relatively friendly to international students, one of Paris's best value-for-money ML/SWE internship options. 4-6 month stage, mature referral system.

---

| Dimension | Info |
|---|---|

| Business | Performance advertising, retargeting, retail media, AdTech ML platform |
| Engineering scale | Paris is R&D + AI Lab main base; Grenoble also has R&D center |
| Tech stack | Scala/Java/Python, Spark, Hadoop, Kafka, TensorFlow/PyTorch, K8s, GCP/AWS, Vertica |

## New Grad / Junior Roles

> Information richness: ⭐⭐⭐⭐⭐ (Paris L2-L5 Levels.fyi complete + Criteo Campus official entry confirmed + Glassdoor data rich, most complete tier among 11 companies)
> Differences vs internship: Full-time entry-level (0-2 years experience); Criteo names its entry-level program **Criteo Campus** (not Graduate Programme), includes Internship + Apprenticeship + CDD; direct CDI Junior is another independent channel

- **Common role names**: Software Engineer L2 (Entry) / L3 (II), ML Engineer, Data Scientist, Apprenti SWE/ML (French alternance apprenticeship system); careers page active reqs mostly list "Software Engineer Intern" + "Senior Software Engineer", **direct "Junior" named reqs few**, goes through L2/L3 standard reqs
- **European locations**: Full-time engineering mainly **Paris (32 rue Blanche, 9th arr.)** and **Grenoble (R&D center)**; some roles Barcelona, occasional London / Milan / Amsterdam; Junior SWE / ML mainly Paris, Grenoble leans platform / infra
- **Independent Graduate Programme**:
  - **Criteo Campus** is the named entry-career program [Source (verified opened): https://careers.criteo.com/en/working-at-criteo/criteo-campus/]
  - **Explicitly not a traditional graduate scheme** (Criteo Campus official original: "not a traditional graduate scheme"), but an umbrella including: **Internship + Apprenticeship + CDD (Temporary)**
  - 2026 standard internship 4-6 months, **2026-07 multiple start dates active**
  - Equipped with mentor / buddy system + onboarding training + selection cycle 2-4 weeks
  - Globally distributed: Americas + Europe + APAC; Junior CDI is another standard rolling req, parallel to Campus
- **Non-EU visa (full-time)**:
  - **France Passeport Talent (Salarié Qualifié)**: Criteo sponsors; monthly salary ≥ 2x SMIC (~€3,494/month gross), Criteo L2 starting salary €63k base far above threshold [Source (verified opened): https://www.levels.fyi/companies/criteo/salaries/software-engineer/locations/greater-paris-area]
  - **EU Blue Card (France) 2026**: Threshold ~€54-55k/year, Criteo L2 base €63.4k safely meets
  - **APS (Autorisation Provisoire de Séjour)**: M2 French graduates get 12 + 24 month job search; many Chinese / Indian candidates follow "internship → APS → Criteo CDI sponsor" path
  - Internship / Apprenticeship usually covered by student status, full-time Criteo proactively sponsors
- **Salary range (Levels.fyi 2026-05-28 data, Greater Paris Area)**:
  - **L2 (Software Engineer Entry)**: TC ~$70K (~€65K), base $63.4K + stock $2.7K + bonus $3.8K [Source (verified opened): https://www.levels.fyi/companies/criteo/salaries/software-engineer/locations/greater-paris-area]

  - **Vesting**: 25% Y1 + remaining 36 months monthly 2.08% vest
- **Application window**: **Rolling year-round**; Apprenticeship mainly Jul-Sep start (synced with French school year); CDI Junior year-round, Mar-May / Sep-Nov two peak periods; **Criteo Campus 2026-07 multiple start dates active**

## 4. Hiring Process

| Round | Content | Duration |
|---|---|---|
| 1. HR Screen | Resume, motivation, time, expectations (English) | 30-45 min |
| 2. Online Test (some roles) | Online algo / SQL / analytics test | 60-90 min |
| 3. Technical Interview 1 | Algorithms + data structures (LeetCode Medium type) | 60-90 min |
| 4. Technical Interview 2 | Algorithms + project deep-dive / design pattern | 60-90 min |
| 5. (ML role) ML/system design | Recommendation systems, ranking, feature engineering, evaluation | 60 min |
| 6. Manager / Team Fit | Chat with hiring manager about fit, project assignment | 30-45 min |

**Total length**: 2-4 weeks (smooth case), some candidates report ~22 days to hire.

**Interview difficulty**: Glassdoor 3.1/5, 67% positive — **mild/friendly tier**, far below FAANG.

**Key assessments**:
- LeetCode Easy/Medium (array, DP, recursion, hashmap)
- Big-O complexity reasoning (always asked)
- System design (advanced roles): MapReduce, Kafka, Elasticsearch, cache, SQL/NoSQL trade-offs, web crawler
- ML role: CTR prediction, embedding, two-tower model, multi-task learning, A/B test, online metrics
- Soft skills + communication (interviewer explicitly stated will assess)

## 7. Culture, Work Environment, Soft Intel

- **Office**: Paris 9th arr., "great office, yummy canteen, smart & friendly colleagues from around the world"
- **Hybrid**: 1 day/week in office is enough, flexible time
- **Pace**: Not intense, friendly, "limitation is limited growth opportunities" — some employees report slow promotion
- **International**: Paris office English work language, French **not mandatory**
- **Career growth**: 3.5/5 — this is Criteo's main complaint, internship OK but long-term growth not aggressive
- **Colleagues**: 4.0+/5, strong helpfulness culture, "no judgment for asking questions, hierarchy doesn't matter"
- **AI Lab**: Has published NeurIPS / RecSys / KDD papers, academic atmosphere much better than typical AdTech

| Step | Recommendation |
