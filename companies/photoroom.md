- **常见岗位名**: Software Engineer (iOS / Android / Backend), ML Research Engineer, ML Engineer, Founding 类岗位 (small team)

## 3. 面试流程

- **总轮数**: 4-5 轮, 平均 24 天 [来源 (实际打开过): https://www.glassdoor.com/Interview/Photoroom-Interview-Questions-E8011752.htm]
- **每轮形式**:
  1. Recruiter screen (30 min)
  2. Technical coding / take-home
  3. Tech deep-dive 与 future manager
  4. **Values interviews** (scenario-based, Photoroom values 重)
  5. **Final onsite at Paris office** (Photoroom 出差旅费), 半到一天, 团队互动
- **题型分布**: Tech 50% / Values 30% / Manager fit 20%
- **难度评估**: 难度 3/5 (Glassdoor), positive rate 仅 30.8% (筛人狠)
- **OA 是否存在**: take-home 或 live coding 二选一, 视岗位

## 7. 踩坑与社区评价

- 30.8% positive interview rate — 流程**很难通过**, 但 fair
- Values round 不准备会挂 — CEO 文章列出 5 个 values 必读

- Founding-team 文化, 节奏快, 不适合 "稳定大厂" 心态
- 国际生友好度极高 (30% 强制 + visa + relocation bonus)
