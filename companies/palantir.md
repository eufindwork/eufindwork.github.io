# Palantir (London / Munich / Paris) — 实习情报

> **Language**: 中文 | [English](palantir.en.md)
>
> 更新时间: 2026-05-31
> 一句话定位: Foundry / Gotham / AIP 平台公司, 政府 + 商业双线. **FDSE (Forward Deployed Software Engineer)** 是 Palantir 标志性岗位, 既写代码又跟客户. UK Government FDSE 是 London 招聘大头. 对国际学生 friendliness 中等偏高, UK Skilled Worker license 完整, **有正式 Launch (Spring insight) + Accelerate (intern) + New Grad 三条 student pipeline**, 在 frontier 范围内 student-friendly.

## 1. 基本信息

- **欧洲办公室**:
  - **London** — 主基地, Soho Square (UK Government / Commercial / Engineering)
  - **Munich** — 欧陆中心, Engineering + Customer Engineering
  - **Paris** — 法国国防 + 商业 (2024 起扩张)
- **岗位类型**: Software Engineer (Backend / Frontend / Infra), Forward Deployed Software Engineer (FDSE), Forward Deployed Engineer (FDE — non-coding), Data Engineer, Solutions Engineer, Product Designer
- **实习时长**: **Accelerate Internship** 通常 12 周 (Summer cohort); **Launch Program** 4 天 spring insight; **FDSE Intern** 12 周
- **招聘周期**: Cohort + rolling. Launch ~Q3-Q4 prev year (4 月活动); Accelerate / Intern Q3-Q1 (Summer cohort 春季前满)

## 3. 面试流程

- **总轮数**: 4-5 轮 (intern 3-4 轮, 全职 5-6 轮)
- **每轮形式**:
  1. **Recruiter Screen** (30 min, **filter aggressive — surface answers 直接挂**)
  2. **OA / HackerRank** (30 min, intern; 全职可能 take-home)
  3. **Decomposition Interview** — 给 ambiguous 业务问题, 拆解 + 推架构
  4. **Coding** — LeetCode Medium 级
  5. **Learning Interview** — 现场学新 API/concept, 评 learn-on-the-fly 能力
  6. (全职) **System Design + Hiring Manager Final**
- **题型分布**: Coding 30% / Decomposition 30% / Learning 20% / Re-engineering 10% / BQ 10%
- **难度评估**: FDSE Intern 3.1/5 (Glassdoor); 整体 ~28 天
- **OA 是否存在**: **Yes**, HackerRank 30 min for intern

## 6. 申请渠道与建议

- **官网投递**: https://www.palantir.com/careers/ + Lever 直接搜 (Palantir 用 Lever ATS)
- **内推途径**: Launch alumni 主动帮内推; LinkedIn 上 Palantir UK recruiter 极活跃 (公开 hot reqs)
- **简历/背景要求**:
  - 强 CS 基础 + clean coding; 不强求 ML 背景
  - **Decomposition 思维** 是 Palantir 招聘核心 — 准备 "把 ambiguous 问题拆成可执行步骤" (找 Google open-source 项目 / Hacker News 文章 mock)
  - UK Government FDSE 需 SC clearance 可能 (但 UK Government FDSE New Grad lever 没明确写, 国际学生可投)

## 7. 踩坑与社区评价

- **Recruiter screen 杀手轮**: Palantir 在 recruiter 阶段刷得比同行重, "surface motivation = 出局" — 准备讲清为啥是 Palantir 而不是 Amazon/Google
- **Decomposition / Re-engineering 题型独特** — 不是 LC, 不能靠刷题应付; 看 [hellointerview / prepfully](https://prepfully.com/interview-guides/palantir-software-engineer) 的 Palantir 专项
- **FDSE 不是纯码农** — 50% 写代码 + 50% 客户 onsite (国防 / 银行 / 制药), 介意频繁 client travel 别投 FDSE, 走纯 SWE
- **UK Gov clearance**: 部分 UK Government 岗要 SC / DV clearance — 国际学生不能拿; 看 lever JD 是否明写
- **国际学生友好度高**: Palantir 是 frontier 范围里 UK Skilled Worker 最稳的之一 (Juno 8/10)
