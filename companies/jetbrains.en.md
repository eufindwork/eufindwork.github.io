## 2. Visa & International Student Policy

**Core conclusion: JetBrains internship does not provide visa sponsorship, but provides relocation to designated countries.**

| Dimension | Policy (official quote / meaning) |
|------|------------------------|
| Applicant residency requirements | Must reside in EU / Armenia / Serbia (or UK student status), and have no legal/visa restrictions |
| Student visa holders | Can apply (official notes "holders of student visas") |
| Internal visa support (intern) | **None** ("we do not offer visa/permit support within the internship framework") |
| Relocation support (intern) | Only supports full-time 3 month summer internship; relocation countries: Armenia, Cyprus, Czechia, Germany, Netherlands; must already have target country work + residence permit or passport; case-by-case decision |
| Post full-time conversion | Provides complete work permit / residence / document translation / 1 month temporary housing / flights / luggage shipping / language courses in some countries; historically 90+ employees + family members (incl. pets) relocated within 1 year |

**Feasible paths for Chinese international students**:
1. **Already studying in EU (incl. student visa)**: apply directly, JetBrains won't get new visa for you, but you can use school's internship agreement to intern in Netherlands/Germany/Czechia (need to go through Nuffic tripartite agreement or school Erasmus+ framework)
2. **Already studying in UK**: can also apply (application page explicitly accepts UK students)
3. **Not studying in EU/UK/AM/RS**: officially ineligible; can email `internship@jetbrains.com` for individual case inquiries, but success rate extremely low
4. **Alternative path**: prioritize Armenia (Yerevan) application, because it's the only country with case-by-case relocation for "non-EU residence"

> Source: jetbrains.com/careers/internships/, blog.jetbrains.com/life-at-jetbrains/2026/05/relocating-with-jetbrains-...

## 3. Interview Process

### Overall process (non-standard!)
JetBrains internship **doesn't have the traditional OA + multi-round LeetCode model**, the entire process revolves around "project + mentor":

```
① Browse project library (internship.jetbrains.com)
   ↓
② Pick 1–5 projects, submit application (Hub account login)
   ↓
③ Complete project-specific test task (countdown starts after clicking "Solve the task")
   ↓
④ Mentor reviews test task solution, those who pass get email invitation
   ↓
⑤ 1 round technical / behavioral interview (Mentor + dev) — mostly behavioral, may also ask technical
   ↓
⑥ Hiring decision
```

### Question type distribution
| Question type | Proportion | Notes |
|------|------|------|
| **Test task (home assignment)** | 80% weight | Highly relevant to target project; e.g. Kotlin Analysis API project will have you implement mini parser / static analyzer |
| **Behavioral interview** | Main | "Tell us about yourself", project experience, collaboration style |
| **Technical oral** | Occasional | OOP basics (Abstract class vs interface), Git, JVM (GC, stack/heap), language details (Kotlin `==` vs `===`, nullable types) |
| **Algorithm / LeetCode** | Very rare | JetBrains not like FAANG main drilling algorithms; but SWE Senior role Glassdoor shows 90 min tech + 90 min system design + 7-day take-home |

### OA
- **No traditional online test**; test task itself serves screening function
- Test task difficulty corresponds to medium engineering task, not LeetCode question

### Process pace
- Glassdoor data: company-wide average hire cycle **35.77 days** (70 samples)
- Intern full process: about 2 months (e.g. apply Mar, results late Apr)
- **Summer/Fall 2026 cycle (verified opened admissions/114)**: application deadline **2026-03-16 23:59 GMT** → interviews to **2026-04-17** → results **2026-04-22** → Summer/Fall start
- 2025/2026 winter cycle pace (historical reference): application deadline 11/7 → interviews to 12/9 → results 12/10

> Source: glassdoor.com/Interview/JetBrains-Software-Engineer-Internship..., jetbrains.com/careers/internships/, internship.jetbrains.com/admissions/114 (2026 Summer/Fall cycle public admissions page)

## 6. Application Channels & Advice

### Official channels
- **Internship project library + application entry**: https://internship.jetbrains.com/ (login JetBrains Hub account)
- **Company career main entry**: https://www.jetbrains.com/careers/
- **Career project Greenhouse**: https://job-boards.eu.greenhouse.io/jetbrains (mainly full-time roles, occasionally with intern)
- **Contact email**: internship@jetbrains.com (visa / individual case inquiries)

### Project selection tips
1. **Max 5 projects per cycle**, so carefully select those highly matching your stack
2. Once you click "Solve the task" the **timer starts**, be sure to download + read the task first before clicking
3. If a single cycle project contains multiple tasks, **shared single total countdown** — carefully allocate time
4. Mentor seeing a high quality test task solution is more useful than drilling more LeetCode — clean up code / write README / brief design rationale before submission

### Resume / background requirements
- **Required**: EU/UK/AM/RS residence + student (or graduated ≤1 year)
- **Bonus**:
  - Depth of corresponding project stack (e.g. Kotlin Analysis API project requires Java/Kotlin + parser/static analysis experience)
  - **Open source contribution to JetBrains repos** (kotlin, intellij-community, intellij-kotlin etc.) — this is the most direct signal for mentor
  - Compiler / IDE / DSL related courses or projects
- **Kotlin Ecosystem Mentorship Program** (https://blog.jetbrains.com/kotlin/2026/05/kotlin-ecosystem-mentorship-program/) is another bend-around path: through it contact JetBrains core contributors → get referral

### Referral
- JetBrains doesn't have public referral bonus, but **project pages usually list mentor names** — contacting mentors via GitHub / Twitter / academic conferences is much more effective than LinkedIn cold message

## 7. Pitfalls & Community Reviews

| Dimension | Evaluation |
|------|------|
| Process pace | Medium; 30–60 days, faster than FAANG, slower than startups |
| Whether OA discourages | No OA, but test task workload ≈ a small weekend project, time-tight students need to plan ahead |
| International student friendliness | **Residency hard threshold (EU/AM/RS/UK)** is biggest pitfall; not sponsoring visa is public statement, don't hope for exception |
| Culture | Glassdoor overall 4.x / 5, intern rated 4.6 culture; company culture engineer-driven, weak hierarchy |
| Project quality | Interns contribute production / research code from Day 1, AI4SE projects can even convert to FTE |
| Stipend | Not top-tier (Amsterdam €1.6k, Warsaw €2.3k), but for IDE / programming language enthusiasts, "doing Kotlin/IntelliJ itself" has more prestige than salary |
| Remote restrictions | Only remote in countries where JetBrains has office, can't remote from within China |
| Conversion path | AI4SE / Research path has clear conversion cases; engineering intern conversion conditions not public, but usually needs mentor active push within cycle |

### Known "pitfalls"
- **Many projects only open in certain cycles** — don't wait for "perfect fit" project, apply when you see suitable
- **Stipend differs greatly between countries** (Warsaw > Amsterdam, 2023 vs 2024 data differs 2x); confirm housing / transit included before accepting offer
- **Don't use 2023 Munich $4k/month for negotiation** — it's outlier
- **No referral bonus** → cold apply and "find mentor pre-pitch" are only two paths
