## 2. 签证与国际学生政策

**核心结论: Sponsor visa + relocation 给非涉密岗; 涉密 / NATO classified 岗 nationality-restricted**

| 维度 | 政策 |
|------|------|
| 是否支持非EU学生 | **Conditional Yes** — 非涉密 IC SWE/ML/Infra 岗办 Blue Card / Skilled Worker / Passeport Talent; **涉密岗 No** (需 NATO 国国籍 + clearance) |
| 是否要求 work auth | **No** (非涉密) — 公司办 Blue Card / Skilled Worker |
| 中国籍 OK 岗位 | 商业 SaaS / 基础设施 / DevOps / 部分 ML infra (非武器系统) — 仍需 case-by-case 邮件确认 |
| 中国籍 NOT OK 岗位 | UK MoD partnership / DE BMVg classified 项目 / HX-2 武器系统 / NATO STANAG 涉密数据 — 强制 NATO 国国籍 + clearance |
| 已知 sponsorship 案例 | Drone Field Eng JD 标 visa-friendly [来源 (实际打开过): https://jaabz.com/jobs/162773-drone-field-engineer]; LinkedIn 上 Munich/London 多个非欧国籍工程师入职 (印度/巴西/美国背景多见; 公开中国籍案例稀疏) |
| Field Engineer 出差 | UK/FR/DE testing site 经常出差, visa stamp 灵活度要求高 |

**对中国留学生的可行路径**:
1. **强烈建议**: 申请前**直接邮件 HR** 写明国籍 + 目标岗位, 让 Helsing 确认该岗位是否 nationality-restricted (Helsing recruitement@helsing.ai)
2. **目标 Munich 非涉密 SWE / Infra / ML platform 岗**: 中国籍可办 Blue Card, 流程同 Munich 其他 tech 公司
3. **避开**: HX-2 drone team / UK MoD partnership / NATO classified 团队
4. **Working Student (DE only)**: 持德国学生签 + 在德高校在读, 不需要额外 visa; 但**国防属性同样适用 — 涉密项目仍 restricted**
5. **PhD / 顶会 ML 背景**: 走 Foundation Model Research 岗, 通常 publication-driven, nationality 限制较松

> 来源: helsing.ai/careers + Glassdoor + 行业 standard NATO clearance 规则

## 3. 面试流程

> Glassdoor 数据: SWE 难度 3.4/5, 20% positive, 平均 26 天 hire 周期

- **总轮数**: SWE 全职 ~5 轮 / Intern ~3-4 轮
- **每轮形式**:
  1. **Recruiter Call** (30 min): role / location / nationality / clearance fit
  2. **Hiring Manager** (45-60 min): past projects + 技术深度
  3. **Technical Coding** (60-90 min): **CSV exercise** — "Leetcode-style CSV handling, unlocks stage by stage, 数据从 CSV 提取到正确 DS 并按需求 process" (Glassdoor 2026-02 Berlin SWE 原话) [来源: https://www.glassdoor.com/Interview/Helsing-Software-Engineer-Interview-Questions-EI_IE6763957.0,7_KO8,25.htm]
  4. **System Design + Domain** (60 min): 实时数据处理 / sensor fusion / 分布式 inference 等场景设计
  5. **Culture / Mission Fit** (45 min): 国防 mission alignment (Helsing 强调"defending democracies", 反战 / 道德疑虑明显的候选人不合适)
- **题型分布**: Coding (CSV exercise + 算法) 40% / 系统设计 30% / Domain (ML / Robotics / Defense scenario) 20% / BQ + mission fit 10%
- **难度评估**: Medium - Hard; CSV exercise 本身不难但分阶段解锁要求扎实工程基础
- **OA 是否存在**: CSV exercise 接近 OA 形式但通常是 live, 不是异步 OA

### Filtra.io 公开 Rust 角度面试 (2025 Helsing Engineer 访谈)
- Rust 是 Helsing 主力 backend 语言 (除 Python)
- 面试可能涉及 Rust idiom (ownership, async, lifetime) — 但**不强制要求面前会 Rust**, 可以 Python 答, 入职后学

> 来源: [filtra.io Helsing Rust 访谈](https://filtra.io/rust/interviews/helsing-jun-25)

## 7. 踩坑与社区评价

### 流程层面
- **20% positive Glassdoor**, 24 天 hire 周期 — 国防独角兽招聘 selectivity 极高
- **CSV exercise 解锁式题型**: 准备时多刷 "data parsing + multi-stage" 不是常规 LC
- **Mission fit 是 hard filter**: 反战 / 国防道德质疑明显的候选人会被拒, 哪怕技术满分

### 文化 / 国防风险
- **⚠️ 国防 mission**: 公司业务包括武器系统 (HX-2 strike drone) — 对部分候选人是 ethical hard no, 申请前要内心明确接受
- **⚠️ 涉密岗 nationality-restricted**: UK MoD / DE BMVg / NATO STANAG 项目要求 NATO 国国籍 + clearance; 中国籍即便拿到非涉密 offer, 内部转岗也受限
- **In-person bias**: Helsing 偏 office-based (Munich / Berlin / London / Paris / Stockholm), 远程很少
- **快速 scaling**: 250 → 700+ 人 2-3 年, mentorship / 流程未必跟上, "scrappy" 是常态

### 已知"坑"
1. **不要假设非涉密岗就 100% safe**: 业务线之间内部数据共享 / project transfer 可能触发 clearance gap
2. **Stockholm site 走 Saab partnership**: 文化 / IT / 流程与 Munich/Berlin 不完全一致
3. **HX-2 drone team in 乌克兰 deployment 公开**: 媒体曝光度高, 入职后亲属 / 学校 / 媒体可能关注
4. **不公开 intern stipend / Working Student rate**: 谈薪缺基准
5. **Visa 流程 Munich 高效 (4-8 周), London 较慢 (8-12 周 Skilled Worker)**: 跨国 transfer 复杂

### 对国际学生友好度
- **EU 国籍**: 极友好, 国际化文化
- **NATO 非欧 (US/UK/CA/AU)**: 友好, clearance 流程相对顺
- **中国籍**: 中-低友好度, 必须主动 disclose + 选非涉密岗 + 接受内部转岗受限
- **印度 / 巴西 / 拉美 / 中东**: case-by-case, 公开案例多见于 SWE 基础设施 / ML platform 岗
