## 3. 面试流程

- **总轮数**: 4-5 轮 (intern 3-4, full-time RS 5-6)
- **每轮形式** (基于 ML/Research roles):
  1. **Recruiter sync** (15 min)
  2. **Hiring Manager round** (45-60 min)
  3. **Problem solving no-coding** — 1 hr deep learning case study (e.g. 自动驾驶 perception design 思路) [来源 (实际打开过): https://www.glassdoor.co.uk/Interview/Wayve-Interview-Questions-E2225260.htm]
  4. **Programming** (1 hr DS&A)
  5. **PyTorch debugging** — 给 Google Colab notebook 含 CNN bug, 你 debug
  6. **VP leadership / Panel** (full-time)
- **题型分布**: DL case study 25% / Coding 25% / PyTorch debug 20% / ML breadth (RL + GenAI + multimodal) 20% / BQ 10%
- **难度评估**: 难度 2.93/5 (整体中等), ML Engineer 最难
- **OA 是否存在**: 部分 SWE 岗有 HackerRank-style 初筛; ML/Research 走 take-home / live

## 6. 申请渠道与建议

- **官网投递**: https://wayve.ai/careers/ → FirstStage ATS https://wayve.firststage.co/jobs (实时)
- **内推途径**: London King's Cross 集群效应, Science team 在 NeurIPS / CoRL 公开活跃; Wayve PI 直接 cold email 可能有效 (尤其 PhD 申请)
- **简历/背景要求**:
  - **PhD in robotics / ML / CV / RL** → Research Scientist Intern 主路径
  - **MSc / 强 BSc + PyTorch 项目** → SWE Intern / Applied Science
  - 自动驾驶 / 多模态 / GenAI / RL 项目大加分; 实车经验 (ROS / autonomous vehicle stack) 罕见且 highly valued
  - 论文 (CVPR / ICRA / CoRL / NeurIPS) 是 Research Scientist 入场券

## 7. 踩坑与社区评价

- **没有 Bachelor 直入 grad scheme** — 应届走 PhD intern / MSc thesis, 极少 Bachelor 直入 SWE (除非顶校 + 强 ML 项目)
- **ML Engineer 流程难度最高** — 据 Glassdoor; 建议先投 SWE / Applied Science 蹭 conversion
- **PhD intern 流程慢 (~29 天)** — 不要单押, 同时投 DeepMind / Meta Reality Labs / Toyota Research
- **公司在 SoftBank/NVIDIA $1B+ 后扩张快, 但行业风险** — self-driving timeline 不可预测, 接受 cash-heavy 而非 short-term liquidity 才适合
- **国际学生友好度**: 中高 (Skilled Worker license + intern visa relocation 都明文支持), 比 Synthesia 更 from-scratch friendly
