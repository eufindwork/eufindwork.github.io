## 1. 基本信息

- **欧洲办公室**: Amsterdam (HQ) / Sofia (Bulgaria, tech hub) / Istanbul (tech hub)
- **岗位类型**: iOS / Android / Backend / AI Engineer / Security Engineer (强 mobile-first 倾向)
- **招聘周期**: rolling, **无 cohort program**
- **重要截止日期**: 无固定 deadline, 全年滚动
- **IND Recognised Sponsor**: Yes (Bunq 官方 Bunq Together 自称 "primary choice for new skilled migrants to NL" [来源: https://careers.bunq.com/])

## Intern 路径

> ⚠️ **几乎不存在公开 intern 通道** — careers.bunq.com 当前 4 个 Amsterdam tech roles 全部为 Senior / Lead 级 (Senior iOS Developer, Lead Security Engineer, Senior AI Engineer, Android Developer), 无任何 Junior / Graduate / Intern 命名 [来源 (实际打开过): https://careers.bunq.com/]

- **岗位命名**: 无 official intern program
- **时长**: 偶发 stage 通常 4-6 个月 (荷兰高校标准)
- **申请窗口 + deadline**: 无公开窗口
- **薪资 (stipend gross/月)**: 无公开数据
- **资格**: 若有 stage 机会, 默认要求 NL 在读 (学生签即可)
- **Sponsor 政策 (intern)**: 不办 work permit; 仅接收已有 EU work rights / NL student visa
- **流程**: 无标准流程; 推测走 spontaneous application + 直接走 SWE 流程精简版
- **转 FT 率**: 无公开数据

## NG (New Grad / Junior 全职) 路径

> ⚠️ **NG 通道也匮乏** — Bunq 历史上招聘极度偏 Mid / Senior, careers 页 4 个 Amsterdam 岗 0 个 entry-level. Junior 通常通过 spontaneous CV submission 进入

- **岗位命名**: 无独立 NG cohort; 偶发 "Software Engineer" (无 level 标识, 实际偏 mid)
- **是否有独立 cohort program**: **No** — Bunq 风格更像快节奏 startup, 不办 graduate program
- **起薪 (base + bonus + equity)** (Levels.fyi / TechPays):
  - **Entry-level total comp**: **€39,338** (TechPays 8 data points) [来源 (实际打开过): https://techpays.com/europe/netherlands/bunq/entry-level] — **极低**, 比 Adyen / Booking entry 低 50%
  - Software Engineer (median Greater Amsterdam): **€56.2K** [来源 (实际打开过): https://www.levels.fyi/companies/bunq/salaries/software-engineer/locations/greater-amsterdam-area]
  - Bunq global SWE range: **€38.7K – €55.9K+** (Levels.fyi 全球范围)
  - **股权**: private company (CEO Ali Niknam 持大部分), equity allocation 不透明
- **Sponsor 政策 (FT)**: NL Kennismigrant. 2026 阈值 < 30 €4,357/月 ≈ €52.3K/年. **Bunq entry €39K 严重低于标准 HSM 门槛**, 必须走 **reduced HSM for recent NL master grads (€2,801/月 ≈ €33.6K)** 才能合规. 这是申请 Bunq 的关键风险.
- **申请窗口**: 全年 rolling
- **流程差异 vs intern**: N/A (intern 几乎不存在)

## 2. 签证与国际学生政策

- **是否支持非EU学生**: Yes (IND Recognised Sponsor) — 但**注意薪资匹配风险**
- **Intern vs FT sponsor 差异**:
  - Intern: 不办 (需 NL 在读)
  - FT: 办 Kennismigrant, 但 entry-level 薪资可能卡门槛
- **已知 sponsorship 案例**:
  - Bunq Together (官方 community) 自称 "primary choice for new skilled migrants to NL" [来源: https://careers.bunq.com/]
  - Dwayne Gefferie LinkedIn: NL fintechs Adyen / Mollie / **bunq** sponsor [来源 (实际打开过): https://www.linkedin.com/posts/dwaynegefferie_why-dutch-fintechs-adyen-mollie-and-bunq-activity-7185920215904309248-s52u]
- **2026 阈值**: NL Kennismigrant <30 €4,357 / 30+ €5,942 / **NL master grad reduced €2,801**
- **关键风险**: Entry-level base €39K = €3,250/月, **不到标准 HSM <30 阈值 (€4,357)**. UvA master 毕业用 reduced €2,801/月 OK, 但若直接从中国 fresh apply 未走 zoekjaar 路径, **可能无法 sponsor**

## 6. 申请渠道与建议

- **官网投递**: https://careers.bunq.com/
- **内推途径**: LinkedIn 直接联系 talent team; bunq 不依赖大学 career service
- **简历/背景要求**:
  - 强 mobile (iOS / Android / Kotlin / Swift) 或 backend (Java / Kotlin) 项目
  - 金融 / payments 相关经验加分
  - **English fluent, Dutch 非必须**
- **建议**:
  - **谨慎评估文化** — Glassdoor 全球 2.3/5 (Amsterdam 3.6/5), 多评论描述 "abusive and disrespectful culture", "late-night messages and weekend tasks as normal" [来源 (实际打开过): https://www.glassdoor.com/Reviews/bunq-Amsterdam-Reviews-EI_IE1007259.0,4_IL.5,14_IM1112.htm]
  - 适合追求 ownership / 快速 ship 风格的人, 不适合 work-life balance 优先者
  - 关注**薪资是否能过 HSM 门槛** — 务必谈到 base ≥ €4,357/月 (< 30) 或确认 reduced HSM 资格

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

- **Intern 可行性**: **低** — 无公开 intern 通道, 即使能拿到 stage offer, 文化风险大. 学生签技术上可 cover (16h 学期 / 40h 假期), Nuffic 走完即可, 无需公司额外 visa 办理
- **FT 可行性**: **中** — 走 zoekjaar 后申请 FT, 但有 **2 大风险**:
  1. Entry-level base €39K 卡在 HSM 门槛边缘, **必须确认 offer 是 reduced HSM 资格 (€2,801/月)** 或谈到 base ≥ €4,357
  2. Glassdoor 文化评分极低, 建议 entry-level 慎入
- **预计摩擦**: 
  - Intern: 高 (无通道 + 文化风险)
  - FT: 中 (薪资门槛 + 文化)
- **UvA 优势**: 
  - Bunq HQ 在 Amsterdam Naritaweg (Sloterdijk 区), **UvA Roeterseiland 校区地铁 20 分钟**
  - UvA 校友在 Bunq 有一定数量但 turnover 高
- **建议申请时间窗**:
  - 全年 rolling, 但建议**先拿其他 offer (Mollie / Adyen / Booking) 作 backup** 再考虑 Bunq
  - 仅在以下情况优先选 Bunq: (a) 强 mobile / Kotlin 背景 (b) 追求快节奏 startup 经验 (c) 已有 Senior+ 经验, 不是初出茅庐
