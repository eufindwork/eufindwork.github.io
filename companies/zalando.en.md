## 2. Role Profile

### 2.1 Software Engineering Intern
- Tech stack: Java (primary), Kotlin, Scala (some legacy teams), Python, Node.js / TypeScript, React, AWS (heavy, almost entirely on AWS), Kafka, Postgres, DynamoDB, Kubernetes, Microservices.
- Team directions: Catalogue, Customer, Pricing, Returns, Loyalty, Payments, Search & Recommendation, Partner / Marketplace, ZEOS (B2B fulfillment), Fashion Store frontend.
- Expectations: solid OOP / SOLID / design patterns, experience with microservices + REST / event-driven, familiar with at least one JVM language.

### 2.2 Machine Learning / Applied Science Intern
- Tech stack: Python, PyTorch / TensorFlow, Spark, Databricks, AWS SageMaker / EMR, Airflow, Kubeflow, internal ML Platform; recommendation and CV teams also use GPU for heavy embedding training.
- Team directions: Recommendation, Search Ranking, Sizing & Fit, Fashion Image Understanding, Fraud, Marketing Mix Modeling, Pricing, Generative Fashion Assistant.
- Expectations: MLOps mindset (CI/CD, monitoring, reproducible pipelines), understanding of paper → prototype → production end-to-end.

### 2.3 Data Engineering / Data Science Intern
- Tech stack: Spark / Scala / Python, SQL (heavy), dbt, Airflow, Databricks, AWS (S3 + EMR + Glue + Athena), Tableau / Looker.
- Team directions: Data Platform, Business Analytics, Marketing / Growth Analytics, Customer / CRM, Logistics.
- Expectations: strong SQL, familiar with modern data stack, strong statistics, can articulate "problem → data → experiment → conclusion".

## 3. Interview Process

### 3.1 General structure (intern/early career)

1. **Recruiter Screen** (30 min) — background, motivation, visa (key: "do you already have EU work rights?"), salary expectation.
2. **Codility Online Test** — 60-90 minutes, 2-3 questions, including 1 Java/Python algorithm + 1 SQL + 1 DSA; heavily dependent on IDE habits.
3. **Take-home Assignment** (some roles) — design + implement a small service (Java/Kotlin microservice) or ML task; usually within 1 week.
4. **Technical Interview** (1-2 rounds, 60 min)
   - SWE: project deep dive + medium LC + System Design (microservices / REST API / DB choice / caching / Kafka).
   - ML / DS: take-home review + ML concept deep dive (MLOps, A/B experiments, model choice) + 1 coding / SQL question.
5. **Hiring Manager / Team Match** (45-60 min) — behavioral + team alignment.
6. **Final / Panel** (some roles) — chat culture + system design with cross-team seniors.

Overall cycle: **average 32 days** (Glassdoor).

## 5. Visa and Cross-border Work

- **EU/EEA students / residents**: free to work; preferred candidates.
- **Non-EU studying in Germany**: can do **mandatory internship (Pflichtpraktikum)** with *Aufenthaltserlaubnis* student residence — doesn't count toward 120 full-day / 240 half-day / year work cap; **voluntary internship (freiwilliges Praktikum)** does count.
- **Overseas applicants**: Zalando explicitly **does not sponsor internships / apprenticeships visas**; non-EU candidates must solve legal status in Germany first.
- **Full-time graduates**: can use EU Blue Card (2025 threshold ~€45,300/year, slightly lower for shortage occupations); Zalando often sponsors permanent roles.
- **Helsinki**: similar to Germany, needs EU work rights or Finnish student residence permit; Future Talent Program same legal status requirement.

## 6. Application Strategy & Timeline

| Stage | Time | Notes |
| --- | --- | --- |
| Job posting | Year-round rolling, main batches Nov-Mar | Apply via jobs.zalando.com, **email submission not accepted** |
| Application screening | 1-2 weeks | Resume keywords: Java / Kotlin / Microservices / AWS / Kafka / Spark / SQL |
| Recruiter call | 1-2 weeks | Must ask "do you already have EU work rights" |
| Codility | Within 1 week | OA-level difficulty, mind the time |
| Take-home (if any) | 1 week | README + unit tests + CI config = scoring boost |
| Tech + HM | 2-4 weeks | Cross multiple interviewers, schedule slips easily |
| Offer | Average 32 days (intern 18 days) | 1-2 week decision window |

Application tips:
- Zalando is **Germany's #1 engineering hub of Berlin tech scene**, applicant numbers extremely high each year, overseas candidates significantly disadvantaged (visa reasons); prioritize:
  1. Resume highlights Java/Kotlin + microservices + AWS / Kafka projects; ML/DS highlights end-to-end projects + MLOps.
  2. Familiarize with Codility (practice codility lessons 1-10 online).
  3. High-quality take-home: unit tests + dockerfile + README explaining "why this design + trade-offs".
- Helsinki Future Talent is a very cost-effective entry: short cycle, high conversion rate, slightly more friendly to overseas applicants (still need EU/Finnish visa).
- Master Thesis is another efficient channel, particularly for ML / DS.
- Werkstudent suits students already studying in Germany, long-term accumulation, referral to full-time before graduation.

## 8. Key Risks / Notes

1. **Does not sponsor visas**: this is Zalando's biggest intern blocker; overseas candidates need to solve student visa / Blue Card dependent / free work rights in advance.
2. **Long process + Codility is hard gate**: heavy load, tight time; easy to slip for those unfamiliar with Codility.
3. **Take-home grading strict**: just running isn't enough, need to show engineering quality: unit tests, README, design trade-off explanation, CI.
4. **Large org, slow processes**: 32 days average; many people report recruiter communication slow / cross-squad coordination hard.
5. **Intern salary not high**: €1,500-2,500/month, Berlin rent ~€600-1,200 single room, net after tax is limited, plan budget yourself.
6. **AI / Fashion AI direction is clear plus**: 2024-2025 heavy investment in recommendation / sizing / generative assistant, resume + interview story should touch this.
7. **Praktikum vs Werkstudent distinction**: overseas candidates need to be clear whether you're "mandatory internship (Pflicht)" or "voluntary internship (Freiwillig)"; the former doesn't count toward 120 workday cap.
