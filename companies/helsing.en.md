## 2. Visa & International Student Policy

**Core conclusion: Sponsor visa + relocation for non-classified roles; classified / NATO classified roles nationality-restricted**

| Dimension | Policy |
|------|------|
| Supports non-EU students | **Conditional Yes** — non-classified IC SWE/ML/Infra roles process Blue Card / Skilled Worker / Passeport Talent; **classified roles No** (need NATO country nationality + clearance) |
| Requires work auth | **No** (non-classified) — company processes Blue Card / Skilled Worker |
| Chinese nationality OK roles | Commercial SaaS / infrastructure / DevOps / some ML infra (non-weapon systems) — still need case-by-case email confirm |
| Chinese nationality NOT OK roles | UK MoD partnership / DE BMVg classified projects / HX-2 weapon systems / NATO STANAG classified data — mandatory NATO country nationality + clearance |
| Known sponsorship cases | Drone Field Eng JD marked visa-friendly [Source (verified opened): https://jaabz.com/jobs/162773-drone-field-engineer]; LinkedIn shows multiple non-EU nationality engineers onboarded in Munich/London (India/Brazil/US background common; public Chinese nationality cases sparse) |
| Field Engineer travel | UK/FR/DE testing site frequent travel, visa stamp flexibility required |

**Feasible paths for Chinese international students**:
1. **Strongly recommended**: before applying **email HR directly** stating nationality + target role, let Helsing confirm if role is nationality-restricted (Helsing recruitement@helsing.ai)
2. **Target Munich non-classified SWE / Infra / ML platform role**: Chinese nationality can apply Blue Card, process same as other Munich tech companies
3. **Avoid**: HX-2 drone team / UK MoD partnership / NATO classified teams
4. **Working Student (DE only)**: holding DE student visa + enrolled in DE university, no additional visa needed; but **defense attribute same applies — classified projects still restricted**
5. **PhD / top conf ML background**: go Foundation Model Research role, usually publication-driven, nationality restriction looser

## 3. Interview Process

> Glassdoor data: SWE difficulty 3.4/5, 20% positive, average 26-day hire cycle

- **Total rounds**: SWE full-time ~5 rounds / Intern ~3-4 rounds
- **Each round format**:
  1. **Recruiter Call** (30 min): role / location / nationality / clearance fit
  2. **Hiring Manager** (45-60 min): past projects + technical depth
  3. **Technical Coding** (60-90 min): **CSV exercise** — "Leetcode-style CSV handling, unlocks stage by stage, data extracted from CSV to correct DS and processed by requirement" (Glassdoor 2026-02 Berlin SWE original) [Source: https://www.glassdoor.com/Interview/Helsing-Software-Engineer-Interview-Questions-EI_IE6763957.0,7_KO8,25.htm]
  4. **System Design + Domain** (60 min): real-time data processing / sensor fusion / distributed inference and other scenario design
  5. **Culture / Mission Fit** (45 min): defense mission alignment (Helsing emphasizes "defending democracies", candidates with obvious anti-war / ethical concerns not suitable)
- **Question type distribution**: Coding (CSV exercise + algorithm) 40% / system design 30% / Domain (ML / Robotics / Defense scenario) 20% / BQ + mission fit 10%
- **Difficulty assessment**: Medium - Hard; CSV exercise itself not hard but stage-unlock requires solid engineering foundation
- **OA exists**: CSV exercise close to OA form but usually live, not async OA

### Filtra.io public Rust angle interview (2025 Helsing Engineer interview)
- Rust is Helsing main backend language (besides Python)
- Interview may involve Rust idiom (ownership, async, lifetime) — but **doesn't mandatorily require Rust pre-interview**, can answer in Python, learn after onboarding

## 7. Pitfalls & Community Reviews

### Process Level
- **20% positive Glassdoor**, 24-day hire cycle — defense unicorn hiring selectivity extremely high
- **CSV exercise unlock-style question**: when preparing practice more "data parsing + multi-stage" not regular LC
- **Mission fit is hard filter**: anti-war / defense ethical question obvious candidates will be rejected, even if technically perfect

### Culture / Defense Risk
- **⚠️ Defense mission**: company business includes weapon systems (HX-2 strike drone) — ethical hard no for some candidates, must internally clearly accept before applying
- **⚠️ Classified roles nationality-restricted**: UK MoD / DE BMVg / NATO STANAG projects require NATO country nationality + clearance; Chinese nationality even getting non-classified offer, internal transfer also limited
- **In-person bias**: Helsing biased office-based (Munich / Berlin / London / Paris / Stockholm), remote rare
- **Fast scaling**: 250 → 700+ in 2-3 years, mentorship / process may not keep up, "scrappy" is the norm

### Known "pits"
1. **Don't assume non-classified role is 100% safe**: business lines internal data sharing / project transfer may trigger clearance gap
2. **Stockholm site through Saab partnership**: culture / IT / process not fully consistent with Munich/Berlin
3. **HX-2 drone team in Ukraine deployment public**: media exposure high, post-onboarding family / school / media may notice
4. **No public intern stipend / Working Student rate**: salary negotiation lacks baseline
5. **Visa process Munich efficient (4-8 weeks), London slower (8-12 weeks Skilled Worker)**: cross-border transfer complex

### International Student Friendliness
- **EU nationality**: extremely friendly, international culture
- **NATO non-EU (US/UK/CA/AU)**: friendly, clearance process relatively smooth
- **Chinese nationality**: medium-low friendliness, must proactively disclose + choose non-classified role + accept internal transfer limit
- **India / Brazil / Latam / Middle East**: case-by-case, public cases common in SWE infrastructure / ML platform roles
