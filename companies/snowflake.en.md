## 2. Visa & International Student Policy

- **Berlin (Germany)** — R&D hub with highest internationalization, Blue Card direct sponsor; intern status uses student visa (Working Student route) or J-1-style intern visa, 4-6 month internships need to confirm school can issue mandatory internship certificate first
- **Warsaw (Poland)** — multiple intern reqs (Backend / AI-ML / Document AI / Engineering Systems / Research), international students use student residence permit, work hours not exceeding 20h/wk during term / full-time during vacation, full-time Blue Card threshold low and easy to meet [Source (verified opened): https://careers.snowflake.com/us/en/warsaw-poland]
- **London (UK)** — no SWE intern, **avoid**; full-time senior only goes via Skilled Worker route
- **Amsterdam (NL)** — engineering roles extremely few (mainly Commercial Solution Engineer), **don't include Snowflake Amsterdam in NL engineering internship targets**
- **Dublin (IE)** — same as above, Cloud Support primary, **not SWE internship direction**
- **Paris (FR)** — same as Amsterdam / Dublin, GTM primary
- **Intern duration**: Berlin posting **explicitly writes minimum 4 months, recommended 6 months, max support 12 months**, start date flexible (matches German mandatory internship + French stage 6-month convention) [Source (search result): https://www.glassdoor.com/Interview/Snowflake-Berlin-Interview-Questions-EI_IE928471.0,9_IC2622109.htm]
- **School / degree**: BSc/MSc in study, "Computer Science / Computer Engineering / EE / Physics / Math or related"; PhD leans Research Intern (AI) path
- **Conclusion**: International student EU engineering intern path = **Berlin or Warsaw two-choice**, treat other European offices as GTM companies

## 3. Interview Process

| Round | Content | Duration | Notes |
|---|---|---|---|
| 1. Recruiter Screen | CV / motivation / timing | 30 min | English, occasionally asks visa |
| 2. OA (HackerRank) | **3 questions, 90-120 min**, DP / Graph / String / Array, "harder than FAANG" | 90-120 min | C++ / Java / Python any, "correctness + efficiency" dual standard [Source (verified opened): https://medium.com/@sonavikash733/snowflake-berlin-software-engineering-intern-coding-test-0f00a57d422e] |
| 3. Technical Phone 1 | Coding, similar to OA difficulty, but verbal thought process | 60 min | LRU Cache, Range Module, interval merge etc. "engineering implementation-type" questions [Source (verified opened): https://learncswithus.com/2025/07/21/snowflake-onsite-interview/] |
| 4. Technical Phone 2 | Coding 2 (intern may merge) | 60 min | Sliding window / line sweep / TreeMap |
| 5. (Full-time/IC2+) System Design | log ingestion / distributed buffer / query optimization, leans database internals | 60 min | Emphasizes trade-off, "infra-level thinking" |
| 6. Behavioral / Hiring Manager | team conflict, technical decisions, ambiguous situation | 45-60 min | Hires culture fit + long-term match |

**Overall duration**: Glassdoor company-wide average **29 days**; intern fast track ~1 day [Source (search result): https://www.glassdoor.com/Interview/Snowflake-Interview-Questions-E928471.htm]; smooth candidate reports **referral 1/12 → offer 2/7 (~4 weeks)** [Source (search result): https://www.1point3acres.com/bbs/interview/software-engineer-482586.html]

**OA filter heavy hit zone**: 3 questions 120 min must AC 2.5+ to have a chance; DP / BFS / DFS high frequency, boundary cases and time/space complexity both reviewed; one Berlin candidate "all AC but rejected for only using Python (no Java/C++)", **recommend preparing Java or C++ as well** [Source (verified opened): https://medium.com/@sonavikash733/snowflake-berlin-software-engineering-intern-coding-test-0f00a57d422e]

## 6. Application Channels & Advice

- **Official submission**: https://careers.snowflake.com/us/en/search-results — filter by "Berlin" / "Warsaw" + "Intern", Sep-Nov peak; note many reqs are US, verify location when applying to Europe
- **LinkedIn**: Follow Snowflake EMEA recruiters (Berlin / Warsaw each 2-3 UR recruiters mainly stationed), force select location filter
- **Referrals**: Snowflake referral system mature, 1point3acres long has internal referrer posts; Berlin / Warsaw R&D employees fewer, alumni higher pass rate than random employee
- **CV focus**:
  - **Required**: a system / infra project (database / distributed / OS / compiler / Storage any one), Snowflake highly values "engineering implementation completeness"
  - SQL depth (not CRUD, but query plan / optimizer concepts)
  - C++ or Java strong-typed language (Python only is OA fatal flaw)
  - LeetCode Hard DP / Graph experience (can write prefix sum, segment tree, union find)
- **Same-tier alternatives** (European R&D-heavy US data/cloud companies):
  - **Databricks** (Amsterdam) — same race competitor, Amsterdam actually has SWE intern
  - **Confluent** (London) — Kafka commercialization, London has SWE
  - **Elastic** (Amsterdam / fully remote) — same search/data
  - **MongoDB** (Dublin / Amsterdam) — DB same race
  - **AWS** (Berlin / Dublin) — cloud infrastructure

## 7. Pitfalls & Community Reviews

- **Pitfall 1: Don't apply SWE intern in London / Amsterdam / Dublin / Paris** — these offices mainly GTM (Sales / SE / Marketing / Support), LinkedIn London 800+ Snowflake roles SWE intern = 0, only intern is EMEA Communications Intern. Wasted time applying.
- **Pitfall 2: OA mandatory Java/C++** — One Berlin candidate on Medium all AC but rejected, presumed because only Python. Posting says "Excellent programming skills in C++ or Java"; don't only practice Python in preparation.
- **Pitfall 3: Intern conversion team-based, no candidate pool** — Glassdoor multiple reviews complain "no matter how hard you work, no team headcount means no return offer"; when choosing team, prioritize asking "what's your headcount plan this year".
- **Pitfall 4: Berlin office reputation polarized** — A Glassdoor 2022 review describes hiring manager "lacks basic interview / management training, zero psychological safety". Check Xiaohongshu / Blind / Glassdoor for corresponding team review before applying.
- **Positive**:
  - Berlin intern 4.3/5 (19 reviews), 100% recommend, salary competitive [Source (search result): https://www.glassdoor.com/Reviews/Snowflake-Intern-Reviews-EI_IE928471.0,9_KO10,16.htm]
  - Real production code (not toy projects), strong exposure
  - Berlin / Warsaw engineering culture international, English as working language, German/Polish not required
- **International student friendliness**: **Berlin ⭐⭐⭐⭐ / Warsaw ⭐⭐⭐⭐**, other European cities ⭐ (because no roles); full-time Blue Card sponsor smooth, intern visa needs school cooperation to issue mandatory internship certificate.
