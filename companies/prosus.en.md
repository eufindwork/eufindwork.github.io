## 3. Interview Process

- **Total rounds**: **3 rounds (standard IC/Intern)** / **4 rounds (PM / Trainee leadership roles)** — 1 round less than previous estimate of 4-5; Glassdoor 2025-07 AMS sample confirms 3 rounds [Source (verified opened): https://www.glassdoor.com/Interview/Prosus-Netherlands-Interview-Questions-E3405593.htm]
- **Each round format (standard IC/Intern, 3 rounds)**:
  1. **Online screening / Recruiter call** (30 min — motivation + resume + visa status)
  2. **Technical interview 1** (LC Medium / ML concepts / PyTorch + Huggingface framework details / system design fundamentals)
  3. **Technical interview 2 (incl. live practical case task)** — **NOT multi-day take-home**, but an on-the-spot 1-round case during the interview (product-flavored ML case, e.g. "Given an OLX fraud detection use case, propose ML approach + A/B test experiment"); evaluates product thinking + stakeholder management + culture fit
- **Extra round (PM / Trainee / Leadership)**: 4 rounds — adds 1 hiring manager + leadership round (PDT Lead / Trainee program lead), 90% motivation + behavioral; classic question "Describe a past AI/ML project + your contribution from PM perspective"
- **Topic distribution**: **behavioral / motivation ~50%** (Prosus weights this unusually high) + ML / case ~30% + algorithm ~10% + product / stakeholder ~10%
- **Difficulty**: **2.6/5** (Glassdoor average), 50% rate positive, notably lower than Booking / Optiver / Adyen [Source (verified opened): https://www.glassdoor.com/Interview/Prosus-Netherlands-Interview-Questions-E3405593.htm]
- **Apply → outcome timeline**: **2-4 weeks** (2025-02 sample 2 weeks, 2025-07 sample 4 weeks)
- **OA existence**: **no standalone OA**; case is a live 1-round practical task during interview, not a multi-day take-home sent home
