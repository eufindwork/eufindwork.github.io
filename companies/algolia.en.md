## 3. Interview Process

- **Total rounds**: 5 rounds, ~3-4 weeks [Source (verified opened): https://www.techinterview.org/companies/algolia-interview-guide/]
- **Each round format**:
  1. Recruiter screen (30-45 min)
  2. **60-min phone coding** (DSA medium-hard)
  3. Onsite (virtual): **2 coding rounds + 1 system design + 1 craft deep-dive + 1 behavioral/values**
  4. Engineering Manager round
  5. Final values conversation
- **Question type distribution**: Coding 40% / System design (search internals) 30% / Craft deep-dive 20% / Values 10%
- **Difficulty assessment**: **Medium-hard DSA** (string search / string algorithm focus — product related); compared to GAFAM more niche
- **OA exists**: usually none, phone coding substitutes; GitHub paas-coding-interview repo available for prep [Source (verified opened): https://github.com/algolia/paas-coding-interview]

## 7. Pitfalls & Community Reviews

- String search / Trie / suffix array are high-frequency questions — not preparing means failing round 2
- Craft deep-dive trips up outsiders — need to be able to discuss past project latency / scale numbers
- Paris HQ + SF dual HQ → remote collaboration timezone tiring
- IC3/IC4 in Paris starting £65K-£80K — slightly lower than Datadog Paris L1, but sponsor + relocation guarantee is plus
- International student friendliness high (relocation fully covered + public sponsor policy)
