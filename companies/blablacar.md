## New Grad / Junior 岗位

- **常见岗位名**: Junior Backend Engineer, Confirmed Backend Engineer (BlaBlaCar 用 "Confirmed" 表示 mid, junior 直接命名 "Junior"), Mobile Engineer, Data Engineer
- **欧洲地点**: **Paris (绝大多数 tech)**, Madrid (部分), Warsaw (部分)
- **是否有独立 Graduate Programme**: **No** cohort. 主入口:
  - **Stage de fin d'études** (M2 实习, 6 个月) → CDI
  - **Alternance** (1-3 年学徒制) → CDI
  - **Junior SWE 直 hire** (CDI, 0-2 年经验)
- **非EU签证 (全职)**:
  - **France**: French Tech Visa ~€43K/yr — BlaBlaCar Junior SWE base 约触发 (估算 €45-55K)
  - Passeport Talent – Salarié Qualifié €38,616/yr 是兜底
  - BlaBlaCar 公开是 accredited employer, sponsor 流程熟练 [来源 (实际打开过): https://www.eurotoptech.com/blog/visa-sponsorship-france-software-engineers-2026]
- **薪资范围 (Glassdoor / 社区数据)**:
  - **Junior Backend Eng Paris**: estimated base €45-55K (Glassdoor 数据较少, 比 Datadog/Algolia 略低)
  - **Mid (Confirmed) Backend Paris**: €55-70K base + 一些 RSU
  - **Senior**: €70-90K+
  - Levels.fyi BlaBlaCar 数据点稀, Glassdoor 主要是 mid+
- **申请窗口**: Rolling — stage 多在 1-2 月 (秋季 start) 和 6-8 月 (春季 start) 投递; alternance 7-9 月集中
- **面试流程差异 vs 实习**: 全职多 system design + values; intern 偏 case study + 1 tech round
- **录取竞争 / 国际生 friendliness**: 中. 法语**优先但非强制** (Paris HQ 工程部分 team 走英文), 海外 candidate 大量 sponsor 案例

## 3. 面试流程

- **总轮数**: 4-5 轮, 25-30 天平均, offer 通常 48h 内 [来源 (实际打开过): https://www.glassdoor.com/Interview/BlaBlaCar-Paris-Interview-Questions-EI_IE840434.0,9_IL.10,15_IM1080.htm]
- **每轮形式 (Backend)**:
  1. Recruiter screen (30 min)
  2. Hiring manager (深聊经验 + 期望)
  3. **Case study / take-home** (评估 hard + soft)
  4. **90-min live coding** with 2 SWE
  5. **60-min system design** with SWE
  6. Final values round
- **Frontend 新流程 (2024+)**:
  1. Design case study
  2. Code review
  3. Live coding (替代之前 7-day take-home) [来源 (实际打开过): https://medium.com/blablacar/how-we-revamped-our-frontend-interview-process-at-blablacar-dea082399dfa]
- **题型分布**: Live coding 40% / System design 25% / Case study 20% / Values 15%
- **难度评估**: 中. Medium DSA + 实战架构, 不偏竞赛
- **OA 是否存在**: 通常无, take-home / case study 替代

## 7. 踩坑与社区评价

- 流程**快** (25-30 天) + offer 48h, 在欧洲算高效
- Live coding 90 min 是杀手 — 不能光会写 algo, 要能讨论 trade-off
- Frontend 新流程对喜欢长 take-home 的人友好
- 法语虽非强制但 Paris team 文化偏法式, 完全不会法语 onboarding 慢
- 国际生友好度: 全职 sponsor 顺畅, 法语零基础工程 team 也 OK
