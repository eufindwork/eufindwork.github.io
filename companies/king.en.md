## Intern Path

- **Role name**: **Kingternships** — Design / Technology / Art / Data / Marketing and other multi-craft tracks
- **Duration**: **3-6 mo** [Source (verified opened): https://careers.king.com/us/en/early-careers]
- **Application window + deadline**:
  - Summer placements (Barcelona / London / Berlin): apply Oct-Dec previous year
  - Autumn placements (Stockholm / Malmö): apply Feb-Apr
  - Spring placements (Stockholm / Malmö): apply Sep-Nov previous year
- **Salary (stipend gross/month)**:
  - Barcelona Developer Intern reported ~€1,800-2,200/month (gamejobs.co historical JD)
  - Stockholm estimated SEK 25,000-30,000/month ≈ €2,200-2,650
  - Few public confirmed numbers, need to inquire directly students@king.com
- **Eligibility (education, local residency requirements)**: in school bachelor/master, some allow recently graduated ≤ 6 mo; local work visa default required
- **Sponsor policy (intern)**: official page not explicit; usually mobility gaming intern requires local work visa, but Microsoft integration may improve process for big company, contact students@king.com for case-by-case
- **Process**: Application form → recruiter screen → take-home / portfolio → technical/craft interview → final
- **FT conversion rate**: medium-high (King has long promoted Kingternship → grad role conversion as talent pipeline main channel)

> Kingternship public stipend numbers still sparse (2026-06 retry: King Early Careers page + Activision Blizzard early careers both say "fully paid / competitive" without numbers); table above Barcelona €1,800-2,200/mo + Stockholm SEK 25K-30K/mo numbers based on gamejobs.co historical JD + Stockholm/Barcelona dev market, recommend emailing students@king.com for confirmation when negotiating stipend.

## NG (New Grad / Junior Full-Time) Path

- **Role names**:
  - **Business Performance Trainee** — 18 mo rotation across 3 departments, then convert to formal role [Source (verified opened): https://careers.king.com/us/en/early-careers]
  - **Junior Game / Software Developer** — each studio hires independently
  - MBA Internship (single track for MBA students)
- **Whether there is a standalone cohort program**: Yes, Business Performance Trainee is formal cohort
- **Starting salary (base + bonus + equity)**:
  - **Stockholm SWE median SEK 695,882 total / year ≈ €60,500** (range SEK 579K-SEK 729K+) [Source (verified opened): https://www.levels.fyi/companies/king/salaries/software-engineer/locations/greater-stockholm]
  - **Barcelona SWE median €67.3K total** (range €52.3K-€67.3K+) [Source (verified opened): https://www.levels.fyi/companies/king/salaries/software-engineer/locations/greater-barcelona-area]
  - MSFT RSU + Activision bonus integration gives Microsoft stock
- **Sponsor policy (FT)**:
  - **Sweden certified employer (certifierat arbetsgivare)** — Migrationsverket 2-4 week fast track (vs 1-3 mo) [Source (verified opened): https://www.eurotoptech.com/blog/visa-sponsorship-sweden-software-engineers-2026]
  - Microsoft global mobility process stable; Barcelona / Berlin / London all have sponsor cases
  - 2026-06-01 Sweden work visa new threshold: median 90% (~SEK 31,500/month = €2,750/month = €33K/year), King SWE starting salary covers
- **Application window**: BP Trainee autumn open; Junior dev year-round rolling
- **Process differences vs intern**: full-time 4-5 rounds + technical deep dive + portfolio review (game industry standard)

## 3. Interview Process

1. Recruiter screen (30 min)
2. Craft interview (60-90 min — coding / game design / data analysis by track)
3. Take-home assignment (game-related; 5-10 hr)
4. Onsite / virtual onsite (3-4 rounds, incl. hiring manager + craft + values)
5. Final + Offer

> Gaming industry emphasizes portfolio + game taste; Tech track still tests LeetCode + system design.

## 8. Specific Assessment for UvA Students (NL student visa) ⭐

- **Core trade-off**: already in NL holding student visa → choosing King means **giving up NL zoekjaar (€2,801 reduced HSM)**, switching to SE certified employer / DE Blue Card / UK Skilled Worker / ES EU Blue Card
- **Intern feasibility**:
  - **Medium** — Kingternship policy open, but visa sponsor not explicit; big company may case-by-case, actively inquire students@king.com
  - Recommended strategy: spring/autumn Stockholm/Malmö intern, Sweden certified employer fast track, more stable than summer Barcelona/Berlin/London
- **FT feasibility**:
  - **Stockholm/Malmö → high** — Sweden certified employer 2-4 weeks fast, King SWE €60K covers 90%-median threshold
  - **Barcelona → medium-high** — ES EU Blue Card €67K covers; Microsoft mobility process stable
  - **Berlin → high** — DE Blue Card shortage €45,934, Microsoft sponsor strength strong
  - **London → medium** — Skilled Worker £41,700, King SWE usually covers
- **Estimated friction**: medium (cross-EU move + redo visa)
- **UvA advantage invalidated**: this company not in NL, no zoekjaar benefits
- **Recommendation**:
  - Want to do mobile gaming → **King is among the most stable sponsors of the 7 companies**; Stockholm is first choice (Sweden process + Microsoft mobility dual buff)
  - If want to stay in EU but language unburdened → Barcelona also great (English work environment, ES climate)
  - If user wants product / non-gaming → this company is off-target, go Spotify / Klarna
