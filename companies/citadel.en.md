## 2. Visa & International Student Policy

**Core conclusion: Citadel (HF) + Citadel Securities (MM) London both entities hold Skilled Worker license; FT sponsor active + relocation complete; intern via Tier 5 GAE / student work**.

- **Skilled Worker (full-time)**: Citadel Enterprise Europe Limited + Citadel Securities (Europe) Limited (Companies House 05462867) dual sponsor license holders (worksponsors.co.uk + huzzle-app graduate-jobs-with-visa-sponsorship-uk listed); FT base £150K+ far exceeds 2026 threshold £41,700 + SOC 2136 going rate £55K
- **Internship visa**: UK student Tier 4 vacation work; non-UK students via Tier 5 GAE; Citadel historically accepts US/CN/IN intern, visa process 1-2 months
- **Relocation package**: Official + industry reports — includes flight + 1-2 month temporary housing + **£5-15K relocation allowance** + visa fee reimbursement; intern provides corporate housing
- **EU 27 (post-Brexit)**: Same as non-EU Skilled Worker
- **Nationality restrictions**: None apparent, but trader / Quant Researcher path FCA SMCR background check strict
- **Remote**: London 5d/wk onsite (Citadel culture anti-remote); intern mandatory onsite (Summer Associate)
- **Transfer from London to NY/Miami**: Internal transfer via L-1 (US) / employment pass (HK/SG), common after 2+ years tenure
- **Datathon advantage**: top 10 performance can directly receive interview invitations (bypass OA + skip one tech round), this is best entry for international student without local network

## 3. Interview Process

| Round | Content | Duration |
|------|------|------|
| 0. Application | citadel.com/careers/ or citadelsecurities.com/careers/ → single application; referral helpful but not required | - |
| 1. HackerRank OA | 3-5 LC medium-hard, C++/Python choice, ~75-90 min; reject directly if not pass | 75-90 min |
| 2. Technical + behavioral phone 1 (45 min) | coding + DS/algorithm + project experience + "why Citadel" | 45 min |
| 3. Technical phone 2 (45-60 min) | deeper coding + algorithm; Quant Researcher adds probability + math | 45-60 min |
| 4. Team match | hiring manager looks at résumé + team match; multi-team interested → multi-round onsite | - |
| 5. Final onsite/virtual (4-6 rounds) | 2 coding + 1 system design + 1 behavioral + 1 senior chat + 1 cross-team match; Citadel Securities adds trading game / market making puzzle | 5-6 hr |
| 6. Offer | Average 28 days application → offer (efinancialcareers); total process 4-8 weeks |

**Citadel Specialties**:
- **C++ depth extremely strict**: move semantics / template meta / lock-free / memory model — more focused on low-level than Jane Street (OCaml-first)
- **System design includes low-latency topics**: design limit order book / pricing engine / risk system
- **trading game**: Citadel Securities path common — "imagine you market make X, how do you quote" — real-time thinking + communication
- **Datathon accelerated channel**: top performer direct onsite, skip OA + 1 tech
- **Citadel + Citadel Securities simultaneous review**: one application simultaneously connects 2 companies, recruiter internal routing
- Difficulty: Citadel Securities SWE OA "interview process rated 3.6/5", slightly heavier than HRT (3.5+)

## 6. Application Channels & Suggestions

- **Official site submission**: https://www.citadel.com/careers/ (HF) + https://www.citadelsecurities.com/careers/ (MM) — both entries accept same application; "you have the opportunity to talk with two firms at once"
- **Referral**: More useful than Jane Street/XTX/HRT — Citadel uses employee referral, résumé direct to recruiter; but not required (strong candidates direct apply also works)
- **Datathon accelerated channel**: Citadel + Citadel Securities self-hosted Quant Datathon (prize $100K+) — top performer direct interview invitation, best entry for international student without local network
- **CV focus**:
  - **Codeforces / IOI / Putnam / ACM-ICPC** significant plus
  - **C++ depth** (move semantics / lock-free / template) required for SWE; kdb+/q plus (Citadel heavy use)
  - **ML / math papers** required for Quant Researcher path
  - GPA + school prestige extremely important (Oxbridge / Imperial top; US MIT/CMU/Princeton/Stanford/Harvard)
  - Doesn't need finance background, but "interested in markets + fast mental math" plus
  - **Datathon ranking on résumé significant plus**
- **Same-tier alternatives**: Jane Street / HRT / XTX / Optiver / IMC / SIG / Two Sigma (HF) / Millennium / D.E. Shaw

## 7. Pitfalls & Community Reviews

- **Citadel + Citadel Securities simultaneous review = one application, two chances**: Don't apply separately; but also means both reject = neither can go
- **OA HackerRank is hard barrier**: 3-5 LC medium-hard, 75-90 min, reject directly if not pass; preparation suggestion is Neetcode 250 + LC top interview 100
- **C++ depth stricter than Jane Street**: Citadel SWE doesn't accept "I know OCaml but C++ so-so"; must be proficient in STL / move / template / memory model
- **Process relatively fast (28-day mean)**: Faster than HRT (4-8 weeks) / Jane Street (4-6 weeks); suitable for tight deadline application season
- **International student friendliness (UK visa)**: ⭐⭐⭐⭐⭐ — dual entity Skilled Worker license + £5-15K relocation + visa reimbursement; post-Brexit EU same as non-EU
- **Heavy overtime (60-70 hr/week)**: Citadel is one of the worst work-life in quant industry (vs XTX 45-55, HRT 50-55); Glassdoor work-life rating lower than Jane Street/HRT
- **Low failure tolerance (especially trader path)**: Quant Trader cut if not meeting PnL in 1-2 years; SWE/researcher path relatively stable, but senior senior still has manage-out pressure
- **Griffin directly reviews senior offers**: senior offer process includes Griffin personal OK, speed slows; new grad not affected
- **Datathon is best entry for international student**: Public path for those without local network to get interviews via datathon; historically multiple Chinese/Indian students entered via datathon
- **Glassdoor Citadel Securities 4.0/5** (371 reviews); compensation satisfaction top in industry, growth rating medium, work-life rating low
- **Mayfair misconception**: Citadel London previously at Berkeley Square Mayfair, now Citadel Securities (Europe) registered at **120 London Wall EC2Y 5ET** (City of London, not Mayfair); new office complete 2028
