## 3. Interview Process

- **Total rounds**: 3-4 rounds (intern), 4-5 rounds (full-time), ~2-4 weeks
- **Each round format (intern)**:
  1. Technical Recruiter call (30 min) — introduce multiple internship subjects, choose topic
  2. **Take-home technical assessment** — e.g. API implementing shortest path (Dijkstra / A*), evaluates code quality + unit tests + logging + secure headers [Source (verified opened): https://www.glassdoor.co.uk/Interview/Dataiku-Software-Engineer-Interview-Questions-EI_IE1037713.0,7_KO8,25.htm]
  3. Technical interview with engineer (deep-dive take-home, 1 hour)
  4. Final discussion + team fit
- **Question type breakdown**: Take-home 50% / Live coding 25% / Architecture 15% / BQ 10%
- **Difficulty assessment**: Medium. Take-home emphasizes production-readiness (unit tests + logging + documentation), not algo competition
- **OA exists**: Usually no separate OA, take-home replaces

## 7. Pitfalls and Community Feedback

- Take-home emphasizes production-readiness — no unit tests / logging means direct rejection
- Paris office in Gare de Lyon, convenient surrounding commute
- Dataiku is French unicorn but **valuation recently lowered** (2024), hiring slightly slowed (compared to 2022 peak)
- Junior SWE Paris starting salary ~€50K — much less than Datadog Paris L1 (~€70K base), but Dataiku stock + fast learning curve compensate
