# Delivery Hero Internship Intel (Berlin HQ)

> **Language**: [中文](deliveryhero.md) | English
>

> Scope: Software Engineering Intern, Data Analyst / Data Engineering Intern. Delivery Hero is a global food / grocery delivery giant operating in 70+ countries, with brands including foodpanda (Asia), Talabat (Middle East), PedidosYa (South America), Glovo (Southern Europe / Latin America, fully merged 2022), Yemeksepeti (Turkey), etc. Engineering HQ is primarily in **Berlin Mitte**.

## 2. Role Profile

### 2.1 Software Engineering Intern
- Tech stack: **Java / Kotlin (backend mainstay)**, **Go** (some Q-Commerce / Logistics services), Python (data / ML services), TypeScript + React (frontend), Kafka heavy use, AWS + GCP hybrid, Kubernetes, Postgres, DynamoDB, Redis.
- Team directions: Consumer App, Restaurant Platform, Logistics & Dispatch, Q-Commerce (Dmart), Payments & Fintech, Marketing Platform, AdTech, Global Discovery (Search / Recommendation / AI), Developer Platform.
- Expectations: ability to complete end-to-end microservices (design → implement → test → deploy), friendly with message queues / high concurrency.

### 2.2 Data Analyst / Data Engineer / Data Science / ML Intern
- Tech stack: SQL (extremely heavy, **almost all data role interviews have SQL**), Python, Spark, Airflow, dbt, Looker / Tableau, BigQuery / Redshift / Snowflake, Databricks (some teams).
- Team directions: Consumer Analytics, Restaurant Growth, Logistics Optimization, AdTech Analytics, Pricing & Promotions, Fraud & Risk, Recommendation / Search ML.
- Expectations: strong SQL + data modeling + business sense; ML direction needs familiarity with feature engineering, A/B experiments, recommendation systems.

### 2.3 Special: Data Labeler Intern (Multilingual)
- No engineering background needed; targets Chinese / Turkish / Arabic / Spanish, etc. native speakers; labels for Global Discovery (search / recommendation / NLP / multilingual).
- Nature: operations / data prep oriented, low salary, but low threshold, gives local work experience.

## 3. Interview Process

### 3.1 General Process (Internship + Early Engineering)

1. **Recruiter Screen (30 min)** — motivation, alignment with DH leadership principles, visa / EU work rights confirmation, salary expectations.
2. **Technical Interview I (60 min)**
   - SWE: project deep dive + 1 LC Medium (array / string / hashmap), + simple system design concepts (rate limiter / cache / pagination).
   - DA / DE: SQL live (window functions, JOIN, aggregation) + business case.
3. **Coding / Pair Programming (60 min on coderpad.io)**
   - SWE: live coding, including debugging, version control concepts (git workflow), environment setup, learning agility.
   - Some teams change to take-home.
4. **Hiring Manager / Senior Engineer Round (60 min)**
   - Project deep dive, asks "prioritize work, tackle problems, collaborate, empathy".
   - Advanced system design: rate limiter, Kafka consumer model, caching strategy.
5. **Final / Cultural Fit** (some processes)

Overall cycle: **2-4 weeks**, much faster than Zalando.

### 3.2 Tech Graduate Program (Sister Project to Internship, Often Viewed Together)

- Duration: 6 months, includes upskilling sessions, social activities, mentorship, 12-week capstone project.
- Process: Recruiter → Engineer round 1 (project + live coding) → Engineer round 2 (technical concepts: version control, debugging, environment) → Senior Engineer round (coding + soft skills).
- Eligibility: CS / DE or related Bachelor/Master, max 2 years work experience, 2 days/week Berlin Mitte office.

## 5. Visa & Cross-border Work

- **EU/EEA students / residents**: free to work; preferred group.
- **Non-EU studying in Germany**: student visa includes work rights (mandatory internships don't count toward 120/240 limit).
- **Overseas applicants**: internships generally not sponsored; but Delivery Hero is more willing to sponsor Blue Card at Senior positions (salary threshold 2025 ~€45,300 / year).
- **Full-time graduates** (TGP): typically sponsor EU Blue Card, provide relocation budget.
- **Cross-border**: Delivery Hero is a registered employer in Germany, can't work remotely outside EU; if interested in Talabat / foodpanda local teams, must go through corresponding country's process (Dubai / Singapore / Bangkok).

Application tips:
- **Overseas candidates**: since internship visa not sponsored, mainly rely on TGP or Master Thesis entry; Master Thesis is good way to bypass visa.

- Prepare Kafka / Redis / microservices Q&A, DH engineering Q&A likes to ask Kafka consumer model.
- Data Labeler internship friendly to non-EU students: language ability + Berlin student status is enough; can be stepping stone to Global Discovery team.
- Resume plus: projects in fintech / e-commerce / recommendation / delivery / Q-Commerce; Berlin school students (TU Berlin, FU Berlin, HU Berlin, HTW, Hertie School, CODE) have referral advantage.

## 8. Key Risks / Tips

1. **No internship visa sponsorship**: overseas candidates need Master Thesis or study in Germany first; high local student friendliness.
2. **Brand differences**: Berlin HQ mainly does platform / ads / recommendation / Q-Commerce; foodpanda Singapore, Talabat Dubai, etc. local teams go through each country's local process, different from Berlin process.
3. **Lower threshold + signal competition**: because DH hires many interns in Berlin, "high-quality but generic e-commerce projects" resume actually stands out more than fewer big-tech internships.
4. **Salary not high**: Berlin Praktikum monthly salary €1,200-2,000, limited after German tax and living costs; Berlin rent rising rapidly in last two years.
5. **Q-Commerce risk**: Dmart and other Q-Commerce business restructured multiple times (2022 shut down some countries), internship projects may be cut due to business adjustments.
6. **Kafka / microservices / SQL are high-frequency test points**: internship interviews also test Kafka model and SQL window functions; prepare in advance.
