## 3. Interview Process

- **Total rounds**: 3-4 rounds (intern 3, FT 4)
- **Each round format** (based on Bright Network JD + Speechmatics description):
  1. **Recruiter screen** (30 min): background + motivation
  2. **Technical interview** (60 min): Python + ML basics + speech / PyTorch project discussion
  3. **Take-home / project review** (some roles): give you a small speech / ML task, write code + explain
  4. **Final / team fit** (45-60 min): team + leadership
- **Question type distribution**: ML basics / PyTorch 30% / Coding 30% / Project deep-dive 25% / BQ 15%
- **Difficulty assessment**: medium — Cambridge small-medium ML company process usually friendly, doesn't intentionally grind questions
- **OA exists**: usually no separate OA, take-home substitutes

## 7. Pitfalls & Community Reviews

- **Company small size (~110 people)** — project depth good but promotion ladder less clearly tiered than big company; suitable for "wanting to deeply do speech 5+ years", not suitable for broad casting
- **Sponsor unclear** — most opaque sponsor policy of the 7 companies; overseas candidates strongly recommend email confirmation first
- **Salary transparency low** — "candidate-led and flexible" sounds good, but in practice candidate doesn't know anchor → use levels.fyi peers (ARM Cambridge / Microsoft Research Cambridge) for comparison in advance
- **Bright Network entry is historical posting** — not open every year, 2026 cohort opening needs to check careers page directly
- **Cambridge geography** — not in London, limited commute options (Cambridge local renting / train to London 45 min); if don't like small town lifestyle don't apply
- **International student friendliness**: medium-low (sponsor cases few + salary transparency low); suitable for UK enrolled MSc students as first job
