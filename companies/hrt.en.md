## New Grad / Junior Roles

> Information richness: ⭐⭐⭐⭐ (Quantt 4-track breakdown + Levels.fyi L1 $400K + Companies House £940k average pay + official student-opportunities status confirmed)

- **Common role names (key distinction — HRT uses 4 tracks)**:
  - **Algorithm Developer** (≈ other firms' "Quant Developer"): designs / builds / optimizes trading systems, directly interfaces with traders; **HRT's most famous entry point**; intern is called "Algorithm Development Intern"
  - **Software Engineer**: general engineering, infrastructure / data pipeline / tooling; intern is called "Software Engineering Intern"
  - **Quantitative Researcher**: math / ML driven, PhD heavy
  - **Quantitative Trader**: monitors + tunes live strategy, non-SWE path
  - **Hardware Engineer**: FPGA / ASIC digital logic design — **HRT's key niche distinguishing it from Jane Street**
  - **Core Engineer**: foundation infra / monitoring
  - **Systems and Networking**: low-latency network stack [Source (verified opened): https://www.hudsonrivertrading.com/student-opportunities/]
- **European locations**: **London (the only European office)**; other global offices NYC (HQ) / Chicago / Austin / Boulder / Singapore / Shanghai / Mumbai / Dublin
- **Whether there is a standalone Graduate Programme**:
  - **Summer Internship** (10-12 weeks, late May - mid Aug): SE / Algo Dev / PhD Algo Dev all open London; 2027 grads apply; **Summer 2026 already closed** (official page confirmed), next batch Summer 2027 opens ~2026-08/09
  - **Sophomore Internship**: **NYC only**, not in London (2028 grads, cross algo + SE rotation) — this is a brand confusion point
  - **Winter Internship** (Jan, 2-4 weeks): **NYC only**
  - **Women in Trading & Tech Internship**: **NYC only**
  - Full-time New Grad goes through "Full-Time → New Grad" filter, apply directly [Source (verified opened): https://www.hudsonrivertrading.com/student-opportunities/]
- **Non-EU visa (full-time)**: HRT London holds Skilled Worker license (Companies House three entities + FCA registered firm); algo dev / SWE FT base far exceeds UK 2026 threshold £41,700 + SOC 2136 going rate £55K; standard sponsor
- **Salary structure (London, gross/year)**:
  - **Intern (SE / Algo Dev)**: Global Levels.fyi reports **$145/hr ≈ $5,800/week** (NYC baseline); London estimated at 15-25% discount £4,200-£4,800/week, 11-12 weeks ~£50-60k stipend; **fully-paid housing + travel allowance + chef-prepared breakfast/lunch + dinner stipend** [Source (verified opened): https://www.levels.fyi/internships/Hudson-River-Trading/Software-Engineer-Intern/]

## 2. Visa & International Student Policy

**Core conclusion: HRT London holds Skilled Worker license, active FT sponsor; intern goes through Tier 5 GAE / student work**.

- **Skilled Worker (full-time)**: Hudson River Trading Europe Ltd + HRT Research Ltd + HRTSVC Ltd all three entities Companies House registered, holds FCA license; algo dev / SWE FT base £150K+ far exceeds 2026 threshold £41,700 + SOC 2136 going rate £55K
- **Intern visa**: UK student Tier 4 visa comes with vacation work; non-UK students go through Tier 5 GAE or Standard Visitor (HRT provides visa support, 1-2 months to complete)
- **Relocation package**: intern fully-paid housing (company rents corporate apartment) + travel allowance; FT provides flights + temporary housing (1-2 months) + reimbursed moving expenses + visa fees
- **Nationality restrictions**: none obvious, but trader / researcher path has strict background checks (FCA SMCR + position disclosure)
- **EU 27 (post-Brexit)**: same as non-EU, goes through Skilled Worker
- **Remote**: London office onsite 5d/week (HFT nature dictates — mandatory low-latency environment)
- **Transfer from London to NY/Singapore**: internal transfer via L-1 (NY) / employment pass (SG), common after 2+ years tenure

## 3. Interview Process

| Round | Content | Duration |
|------|------|------|
| 0. Application | hudsonrivertrading.com/student-opportunities/ or careers; referral is not a key bonus (HRT opposes nepotism) | - |
| 1. OA (HackerRank) | engineer: LeetCode medium-hard, C++/Python optional, 4 questions/90 min; researcher: probability + mental math + brain teaser | 90 min |
| 2. Tech phone 1 | algorithm depth + system knowledge (memory model / cache / OS); algo dev adds probability puzzle | 45-60 min |
| 3. Tech phone 2 (sometimes) | second round algorithm + probability + behavioral | 45 min |
| 4. Final onsite/virtual | **4-6 rounds**: 2 algo (coding + system design) + 2 culture/judgment + 1 manager + 1 team match; algo dev adds trading game / market making puzzle; hardware engineer adds live Verilog | 5-6 hr |
| 5. Offer | usually 1-2 weeks; overall 4-8 weeks application → offer |

**HRT specifics**:
- **"Green Book" probability questions appear frequently** (must-know for HRT Research / quant path): Central Limit Theorem intuition proof / Law of Large Numbers / Bayesian update / dice + coin EV
- C++ depth (move semantics / lock-free queue / memory alignment / branch prediction) — focuses more on low-level than Citadel/XTX
- **FPGA / hardware path is unique**: live Verilog module design (FIFO / arbiter / parser); HRT is one of the few firms hiring undergrad FPGA interns
- Doesn't require finance knowledge, but algo dev will ask "given an order book that looks like this, what do you think"

## 6. Application Channels & Advice

- **Apply via official site**: https://www.hudsonrivertrading.com/student-opportunities/ (Summer intern) + https://www.hudsonrivertrading.com/careers/ (full-time + new grad)
- **Referral**: not popular, **HRT is anti-nepotism**; officially says "considers non-traditional backgrounds if technically strong"
- **CV focus**:
  - **Codeforces / IOI / Putnam / ACM-ICPC** significant bonus (must-have for algo dev path)
  - **C++ depth** (move semantics / template metaprogramming / lock-free) strong bonus
  - **FPGA / Verilog experience** is a hard threshold for hardware path; FPGA 4 / Xilinx Vivado projects bonus
  - **High kaggle rank / ML papers** are entry tickets for researcher path
  - GPA + school prestige important (Oxbridge / Imperial / UCL / Cambridge top targets; US MIT/CMU/Princeton/Stanford)
  - Doesn't need finance background, but "interest in markets" bonus for algo dev path
- **Same-tier alternatives**: Jane Street (SWE) / Citadel Securities / XTX / Optiver / IMC / DRW / Tower Research / Two Sigma (HF leaning)

## 7. Pitfalls & Community Reviews

- **0.1% hit rate**: efinancialcareers reports NY intern 1 in 1000; London should be similarly stringent — don't treat HRT as the only choice
- **OA difficulty high**: HackerRank 3-4 questions LeetCode hard, 90 minutes; very hard for those who haven't systematically practiced LC; preparation suggestion is Neetcode 250 + EPI (Elements of Programming Interviews) C++ version
- **Green Book probability questions in depth**: must-read for Quant Research / Algo Dev path "A Practical Guide to Quantitative Finance Interviews" (by Xinfeng Zhou), HRT questions overlap significantly
- **Slow process**: 4-8 weeks application → offer; wait 1-2 weeks after Final round
- **International student friendliness (UK visa)**: ⭐⭐⭐⭐⭐ — Skilled Worker license + intern fully-paid housing + FT relocation; post-Brexit EU students same as non-EU
- **Relatively moderate overtime**: vs Citadel's 60-70 hr/week, HRT generally 45-55 hr/week (Glassdoor work-life rating higher than Citadel)
- **Private company no IPO path**: no RSU vest concerns when leaving, but also no IPO cash-out windfall; suitable for those pursuing stable high pay + engineering depth
- **London 50 headcount misinformation**: in early years (before 2015) HRT London was indeed ~50, **now 152** (Companies House 2024); don't use old data for decisions
- **Glassdoor 4.1/5** (company-wide); technical depth rating high, growth rating medium
