# Deezer (Paris) — Internship Intel

> **Language**: [中文](deezer.md) | English
>
> French local streaming music platform, Paris HQ, engineering team mid-sized (smaller than Criteo / Doctolib). Recommendation systems / audio research are highlights, but financial pressure heavy in recent years, internship slots fluctuate under multi-round layoff shadow. Suitable for M1/M2 enthusiastic about music/recommendation/audio ML.

## 3. Application Qualifications

| Item | Content |
|---|---|
| Education | M1/M2 engineering school/university; Research Intern leans M2/PhD |
| Language | Work language **French + English mixed** — many internal teams default French communication, one of the few Paris-area tech companies with high French weight. Non-French native speakers need intermediate-plus listening/speaking (B1+ suitable) |
| Programming | Python almost essential; backend role PHP/Go a plus (PHP is historical baggage); ML role PyTorch |
| Data | SQL must-test (intern HR all screens) |
| Research role | RecSys/audio papers, top venue (KDD/ISMIR/RecSys) a plus |

> **French language threshold note**: This is Deezer's key difference from Criteo/Mistral/HF. Hiring descriptions usually written in English, but internal standup/code review often in French. Not knowing French at all is **not disqualifying** (English-only teams exist), but honestly noting French level in resume/interview is important.

## 4. Hiring Process

| Round | Content | Duration |
|---|---|---|
| 1. HR phone screen | Motivation, school, time, French/English level, resume pass | 30 min |
| 2. Team 2-person phone/video | Project deep dive, DB/Python/system basic concepts | 30 min |
| 3. Onsite Tech 1 (with 2 engineers) | Live tech discussion, design/algorithms | 60 min |
| 4. Take-home Test | Python + SQL + design; 1-week completion | One week |
| 5. Onsite Tech 2 (Final) | Take-home defense + design follow-up | 60-90 min |

**Total length**: Some smooth 1 week; most candidates report 3-4 weeks; **many candidates report no response after take-home submission**, follow-up ghosting issue — recommend proactively chasing HR.

**Take-home characteristics**:
- Involves code (Python) + system design document
- Some have "optional" sections, not doing them gets compared and deducted (others will)
- Then onsite present to 2 engineers, follow-up on design choices

**HR screen common questions**:
- "Difference between data lake vs data warehouse?"
- SQL JOIN types / window function
- Python list comprehension, generator, decorator

## 7. Culture, Work Environment, Soft Intel

- **Office**: Paris 9th arr., "music-themed" decor, has podcast studio
- **Atmosphere**: More "French" than Criteo — internal social language more French, long lunch culture
- **Music culture**: Employees universally passionate about music, teams go to concerts together
- **WLB**: Generally reported good, little overtime
- **Company risk**: Financial pressure, 2023-2024 had layoffs; internship slots fluctuate by year. Confirm careers page active before applying
- **Tech stack warning**: Core codebase still has lots of legacy PHP — to do modern Go/Rust projects, pick right team
- **Deezer Research**: Separate research department, paper output stable (KDD, RecSys, ISMIR), suitable for undergrad/M1 stage planning PhD
