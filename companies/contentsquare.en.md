## 3. Interview Process

- **Total rounds**: 4 rounds, average 14 days (some 2-4 weeks) [Source (verified opened): https://www.glassdoor.com/Interview/Contentsquare-Software-Engineer-Interview-Questions-EI_IE1106723.0,13_KO14,31.htm]
- **Each round format**:
  1. **Coding Game Challenge** — MCQ + problem-solving (similar to CodinGame), first-step filter
  2. Hiring manager screen (experience + expectations)
  3. Manager interview (thinking + tech + design pattern)
  4. **Technical interview (90 min)** — live coding DSA + tech stack questions (Node.js / TS)
- **Question type breakdown**: Live coding 40% / Coding Game OA 25% / Design / system 20% / BQ 15%
- **Difficulty assessment**: **3.2/5 difficulty** (Glassdoor), medium DSA + practical Node.js/TS
- **OA exists**: **Yes (Coding Game Challenge is mandatory first step)** — similar to CodinGame / Codility

## 7. Pitfalls and Community Feedback

- Coding Game OA is the first-step hard filter — fail it without prep, you're out
- 90-min live coding is intense — DSA medium + tech stack questions double-duty
- Contentsquare went through layoffs 2023-24 (integration with Heap acquisition), 2025-26 hiring recovering
- Paris SWE median €68.7K — mid-range in Paris, 10K+ less than Datadog but slightly higher than Dataiku
- International student friendliness: Full-time sponsor smooth, internship requires self-held student visa
