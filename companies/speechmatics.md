## 3. 面试流程

- **总轮数**: 3-4 轮 (intern 3, FT 4)
- **每轮形式** (基于 Bright Network JD + Speechmatics 描述):
  1. **Recruiter screen** (30 min): 背景 + 动机
  2. **Technical interview** (60 min): Python + ML 基础 + speech / PyTorch 项目讨论
  3. **Take-home / project review** (部分岗): 给你一个小 speech / ML 任务, 写代码 + 解释
  4. **Final / team fit** (45-60 min): 团队 + leadership
- **题型分布**: ML 基础 / PyTorch 30% / Coding 30% / Project deep-dive 25% / BQ 15%
- **难度评估**: 中等 — Cambridge 中小型 ML 公司流程通常友好, 不刻意刷题
- **OA 是否存在**: 通常无独立 OA, take-home 充当

## 7. 踩坑与社区评价

- **公司体量小 (~110 人)** — 项目深度好但晋升 ladder 不像大厂分层清晰; 适合"想深做 speech 5+ 年"的, 不适合广撒网
- **Sponsor 不明** — 是 7 家中 sponsor 政策最不透明的一家; 海外 candidate 强烈建议先邮件确认
- **薪资透明度低** — "candidate-led and flexible" 听起来好, 实操是 candidate 不知锚点 → 提前用 levels.fyi 同侪 (ARM Cambridge / Microsoft Research Cambridge) 做对标
- **Bright Network entry 是历史 posting** — 不是每年都开, 2026 cohort 是否开放需直接看 careers page
- **Cambridge 地理位置** — 不在 London, 通勤选择有限 (Cambridge 当地租房 / 火车去 London 45 min); 不喜欢小镇 lifestyle 别投
- **国际学生友好度**: 中等偏低 (sponsor 案例少 + 薪资透明度低); 适合 UK 在读 MSc 学生作为 first job
