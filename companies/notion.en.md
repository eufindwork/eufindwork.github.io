## 3. Interview Process

- **Total rounds**: 4-5 rounds FT / 3-4 rounds intern
- **Each round format**:
  1. Recruiter screening (30 min, motivation + location flexibility)
  2. **Technical phone screen** (CoderPad coding, LC Medium-Hard)
  3. **Take-home** (Notion famous: given a small product feature spec, implement in a few hours — tests product sense + code quality)
  4. Virtual onsite: 2x coding, 1x system design (FT only), 1x BQ + product sense
  5. Hiring committee
- **Topic distribution**: algorithm ~35% + system design ~25% + **product sense / take-home** ~25% (Notion's signature) + BQ ~15%
- **Difficulty**: LC Medium dominates, Notion AI roles add LLM / retrieval / RAG; product sense is the scoring focus (can you think "if I were a Notion user, how would I use this")
- **OA existence**: Take-home more common than OA
