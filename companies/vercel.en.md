## Intern Path

- **Role name**: "Engineering Summer Intern" [Source (verified opened): https://vercel.com/careers/engineering-summer-intern-5628292004]
- **Duration**: 12 weeks summer (June-Aug)
- **Application window**: Nov-Feb (US/EU synchronized, single window)
- **Salary (stipend gross/month GBP / EUR)**:
  - **US intern**: $9,500-$11,000/month [Levels.fyi / Glassdoor verified numbers]
  - **London / Berlin intern**: estimated £6,500-£8,000/month (London) / €7,500-€8,500/month (Berlin) — proportional to US intern
  - Significantly higher than Sophos/Ocado intern, because Vercel intern total is extremely few (~10-20/year globally)
- **Eligibility**: Enrolled undergrad / master's, **extremely high bar** — usually requires GitHub / OSS contribution (Next.js, SWC, Turbopack repo PR preferred), or demo project (publicly deployed complex project)
- **Sponsor policy (intern)**:
  - Historically H-1B sponsor mainly US, EU intern no explicit public sponsor record
  - UK Student visa (Tier 4) holders can go — but must already be in UK
  - **NL student visa**: cannot directly intern UK / DE; Berlin Werkstudent needs EU work right
- **Process**: Resume → 90 min timed coding (CodeSignal-style, proctored, camera on) → 1-2 rounds tech + project discussion → behavioral; total ~3 weeks
- **Conversion rate to FT**: high (~70%, intern slots small, goal is funnel)

## NG (New Grad / Junior full-time) Path

- **Role names**:
  - **No independent "New Grad" track** — directly listed as "Software Engineer" (no level marker)
  - Vercel has extremely few entry-level roles, mainstream senior+ (Vercel internal level roughly maps IC3-IC5)
  - Occasionally "Software Engineer, DX" / "Software Engineer, Experimentation" — London [Source (verified opened): https://www.glassdoor.co.uk/job-listing/software-engineer-experimentation-vercel-JV_IC2671300_KO0,33_KE34,40.htm]
- **Whether there's an independent cohort program**: **None**
- **Starting salary (base + bonus + RSU)**:
  - **US New Grad TC**: $168K-$232K [Source (verified opened): https://6figr.com/us/salary/vercel--new-grad--cy]
  - **US SWE median TC**: $220K (P50) [Levels.fyi]
  - **London SWE base**: estimated £100-130K (Levels.fyi US median $220K adjusted to London ~50-60% = ~£100-130K), TC + RSU ~£140-170K
  - **Berlin SWE base**: estimated €110-150K, TC + RSU ~€150-180K
  - Actual London / Berlin public data is scarce (Levels.fyi mainly US samples), estimated from internal cross-region ratios
  - **Key**: Vercel doesn't separate "junior", base starts at senior level — but bar is also senior level, actual grad getting offer is extremely rare
- **Sponsor policy (FT)**:
  - **Vercel UK Limited** holds Skilled Worker license, A-rated [Source (verified opened): https://immigrationgpt.co.uk/company/vercel-uk-limited]
  - £100K+ base far exceeds SW £41,700 threshold + going rate £49,400 — **passes threshold extremely easily**
  - **DE Berlin**: Vercel GmbH historically no explicit sponsor signal, presumed can go Blue Card (€45,934 shortage threshold, Berlin SWE €100K+ far exceeds) — case-by-case
  - Actual constraint is **bar not visa** — Vercel hires single digits in EU per year, international grad hit rate <1%
- **Application window**: rolling open, no fixed cohort
- **Process differences vs intern**: 5 rounds (recruiter, coding, sys design, hiring manager, cross-team), 3 weeks

## 2. Visa & International Student Policy

- **2026 UK threshold**: Skilled Worker £41,700, NEC £33,400, going rate ~£49,400
- **2026 DE threshold**: EU Blue Card shortage (IT) €45,934, regular €48,300
- **Vercel UK Limited** Skilled Worker license active [immigrationgpt verified opened]
- **Vercel GmbH**: presumed sponsor license but no public sponsor record (small office)
- **Key reality**: visa is not bottleneck, **role count + bar** is. Vercel EU total headcount <100 (London ~30, Berlin ~30, remote ~30), opens 10-15 new roles annually
- **NL student visa path**:
  - UK: directly apply FT (intern doesn't open sponsor), needs IC3-IC4 level
  - DE Berlin: Blue Card can go, but extremely few roles
  - NL remote: Vercel some roles written "EU-friendly remote" — can ask

## 6. Application Channels & Advice

- **Official**: https://vercel.com/careers
- **Greenhouse**: https://job-boards.greenhouse.io/vercel
- **Advice**:
  - **Real threshold**: This is a senior-only company, grad conversion rate <1%. **Don't treat Vercel as main pipeline**, only as high-risk high-reward backup
  - If you insist on applying, **must**:
    - Public OSS contribution (Next.js / SWC / Turbopack repo PR merged) — strongest signal
    - Personal projects deployed on Vercel, demo complex (full-stack + edge functions)
    - In-depth blog / Twitter on Next.js / React / edge compute (Guillermo himself reads)
  - When applying **resume first page should put GitHub + Twitter handle**, referral path probability 3-5x higher
  - Skip regular SWE, apply **specific directions**: DX Engineer / Developer Advocate (slightly lower bar, NL student visa less sponsor friendly but can ask)

## 7. Pitfalls & Community Reviews

- **Layoffs**: 2023-04 + 2024-02 two small-scale layoff rounds, but 2025-2026 strong hire back (v0 + AI product explosion)
- **WLB differentiation**: SF / NY culture aggressive (60h/week), EU office relatively normal (~45h)
- **Stock price**: pre-IPO, 2024 valuation $3.25B (Series B), RSU is lottery — 2025-2026 IPO rumors but no confirmation
- **DX extremely strong**: internally uses own product, dogfooding culture, eng satisfaction high (Glassdoor 4.4/5)
- **EU hiring pace**: single Engineering Summer Intern + single digit FT/year, far less friendly than Cloudflare / Snyk
- **Berlin office status**: mainly product + design + DX, infra eng mostly SF; Berlin role often "remote-friendly" actually hopes to relocate

## 8. For UvA Students (NL student visa) — Specific Assessment ⭐

- **Core trade-off**: Vercel **unsuitable for UvA grad users**, unless you are Next.js core contributor or have extremely strong personal projects
- **Intern feasibility**: **Zero-extremely low**
  - Engineering Summer Intern ~10-20 slots globally, mostly in US
  - EU intern historically no public sponsor cases
- **FT feasibility**: **Extremely low**
  - Role bar is IC3-IC4 senior, grad hit rate <1%
  - Even if visa OK (Vercel UK holds SW), application pass rate extremely low
  - Levels.fyi London / Berlin data sparse, real EU hiring almost all senior+ hires
- **NL path**: Vercel **no NL office**, NL remote case-by-case
- **DE path**: Berlin can go Blue Card, but roles few and bar high
- **Estimated friction**: **Extremely high** (not visa friction, bar friction)
- **Advice**:
  - **Don't list Vercel as active pipeline** — UvA grad hard to hit
  - If React / Next.js / Turbopack depth is strong (has OSS PR), try a backup
  - Parallel apply: Algolia (French small unicorn, EU intern friendly), Datadog London (DX friendly + EU grad cohort), Stripe Dublin (Engineering Rotational Program — much more EU intern friendly)
  - **Real advice**: time on Snyk / Datadog / Stripe, not on Vercel
