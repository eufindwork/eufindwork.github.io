> **Language**: [中文](huggingface.md) | English
>
> Updated: 2026-10-10

## 2. Internship Role Types

HF has a dedicated intern cohort each year, usually announced all at once (see [huggingface.co/blog/interns-2023](https://huggingface.co/blog/interns-2023) etc.). Types span multiple teams:

| Role | Team | Keywords |
|---|---|---|
| ML Engineer Internship - ML for Code | Open Source / Science | CodeParrot, BigCode, Megatron-LM |
| ML Engineer Internship - WebML | Inference | TF.js / ONNX / WASM on-device inference |
| ML Engineer Internship - AI Art Tooling (Residency) | Diffusers | Stable Diffusion toolchain, artist collaboration |
| ML Engineer Internship - Audio | Audio / TTS / ASR | Whisper, Bark, MusicGen |
| Accelerate Internship | Open Source | Distributed training library feature |
| Text-to-Speech Internship | Open Source | TTS reproduction |
| Embodied AI Internship | Science | RL in simulators (LeRobot etc.) |
| Fast Distributed Training Framework Internship | Science | Large-scale training framework |
| Datasets for LLMs Internship | Science | LLM training datasets (FineWeb, FineFineWeb series) |
| Social Impact Evaluation Internship | Ethics / Policy | Generative model social impact evaluation |
| AI Resident (9-month residency) | Science | Similar to Google Brain residency, aim to publish papers |

**Locations**: Paris / Remote (EMEA, US) — most role descriptions say "Remote (location)", Paris is EMEA HQ but **the vast majority of interns choose remote**.

**Duration**: most 3-6 months; AI Residency 9 months.

## 4. Hiring Process

HF process is **lightweight + practical**, no whiteboard back-to-back:

| Round | Content | Duration |
|---|---|---|
| 1. Application submission | via Workable; **end requires a short project / proposal** (for role topic) | — |
| 2. Recruiter Call | initial background, interest, timing | 30 min |
| 3. Take-home Assignment | e.g.: write an HF Spaces demo, fix a transformers / diffusers bug, make a dataset card, run a small experiment + write report | few days to a week |
| 4. Take-home Review Call | you present + engineer follow-up | 45-60 min |
| 5. Team Fit / Meet team | 1-2 rounds video with team members, "getting to know" in nature | 30-45 min each |

**Key features**:
- **"collaborative and conversational, not adversarial"** — candidate feedback
- Doesn't require memorizing LeetCode, no algorithm trivia drilling
- Focus: how do you solve problems, how do you collaborate with teams, how do you contribute open source
- Feedback cycle may be slow: a Reddit user reported ~1.5 months before hearing take-home result
- Some negative feedback: individual reviewers didn't carefully review take-home, feedback "only 'good'"

## 7. Culture, Work Environment, Soft Intel

- **OSS-native**: your work is almost entirely in public, GitHub PR + Hub model card are your output
- **Async-first**: global team, time zones spread; Slack + GitHub + docs-driven
- **Diversity**: recruiting description repeatedly emphasizes welcoming underrepresented groups, this isn't lip service, HF internally is among the better in ML circle for diversity
- **No CV-cult**: school brand doesn't matter, contribution is hard currency
- **Pace**: slightly slower than Mistral, doesn't emphasize "thousand-card cluster extreme optimization", but as a platform company, infra/scale issues plenty
- **Paris office**: located near Paris 9th district; but vast majority of employees remote
- **Promotion path**: intern → conversion cases plenty, especially OSS already contributing
- **Real risk**: HF intern slots are announced by cohort, not always open; missing batch means waiting for next round
- **Residency vs Internship**: Residency is 9 months, full-time, can publish papers, aim "to become independent AI researcher"; Internship is 3-6 months following team on projects. **Residency is harder than internship to get in, same tier as Mistral PhD internship**

## 8. Application Strategy & Timeline Recommendations

| Step | Recommendation |
|---|---|
| 1. **Build OSS credit** (most important) | Submit at least 1-2 substantive merged PRs to transformers / diffusers / datasets / accelerate / peft / trl / lighteval. Bug fix is a starting point, but **new feature / model integration PR has highest value** |
| 2. Build HF Hub presence | Publish your own model + dataset card, at least 1 public Space (demo) |
| 3. CV revamp | First screen: your HF profile URL + GitHub stats + key PR list; school on second screen |
| 4. Short project proposal | The "short project" field at end of application is actually reviewed — write a specific technical proposal for the team / repo, 200-400 words |
| 5. Submission timing | HF intern cohort usually **announced in spring (March-April) concentrated**, follow [HF blog](https://huggingface.co/blog) + [Workable recruiting page](https://apply.workable.com/huggingface/); small rolling roles outside cohort |
| 6. Role selection | Whichever repo your OSS contribution is in, apply to that team's intern; applying to LLM data / training infra roles with no contribution has low match |
| 7. Take-home preparation | Practice HF Spaces (Gradio app) regularly; fine-tune on transformers; datasets streaming. Take-home is stringing these together |
| 8. Follow-up | Feedback cycle may drag to 1.5 months; can ping recruiter after 4 weeks of silence, but don't pester |
| 9. Alternatives | Same-tier OSS-friendly: EleutherAI, LAION, Allen AI (US remote), Cohere For AI, Stability AI, Together.ai; Paris same-tier: Kyutai, Mistral, Adept |
