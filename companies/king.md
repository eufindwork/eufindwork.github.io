## Intern 路径

- **岗位命名**: **Kingternships** — Design / Technology / Art / Data / Marketing 等多 craft track
- **时长**: **3-6 mo** [来源 (实际打开过): https://careers.king.com/us/en/early-careers]
- **申请窗口 + deadline**:
  - Summer placements (Barcelona / London / Berlin): apply Oct-Dec 前一年
  - Autumn placements (Stockholm / Malmö): apply Feb-Apr
  - Spring placements (Stockholm / Malmö): apply Sep-Nov 前一年
- **薪资 (stipend gross/月)**:
  - Barcelona Developer Intern 报道 ~€1,800-2,200/月 (gamejobs.co 历史 JD)
  - Stockholm 估计 SEK 25,000-30,000/月 ≈ €2,200-2,650
  - 公开 confirm 数字不多, 需直接 inquire students@king.com
- **资格 (学历, 当地居留要求)**: 在读本/硕, 部分允许刚毕业 ≤ 6 mo; 当地工签默认要求
- **Sponsor 政策 (intern)**: 官方页未明文; 通常 mobility gaming intern 需本地工签, 但 Microsoft 整合后大公司流程有改善空间, 联系 students@king.com 求 case-by-case
- **流程**: Application form → recruiter screen → take-home / portfolio → technical/craft interview → final
- **转 FT 率**: 中等-高 (King 多年宣传 Kingternship → grad role 转化是 talent pipeline 主渠道)

> Kingternship 公开 stipend 数字仍稀 (2026-06 retry: King Early Careers page + Activision Blizzard early careers 都说 "fully paid / competitive" 不挂数字); 上表 Barcelona €1,800-2,200/月 + Stockholm SEK 25K-30K/月 数字基于 gamejobs.co 历史 JD + Stockholm/Barcelona dev 行情, 谈 stipend 时建议直接邮件 students@king.com 求 confirm.

## NG (New Grad / Junior 全职) 路径

- **岗位命名**:
  - **Business Performance Trainee** — 18 mo rotation 横跨 3 部门, 然后转正式 role [来源 (实际打开过): https://careers.king.com/us/en/early-careers]
  - **Junior Game / Software Developer** — 各 studio 独立 hire
  - MBA Internship (single track for MBA students)
- **是否有独立 cohort program**: ✅ Business Performance Trainee 是正式 cohort
- **起薪 (base + bonus + equity)**:
  - **Stockholm SWE 中位 SEK 695,882 total / 年 ≈ €60,500** (range SEK 579K-SEK 729K+) [来源 (实际打开过): https://www.levels.fyi/companies/king/salaries/software-engineer/locations/greater-stockholm]
  - **Barcelona SWE 中位 €67.3K total** (range €52.3K-€67.3K+) [来源 (实际打开过): https://www.levels.fyi/companies/king/salaries/software-engineer/locations/greater-barcelona-area]
  - MSFT RSU + Activision bonus 整合后给 Microsoft stock
- **Sponsor 政策 (FT)**:
  - **Sweden certified employer (certifierat arbetsgivare)** — Migrationsverket 2-4 周快通道 (vs 1-3 mo) [来源 (实际打开过): https://www.eurotoptech.com/blog/visa-sponsorship-sweden-software-engineers-2026]
  - Microsoft 全球 mobility 流程稳; Barcelona / Berlin / London 都有 sponsor 案例
  - 2026-06-01 Sweden 工签新阈值: 中位 90% (~SEK 31,500/月 = €2,750/月 = €33K/年), King SWE 起薪 cover
- **申请窗口**: BP Trainee 秋季开放; Junior dev 全年 rolling
- **流程差异 vs intern**: 全职 4-5 轮 + technical deep dive + portfolio review (game industry 标配)

## 3. 面试流程

1. Recruiter screen (30 min)
2. Craft interview (60-90 min — coding / game design / data analysis 按 track)
3. Take-home assignment (game-related; 5-10 hr)
4. Onsite / virtual onsite (3-4 rounds, 含 hiring manager + craft + values)
5. Final + Offer

> Gaming industry 重 portfolio + game taste; Tech track 仍考 LeetCode + system design.

## 8. 对 UvA 学生 (NL student visa) 的具体评估 ⭐

- **核心 trade-off**: 已在 NL 持学生签 → 选 King 意味着 **放弃 NL zoekjaar (€2,801 reduced HSM)**, 换 SE certified employer / DE Blue Card / UK Skilled Worker / ES EU Blue Card
- **Intern 可行性**:
  - **中** — Kingternship 政策开放, 但 visa sponsor 没有明文; 大公司有可能 case-by-case, 主动 inquire students@king.com
  - 推荐策略: spring/autumn Stockholm/Malmö intern, Sweden certified employer 快通道, 比 summer Barcelona/Berlin/London 更稳
- **FT 可行性**:
  - **Stockholm/Malmö → 高** — Sweden certified employer 2-4 周快, King SWE €60K cover 90%-median 阈值
  - **Barcelona → 中-高** — ES EU Blue Card €67K cover; Microsoft mobility 流程稳
  - **Berlin → 高** — DE Blue Card 短缺 €45,934, Microsoft sponsor 力度强
  - **London → 中** — Skilled Worker £41,700, King SWE 通常 cover
- **预计摩擦**: 中 (跨欧搬家 + 重新做 visa)
- **UvA 优势失效**: 这家不在 NL, 无 zoekjaar 福利
- **建议**:
  - 想做 mobile gaming → **King 是 7 家中 sponsor 最稳的之一**; Stockholm 是首选 (Sweden 流程 + Microsoft mobility 双 buff)
  - 若想留 EU 但语言无负担 → Barcelona 也很好 (英语工作环境, ES 气候)
  - 若 user 想做 product / 非 gaming → 此公司不对口, 走 Spotify / Klarna
