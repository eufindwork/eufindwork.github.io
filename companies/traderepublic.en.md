## 2. Visa and International Student Policy

**Core conclusion: Blue Card sponsor explicit + Graduate SWE salary fully meets threshold**

| Dimension | Policy |
|------|------|
| Supports non-EU students | **Yes** — Nextleveljobs explicitly lists as Blue Card sponsor; multiple international engineer onboarding cases |

| 2026 Blue Card threshold | IT shortage €45,934/year (new grad within 3 yr + IT degree reduced €41,041.80); Graduate base €51,684 ≥ threshold |

**Feasible paths for Chinese international students**:
1. **Target Berlin full-time SWE / Graduate Programme**: apply directly, Blue Card handled by company, process 4-12 weeks
2. **Already studying in DE**: Werkstudent path (semester 20h/wk) is low-cost entry + conversion path
3. **Not in DE / EU**: apply directly to Graduate Programme, Blue Card standard process
4. **Plus points**: Java / Kotlin / Spring Boot backend stack + finance/payments/compliance (KYC / AML) background
5. **Pitfalls to avoid**: confirm role actually opens Blue Card sponsor before applying (most yes, but occasional EU-only roles)

## 3. Interview Process

> Glassdoor SWE average difficulty 2.8/5, 50% positive, 23-day hire cycle (Berlin fast side)

- **Total rounds**: ~4-5 rounds (full-time SWE) / 3-4 rounds (Graduate Programme)
- **Each round format**:
  1. **Initial Screening** (15-30 min): recruiter / HR call, role + visa + location fit
  2. **HM / Senior Engineer Chat** (45-60 min): past projects + Java/Kotlin / backend stack depth
  3. **Take-home Assignment + Discussion** (typically once): backend coding task (e.g. implement REST API + data persistence), 1h discussion after completion (architecture choices, trade-offs, optimization)
  4. **System Design** (60 min): design fintech scenarios (e.g. design trade execution engine / KYC pipeline / real-time price feed)
  5. **Product / Behavioral** (45-60 min): product mindset (fintech user scenarios / regulatory compliance trade-offs), team fit
  6. **Final / Onsite Berlin** (before offer): some roles require in-person at Berlin office (visa candidates can be remote)
- **Question type distribution**:
  - Backend: Java/Kotlin + Spring Boot implementation (40%) / system design fintech scenarios (30%) / Product / fintech domain (20%) / BQ (10%)
  - Frontend (Level Up Coding 2025 verification [Source](https://levelup.gitconnected.com/trade-republic-frontend-interview-experience-bc90ff24d544)): assignment-driven, React/TS, performance + state management focus
- **Difficulty assessment**: Medium; low LeetCode hard ratio, take-home + system design weighted higher (fintech industry convention)
- **OA exists**: no HackerRank-style timed OA, but take-home assignment (usually 4-8h) is standard

## 7. Pitfalls and Community Reviews

### Process layer
- **Take-home assignment time investment large**: prepare 8-12h, not just writing code but also writing design doc + trade-off explanation
- **Product / fintech knowledge is hidden threshold**: not understanding broker business / regulation / user protection will fail in product round
- **Berlin office bias**: most roles hybrid (3 days office), remote extremely rare; confirm location policy before applying

### Culture layer (Glassdoor aggregate)
- **Positive**: "Great mission, smart team, real fintech impact"; Nordic / Indian / Central European diverse team
- **Negative**: "Process heavy" (regulated industry), "stock options lack liquidity event"
- **Overall rating**: ~3.5-3.8 / 5 (Berlin SWE reviews)

### Known "pitfalls"
1. **Stock at grad/junior level is 0**: don't be misled by "Series D unicorn" imagining base — Graduate base €51K, total €59K, actual stock $0/yr
2. **Regulated industry slow process**: long decision chain, strict code review (financial regulation audit trail), unsuited for "move fast break things" personality
3. **Berlin cost of living rising**: 2026 Berlin rent has notably risen (€20-€25/m² downtown), Graduate base €51K disposable medium
4. **Vienna / Paris few opportunities**: harder to get to these two sites than Berlin
5. **Graduate Programme rotation doesn't guarantee final team**: after 12-18 months rotation then placement, wanting specific direction (e.g. AI agent) requires active expression + internal push

### International student friendliness
- **Extremely friendly policy-wise**: Blue Card public sponsor, Graduate salary meets threshold
- **Practically**: Berlin internationalization high (English working environment), process transparent
- **Chinese students**: many public cases; backend Java/Kotlin + fintech background is key signal
- **New grad friendly**: Graduate Programme is one of few cohort channels in EU fintech
