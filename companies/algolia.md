## 3. 面试流程

- **总轮数**: 5 轮, ~3-4 周 [来源 (实际打开过): https://www.techinterview.org/companies/algolia-interview-guide/]
- **每轮形式**:
  1. Recruiter screen (30-45 min)
  2. **60-min phone coding** (DSA medium-hard)
  3. Onsite (virtual): **2 coding rounds + 1 system design + 1 craft deep-dive + 1 behavioral/values**
  4. Engineering Manager round
  5. Final values 对话
- **题型分布**: Coding 40% / System design (search internals) 30% / Craft deep-dive 20% / Values 10%
- **难度评估**: **Medium-hard DSA** (string search / 字符串算法重点 — 与产品相关); 比 GAFAM 偏 niche
- **OA 是否存在**: 通常无, phone coding 替代; 有 GitHub paas-coding-interview repo 供准备 [来源 (实际打开过): https://github.com/algolia/paas-coding-interview]

## 7. 踩坑与社区评价

- String search / Trie / suffix array 是高频题 — 不准备会挂第 2 轮
- Craft deep-dive 难倒外行 — 要会讲过去项目的 latency / scale 数字
- Paris 总部 + SF 双总部 → 远程协作时区累
- IC3/IC4 在 Paris 起薪 €65K-€80K — 比 Datadog Paris L1 略低, 但 sponsor + relocation guarantee 是 plus
- 国际生友好度高 (relocation 全包 + 公开 sponsor 政策)
