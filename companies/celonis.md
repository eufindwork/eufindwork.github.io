## 3. 面试流程

> Galaxy: 平均 90 天 hire 周期 (Glassdoor 数据)

### Galaxy Graduate Programme 流程 (3 阶段, Glassdoor 实证)
1. **Recruiter Video Call** (30 min): 介绍 Galaxy program + 评估对齐度 + 候选人目标 fit
2. **Galaxy Program Manager Interview** (60 min): 理解候选人 motivation, 对 process mining 的兴趣, business case 讨论
3. **Senior Management Interview** (60 min): final fit + 业务问题 + 长期发展

### 全职 SWE 流程
1. **Recruiter Screening** (30 min): role + Blue Card + location fit
2. **Hiring Manager** (60 min): past projects + 技术栈 (Java / Python / Kotlin / Go 后端) 深度
3. **Technical Coding** (60-90 min): 算法 + LeetCode Medium 主体; 后端栈实现题
4. **System Design** (60 min): 设计 process mining engine / event log processor / GenAI agent fabric
5. **Culture / Team Fit** (45 min): mission fit (data-driven enterprise transformation)

### 题型分布
- Galaxy: Business case + 动机 + product sense (60%) / 行业理解 (process mining / ERP / SAP / consulting) (30%) / 软技能 (10%)
- SWE 全职: Coding (40%) / System design (25%) / Java/Python/Kotlin 后端 (20%) / BQ + culture (15%)

### 难度评估
- Galaxy: Medium (非纯技术, 重 business sense + 沟通)
- SWE: Medium - Medium-Hard (LeetCode Medium 主体, 部分 Hard, system design 是 mid+ 关键)

### OA
- Galaxy: 无 OA, 直接面试
- SWE: 偶发 HackerRank-style OA (Munich 全职 IC1-IC3 流程中可能出现)

### 流程速度
- Galaxy 90 天 hire (Glassdoor 数据, 较慢) — 多轮 program manager 评估
- SWE 全职 ~30-60 天

> 来源: Glassdoor Celonis Graduate Program Interview + interviewquery.com Celonis SWE Guide

## 7. 踩坑与社区评价

### 流程层面
- **⚠️ 关键踩坑: Intern / Werkstudent 不办 visa** — 不在 EU 学生不要浪费时间申, 公司明文 reject
- **Galaxy 流程 90 天**: 准备好长期等待 + 主动跟进 (太久不联系会丢人才)
- **Process mining 行业理解必须**: 不研究 Celonis 产品 + 客户案例直接被刷

### 文化 / 业务风险
- **企业 SaaS 巨头**: 流程严格, 不是"move fast break things"; 适合喜欢结构化 + enterprise 客户工作的人
- **IPO 候选**: 2025-2026 媒体讨论 IPO, 入职后 RSU 上行潜力大但有 lock-up
- **GenAI 转型期**: 2024-2025 推 GenAI agent fabric 是公司新增长点, junior 入职可能赶上这波技术 ramp-up
- **Munich vs Madrid vs London 文化差异**: Munich 严格 + 高薪 + 高物价; Madrid 国际化 + 中等薪资; London 高物价 + GTM 重镇

### 已知"坑"
1. **Intern 不办 visa (再次强调)**: 中国籍非 EU 学生想暑期实习 Celonis 几乎封死, 除非已在 DE/ES/UK 念书
2. **Galaxy rotation 不保证定岗**: 12-24 个月 rotation 后定岗依赖 program manager 评估, 想做特定方向需主动 push
3. **企业 SaaS 节奏**: 决策链长, code review 严格, 不适合纯 "research / 探索" 性格
4. **Munich 物价高**: 即便 IC1 base €69.8K, Munich 实际可支配低于 Madrid / Berlin
5. **Galaxy 平均 90 天 hire**: 不要把 Celonis 当 backup, 流程长 + 拖期高

### 对国际学生友好度
- **EU 国籍**: 极友好 (全职 / Galaxy / intern 都开)
- **非EU 全职 / Galaxy 候选人**: 极友好 — Blue Card 公开 sponsor, Levels.fyi 数据清晰, Galaxy 是 cohort 通道
- **非EU 学生 (想实习)**: ⚠️ 极不友好 — 明文不办 visa
- **中国籍 master / 新毕业 (在 EU 念书)**: 顶级友好 — 走 Werkstudent / Praktikum 转 Galaxy / 全职是清晰路径
