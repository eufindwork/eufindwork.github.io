## 2. 签证与国际学生政策

- **是否支持非EU学生**: **Yes** — Stripe 列为 Ireland CSEP **Trusted Partner** (与 Google / Meta / Microsoft / Apple / Datadog / HubSpot / Salesforce / LinkedIn 并列, priority 2–4 周 vs standard 8–12 周) [来源 (实际打开过): https://www.eurotoptech.com/blog/visa-sponsorship-ireland-software-engineers-2026]
- **是否需要提前持有工作许可**: No — Stripe 处理 CSEP 全流程; **配偶 Stamp 1G** 同步申请
- **已知的 sponsorship 案例**:
  - Stripe Dublin 历来稳定 sponsor 中国 / 印度 / 美国本土 new grad [https://nextleveljobs.eu/blog/visa-sponsorship/ie]

  - TCD intern → FT 是 standard pipeline
- **CSEP 关键数字 (2026)**: 门槛 €40,904; Trusted Partner 处理 2–4 周; intern 走 Atypical Working Scheme (90 天以内可免 CSEP)

## 3. 面试流程

- **总轮数**: 5 轮 FT / 3–4 轮 intern
- **每轮形式**:
  1. **HackerRank OA** (60 min, **1 道题分 3 个 sub-task**, 累进难度)
  2. Recruiter call (~20 min)
  3. **Technical phone screen** (CoderPad, integration / API design 题)
  4. **Onsite virtual loop** (4–5 轮): 2x coding (Stripe 风格 "build a system in 90 min" — 真实业务场景, 不是纯 LC), 1x bug squash / integration, 1x system design (FT) / project deep-dive (intern), 1x BQ
  5. Hiring committee review
- **题型分布**: **真实业务 coding** ~60% (Stripe 著名"build a billing system / rate limiter / idempotency layer" 风格) + system design ~20% + BQ ~20%
- **难度评估**: LC 上不常见的 "Stripe 风" 题 — 偏工程化, 强调代码 ship-able, 不是 trick; Glassdoor 难度 3.2/5, 通过率 62% (高于公司平均)
- **OA 是否存在**: Yes, HackerRank 60 min, 1 题 3 subtask 累进
- **总时长**: New Grad 平均 22 天, 整体 26 天

## 7. 踩坑与社区评价

- **Stripe 风格题 ≠ LeetCode**: 不要只刷算法; 练习 "build a real system in 90 min" — github 上搜 "Stripe interview problems" 或 join Taro
- **OA 看似简单, 实际有 trap**: 60 min 1 题 3 subtask, 后两 subtask 时间紧, 设计要前瞻 (sub-task 1 写死会 block sub-task 3)
- **Dublin 是真 eng hub**, 不是 commercial — 别申错 team (London 也有 eng 但 commercial 占比高)
- **Trusted Partner 优势真实**: 中国 / 印度 new grad 9 月入职最佳; 配偶 Stamp 1G 同时拿
- **Stripe AI 团队**: 招 ML / Applied AI / Risk ML, 2026 招聘明显加码 (Stripe 在做 payments fraud LLM 模型)
- **国际生 friendliness**: ⭐⭐⭐⭐⭐ — 中国新人 Dublin 入职报告普遍正面 (1point3acres / 一亩三分地)
- **常见挂点**: bug squash 轮没看 doc / Stripe API 用法 (面试前过一遍 https://docs.stripe.com 关键概念)
