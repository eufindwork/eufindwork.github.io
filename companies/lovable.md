## New Grad / Junior 岗位

> Lovable 没有 cohort-based Grad Program, **Junior / 新毕业** 走标准 Engineering job 招聘 — 但创始人在 HN 公开"sponsor visas + relocation packages, even for 1-year visits"是 EU 同类 AI 初创里最明确的国际生承诺

- **常见岗位名**: **Full-Stack Engineer** / **ML Engineer** / **Backend Engineer** / **Frontend Engineer** / **Infrastructure Engineer** (全部 in-person Stockholm 优先)
- **欧洲地点**: 以 **Stockholm 为主**, London 少量 remote-ish 岗位
- **是否有独立 Graduate Programme**: **No** — 没有结构化 grad cohort, 也无 rotation; 走"raw IC hire"路径
- **非EU签证 (全职)**:
  - **Sweden Work Permit (Migrationsverket)**: 2026 起 SE 要求月薪不低于 SE 全国中位数的 **80%** (约 **SEK 28,480/月 ≈ €2,500/月**, 即 **SEK 341.7K/年 ≈ €30K/年 gross**), Lovable Stockholm SWE entry-level base SEK 642K 远超 — 100% 符合
  - 注: SE 已酝酿提至 **100% median (SEK 35,600/月)**, 立法 2025-2026 进行中, 申请前需重新核对最新阈值
  - **EU Blue Card SE 路径**: Sweden 同样接受 EU Blue Card (2026 SE 阈值 ~ SEK 56,290/月 gross), Lovable SWE 薪资满足
  - **HN 原话承诺 (CTO @cviktore 2025-08)**: > "We sponsor visas and have very generous relocation packages (even if you just want to come for a year)." [来源 (实际打开过): https://news.ycombinator.com/item?id=44761620]
- **薪资范围 (base + total, gross/年)**:
  - **Stockholm SWE total**: **SEK 642K – SEK 879K+** (≈ €56K – €77K), median SEK 641,941 ≈ €56K [来源 (实际打开过): https://www.levels.fyi/companies/lovable/salaries/software-engineer/locations/greater-stockholm]
  - **Sweden 全国 SWE total**: SEK 649K – SEK 889K+ ≈ €57K – €78K [来源: https://www.levels.fyi/companies/lovable/salaries/software-engineer]
  - **股权**: 早期 startup, RSU/option 池较大但 strike price 未公开; founded 2024 估值飞涨 — option 上行 leverage 高但风险也高
  - **对比**: 远低于 FAANG Stockholm (Amazon Stockholm SWE SEK 648K – 1.71M+), 但符合北欧 startup 行情; Spotify Stockholm L4 ~SEK 850K-1.0M total 更高一档
- **申请窗口**: rolling
- **面试流程差异 vs 实习**: 全职走完整流程 (recruiter + HM + 2-3 tech + work sample + founder); 实习目前几乎没开, intern 只见 ops/PX 岗
- **录取竞争 / 国际生 friendliness**: 极高竞争 (AI codegen 红海, 25 wave 简历海); 但**国际生 friendliness 明确高** — 创始人级别公开 sponsor + 1-year experiment 路径, 在 EU 同类初创里第一档

  - Lovable Careers (实际打开过): https://lovable.dev/careers

## 2. 签证与国际学生政策

**核心结论**: **Yes, sponsor + relocation** — 创始人公开承诺, 在 EU AI startup 里少见

| 维度 | 政策 |
|------|------|
| 是否支持非EU学生 (全职) | **Yes** — HN 帖创始人原话 "We sponsor visas and have very generous relocation packages (even if you just want to come for a year)" [来源 (实际打开过): https://news.ycombinator.com/item?id=44761620] |
| 是否支持非EU学生 (实习) | **Unclear** — 目前 careers 实抓只有 1 个 People Ops Intern, 无 SWE Intern; 没有公开实习 visa 案例, 建议邮件直接问 |
| 是否要求提前持有 work auth | **No** (全职) — 公司明确办理 SE work permit + relocation; relocation 描述"Moving countries is a big deal. We help make it a little less so." [来源: lovable.dev/careers] |
| 已知 sponsorship 案例 | HN 帖 (2025-08) 公开承诺; LinkedIn 上多个 international hire (印度 / 美国 / 法国背景) 加入 Stockholm office, 但缺中国籍直接实证 |
| 1-year experiment 路径 | **独有** — 创始人明示即便只想试 1 年也支持办 visa, 这是 SE work permit (2 年期) 而非 EU Blue Card 路径 |

**对中国留学生的可行路径**:
1. **已在 EU 念书**: 直接申请 Stockholm SWE 岗, work permit 公司全办, relocation lump sum + 协助找房
2. **不在 EU**: 先有强 portfolio (开源 AI agent / LLM tooling / React/Vercel/Bolt clone), 投 Stockholm SWE, 创始人办 SE work permit; 流程约 4-8 周
3. **1 年试水模式**: 主动提"1-year contract"也接受 (创始人 HN 原话), 适合先体验北欧再决定 long-term
4. **走 Internship 路径不可行**: 目前 SWE intern 岗几乎没开, 主推全职

## 3. 面试流程

> **2026-06 retry**: 已找到 Lovable 公开面经数据点 — Glassdoor Lovable Interview page 有评论 + DataFord interview guide 2026 [来源 (实际打开过): https://www.glassdoor.com/Interview/Lovable-Interview-Questions-E1912696.htm + https://dataford.io/interview-guides/lovable/software-engineer]. 流程: 短 application form → exploratory recruiter intro call → technical interview ~30 min. 重 "practical building, troubleshooting, stakeholder interaction" 而非抽象 whiteboard. Levels.fyi Lovable Stockholm SWE median **SEK 641,941** (range SEK 642K-879K) [来源 (实际打开过): https://www.levels.fyi/companies/lovable/salaries/software-engineer/locations/greater-stockholm].

- **总轮数**: ~4-5 轮 (推断: Recruiter → HM → 2-3 tech + work sample → Founder)
- **每轮形式**:
  1. **Recruiter Call** (30 min): role fit, 动机, 时间表
  2. **Hiring Manager** (45-60 min): past projects 深挖, AI agent 经验, 技术栈
  3. **Technical / Live Coding** (60-90 min): full-stack 题 (React + Node) 或 ML agent 系统题
  4. **Work Sample / Take-home** (估约 4-8h): 给 prompt → 写 mini AI agent / web app feature
  5. **Founder Chat** (45 min): culture, 长期愿景
- **题型分布** (估): 系统设计 + LLM agent design (30%) / Live coding full-stack (30%) / Work sample (30%) / BQ (10%); **算法 LeetCode 比例低** (产品/agent 公司更看实际构建力)
- **难度评估**: 推断 medium-hard; 重 product sense + AI agent 工程经验, 不靠"刷题 200 道"
- **OA 是否存在**: 没有传统 OA, 但 take-home work sample 接近 timed exercise

## 7. 踩坑与社区评价

### 流程层面
- **公开面经空白**: 2024 founded + 中文社区无讨论, 申请前期望管理要做好 — 进度可能反复, 反馈速度因人而异
- **In-person Stockholm 硬性要求**: HN 帖明确 "in-person" — 不接受 100% remote (1-year visa 路径也要搬过去)
- **极速增长 + 早期 startup**: chaos 是常态, mentorship 不像大厂结构化

### 文化 / 业务风险
- **AI codegen 赛道红海**: Cursor (主导) / Vercel v0 / Bolt / Replit Agent / GitHub Copilot Workspace 同台竞争, Lovable 差异化在"prompt → 完整 web app"端到端, 但 moat 仍在建; 2026-2027 行业整合潜在风险
- **股权 leverage 高 + 风险高**: 早期 option, strike price 公司估值上行可观, 但 down round / 收购清算可能稀释
- **Stockholm 生活成本中等**: 高于柏林低于伦敦, SEK 642K base 在 Stockholm 算"舒适生活"但非"奢侈"

### 对国际学生友好度
- **政策上极友好**: 创始人 HN 公开承诺 sponsor + 1-year experiment 是 EU 同类初创第一档
- **实操上**: SE work permit 流程 4-8 周, relocation lump sum + 找房协助; 中国籍走 SE work permit 比走 EU Blue Card 简单 (薪资门槛低 + Migrationsverket 流程透明)
- **语言**: 英语工作环境, 瑞典语 0 基础也可入职
