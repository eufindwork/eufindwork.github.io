- **Core trade-off**: Already in NL holding student visa → choosing Voi means **giving up NL zoekjaar (€2,801 reduced HSM)**, exchanging for Sweden certified employer fast track
- **Intern feasibility**: ❌ **Zero** — no formal intern program; thesis worker can use KTH/Chalmers channels but default requires SE work visa
- **FT feasibility**:
  - **R&D senior → medium-high** — Sweden certified employer 2-4 weeks fast, starting salary should cover 90% median; but currently Stockholm 9 reqs all senior, **Junior/Grad not friendly**
  - **BizOps associate → low-medium** — salary may approach 90% median threshold, high risk
- **Estimated friction**:
  - Industry level → high (2024-25 layoff cycle shadow + regulatory uncertainty)
  - Visa level → low (SE certified)
- **UvA advantage invalidated**: this company not in NL, no zoekjaar benefit
- **Advice**:
  - **Not recommended to prioritize** — most unfriendly grad / intern path among 7 companies
  - If user is already senior R&D + wants to do hardware-adjacent mobility → can be last-resort
  - If wanting mobility but stable sponsor + early-career path → **Free Now (Hamburg) or Bolt (Tallinn, not in this tier)** more worth than Voi
