## 2. Visa and International Student Policy

**Core conclusion**: **Yes, sponsor + relocation** — founder's public commitment, rare among EU AI startups

| Dimension | Policy |
|------|------|
| Supports non-EU students (full-time) | **Yes** — HN post founder's original quote "We sponsor visas and have very generous relocation packages (even if you just want to come for a year)" [Source (verified opened): https://news.ycombinator.com/item?id=44761620] |
| Supports non-EU students (internship) | **Unclear** — currently careers live-scrape only has 1 People Ops Intern, no SWE Intern; no public intern visa cases, recommend emailing directly to ask |
| Requires pre-held work auth | **No** (full-time) — company explicitly handles SE work permit + relocation; relocation description "Moving countries is a big deal. We help make it a little less so." [Source: lovable.dev/careers] |
| Known sponsorship cases | HN post (2025-08) public commitment; multiple international hires (Indian / American / French backgrounds) joined Stockholm office on LinkedIn, but lacks direct Chinese-national evidence |
| 1-year experiment path | **Unique** — founder explicitly says even if you only want to try for 1 year they'll sponsor visa, this is SE work permit (2-year term) rather than EU Blue Card path |

**Viable paths for Chinese students**:
1. **Already studying in EU**: Apply directly for Stockholm SWE role, company handles work permit, relocation lump sum + help finding housing
2. **Not in EU**: First build a strong portfolio (open-source AI agent / LLM tooling / React/Vercel/Bolt clone), apply Stockholm SWE, founder handles SE work permit; process about 4-8 weeks
3. **1-year trial mode**: Proactively propose "1-year contract" is also accepted (founder's original HN quote), suitable for first experiencing the Nordics before deciding long-term
4. **Internship path not viable**: SWE intern roles are barely open right now, full-time is the main push

## 3. Interview Process

> **2026-06 retry**: found Lovable public interview data — Glassdoor Lovable Interview page has reviews + DataFord interview guide 2026 [Source (verified opened): https://www.glassdoor.com/Interview/Lovable-Interview-Questions-E1912696.htm + https://dataford.io/interview-guides/lovable/software-engineer]. Process: short application form → exploratory recruiter intro call → technical interview ~30 min. Emphasis on "practical building, troubleshooting, stakeholder interaction" over abstract whiteboard. Levels.fyi Lovable Stockholm SWE median **SEK 641,941** (range SEK 642K-879K) [Source (verified opened): https://www.levels.fyi/companies/lovable/salaries/software-engineer/locations/greater-stockholm].

- **Total rounds**: ~4-5 rounds (inferred: Recruiter → HM → 2-3 tech + work sample → Founder)
- **Each round format**:
  1. **Recruiter Call** (30 min): role fit, motivation, timeline
  2. **Hiring Manager** (45-60 min): deep dive on past projects, AI agent experience, tech stack
  3. **Technical / Live Coding** (60-90 min): full-stack problem (React + Node) or ML agent systems problem
  4. **Work Sample / Take-home** (estimated ~4-8h): given a prompt → build mini AI agent / web app feature
  5. **Founder Chat** (45 min): culture, long-term vision
- **Question type distribution** (estimated): System design + LLM agent design (30%) / Live coding full-stack (30%) / Work sample (30%) / BQ (10%); **algorithm LeetCode ratio low** (product/agent companies value actual building ability more)
- **Difficulty assessment**: Inferred medium-hard; emphasizes product sense + AI agent engineering experience, doesn't rely on "grinding 200 problems"
- **OA existence**: No traditional OA, but take-home work sample is close to timed exercise

## 7. Pitfalls and Community Reviews

### Process aspect
- **Public interview experiences blank**: 2024 founded + no Chinese community discussion, manage expectations before applying — progress may be back and forth, response speed varies by person
- **In-person Stockholm hard requirement**: HN post explicitly states "in-person" — doesn't accept 100% remote (1-year visa path also requires relocating)
- **Extremely fast growth + early-stage startup**: chaos is the norm, mentorship is not as structured as large companies

### Culture / business risks
- **AI codegen track red ocean**: Cursor (dominant) / Vercel v0 / Bolt / Replit Agent / GitHub Copilot Workspace compete on the same stage, Lovable's differentiation is "prompt → complete web app" end-to-end, but the moat is still being built; potential industry consolidation risk 2026-2027
- **High equity leverage + high risk**: Early-stage options, strike price has significant upside if company valuation rises, but down round / acquisition liquidation could dilute
- **Stockholm cost of living medium**: Higher than Berlin, lower than London, SEK 642K base counts as "comfortable living" in Stockholm but not "luxury"

### Friendliness toward international students
- **Policy extremely friendly**: Founder's HN public commitment to sponsor + 1-year experiment is top tier among EU comparable startups
- **In practice**: SE work permit process 4-8 weeks, relocation lump sum + help finding housing; for Chinese nationals SE work permit is simpler than EU Blue Card (lower salary threshold + transparent Migrationsverket process)
- **Language**: English working environment, 0 Swedish background also fine for joining
