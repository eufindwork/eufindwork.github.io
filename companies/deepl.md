## 3. 面试流程

> Glassdoor SWE: 难度 3/5, 60% positive, 平均 20 天 hire 周期 (Cologne); 全公司 47 个面经条目, 平均 hire 周期 20 天

- **总轮数**: ~4-5 轮 (全职 SWE) / 2-3 轮 (Praktikum / Werkstudent)
- **每轮形式** (基于 Glassdoor 2025 Cologne SWE 面经):
  1. **Screening Call** (30 min): recruiter, role + visa + 时间表
  2. **Technical Background** (1 hr): past projects + 技术栈 (Python / React / Backend) 深挖
  3. **Live Coding** (60-90 min):
     - Backend: 数据库设计 + API + 算法 (state management, async, performance)
     - Frontend: React state management (Redux/Zustand) + 全局 state + app architecture
  4. **System Design** (60 min, mid/senior): 设计翻译 service / inference 平台 / 多语言 routing 等
  5. **Culture / Team Fit** (45 min)
- **题型分布**:
  - Backend SWE: Coding (40%) / DB / API design (25%) / System design (20%) / BQ (15%)
  - Frontend SWE: React + state management (40%) / Coding (30%) / Component design (20%) / BQ (10%)
  - ML Engineer: NLP / transformer 实现 (35%) / Python coding (30%) / Domain (translation / MT eval / BLEU) (20%) / Culture (15%)
- **难度评估**: Medium (LC Easy-Medium 主体, Hard 少); 强调 product engineering + 实际工程能力
- **OA 是否存在**: 不存在标准化 OA; live coding 替代

### 反馈速度
- 部分候选人反馈"professional and effective communication and fast feedback"
- 但也有"after applying, more than two weeks 才响应"案例 — 节奏不稳定

## 7. 踩坑与社区评价

### 流程层面
- **反馈速度不稳定**: 部分案例"fast and reactive", 但也有"2+ 周等响应"; 期望管理要做好
- **DE 行政流程**: 入职文件 / Blue Card 申请 / 银行 / Anmeldung 等需要 2-4 周, 别太焦虑
- **Live coding 重 product engineering**: 不要把 DeepL 当 FAANG 刷题型, 重实际工程能力 + 系统理解

### 文化层面 (Glassdoor)
- **正面**: "International team", "Clear mission (语言无障碍)", "Solid product"
- **负面**: 部分 Berlin reviews 提及"middle management process heavy", "slow decision making" (大公司化)
- **整体评分**: ~3.7-4.0 / 5

### 已知"坑"
1. **Stock 在 entry-level 几乎为 0**: Levels.fyi 直读 base = total, RSU $0; 不要被 unicorn 估值想象忽悠
2. **Cologne vs Berlin vs Munich 文化差异**: Cologne 较稳 + ML 重镇, Berlin 国际化年轻, Munich 高薪高物价
3. **NLP / MT niche**: 招聘 prefer NLP 背景, 纯通用 SWE 竞争激烈
4. **2024-2025 增长放缓 + OpenAI/Anthropic 翻译能力压力**: 业务 moat 在缩, 但 enterprise B2B 仍是 DeepL 优势
5. **Werkstudent 仅限德国学生签**: 不要假设有 EU 学生签就能做 DE Werkstudent

### 对国际学生友好度
- **EU 国籍**: 极友好
- **中国籍 master / 新毕业**: 极友好 — 公开 sponsor, 多个案例
- **PhD NLP/MT/TTS 背景**: 顶级友好, Cologne Research Scientist 是 EU NLP 顶级机会
- **新毕业**: 友好, 但 Levels.fyi 显示 grad SWE 数据点少, 谈薪基准弱
