## 2. Visa and International Student Policy

- **Supports non-EU students**: **Yes** for UK / Ireland; **Conditional** for Munich (needs German), Paris (commercial role French preferred)
- **Whether you need to hold work permit beforehand**: **No** — OpenAI holds Skilled Worker license in UK, Ireland goes via CSEP
- **Known sponsorship cases**:
  - Multiple Blind posts confirm OpenAI sponsors H1B + UK Skilled Worker [Source (verified opened): https://www.teamblind.com/post/does-openai-sponsor-h1b-visa-4o3ha6vf]
  - **Intern visa**: UK Tier 5 GAE / Standard Visitor; must confirm visa status before applying
  - Munich engineering JD writes German B2+ (soft requirement, high frequency) — avoid if you don't speak German

## 3. Interview Process

- **Total rounds**: 6-8 rounds, 2 weeks-2 months [Source (verified opened): https://igotanoffer.com/en/advice/openai-interview-process]
- **Per-round format**:
  1. **Recruiter screen** (30-45 min): background + AGI safety motivation
  2. **2 × 60 min technical** (coding + system design, same day)
  3. **Take-home project** (48hr, "build something real", evaluating reliability + code quality + testing) [Source (verified opened): https://www.tryexponent.com/guides/openai-software-engineer-interview]
  4. **Virtual onsite 4-5 rounds**: coding + system design + deep dive + 1-2 behavioral
  5. **Hiring committee + offer**
- **Question distribution**: Coding practical 40% (not LeetCode, systems questions like "time-based KV store / resumable iterator"), System design 25%, Deep dive on project 20%, Behavioral 15%
- **Difficulty assessment**: difficulty 3.2/5, positive 33% (Glassdoor)
- **Whether OA exists**: usually no standalone OA, take-home substitutes (48hr)

## 7. Pitfalls and Community Reviews

- **Munich blocked by German**: Munich engineering JD frequently lists German B2+ — don't apply Munich without German, apply London/Dublin
- **Process long and unpredictable**: 2 weeks to 2 months, recruiter response speed inconsistent; don't bet solely on OpenAI, simultaneously apply Anthropic / DeepMind / Mistral
- **Take-home high intensity**: 48hr project huge time sink, getting ghosted after submission is a common complaint (Glassdoor 33% positive)
- **Few European intern slots**: bulk still SF; London Fall 2026 SWE Intern is one of few public European reqs
- **Residency non-European**: only offered in SF, want Residency path need to prep US visa
