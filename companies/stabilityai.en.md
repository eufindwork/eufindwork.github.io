> **Language**: [中文](stabilityai.md) | English

## 4. Application Requirements and Visa

- **Education**: Research Intern prioritizes PhD enrolled (Generative Models / Computer Vision / NLP); ML Engineering accepts Master's
- **Hard requirements**:
  - **Diffusion model implementation experience** (having trained / fine-tuned Stable Diffusion yourself is a strong plus)
  - PyTorch + Diffusers / CompVis codebase familiarity
  - CUDA / Triton a plus
  - Top conference papers (NeurIPS / ICCV / CVPR / SIGGRAPH) significant plus
- **Visa**: Stability AI Ltd is a UK domestic company, Skilled Worker sponsor licensed; but interns mostly go through Student Visa
- **Salary**: no public data; cautious budget post-rescue, estimated intern monthly salary £3,500-£5,000

## 8. Key Preparation Checklist

### Research / ML Intern Direction
1. **Diffusion Model theory**: DDPM, DDIM, SDE / Score-based, Classifier-Free Guidance
2. **Must-run code**:
   - Use PyTorch / Diffusers to run Stable Diffusion inference
   - LoRA fine-tuning on a personal dataset
   - Implement simple DDPM training loop
3. **Advanced**: Flow Matching, Rectified Flow, Consistency Models
4. **Video / Audio**: Stable Video Diffusion, Stable Audio codebase browsing
5. **System ML**: FlashAttention, xFormers, torch.compile, CUDA optimization

### General Preparation
1. PyTorch internals (autograd, torch.compile, custom op)
2. At least one GitHub public generative model project
3. Read Stability recent blogs / papers (Stable Diffusion 3, SD3.5, Stable Video Diffusion)
