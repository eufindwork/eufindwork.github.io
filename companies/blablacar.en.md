## 3. Interview Process

- **Total rounds**: 4-5 rounds, average 25-30 days, offer usually within 48h [Source (verified opened): https://www.glassdoor.com/Interview/BlaBlaCar-Paris-Interview-Questions-EI_IE840434.0,9_IL.10,15_IM1080.htm]
- **Each round format (Backend)**:
  1. Recruiter screen (30 min)
  2. Hiring manager (deep talk on experience + expectations)
  3. **Case study / take-home** (assesses hard + soft)
  4. **90-min live coding** with 2 SWE
  5. **60-min system design** with SWE
  6. Final values round
- **Frontend new process (2024+)**:
  1. Design case study
  2. Code review
  3. Live coding (replaces prior 7-day take-home) [Source (verified opened): https://medium.com/blablacar/how-we-revamped-our-frontend-interview-process-at-blablacar-dea082399dfa]
- **Question distribution**: Live coding 40% / System design 25% / Case study 20% / Values 15%
- **Difficulty assessment**: Medium. Medium DSA + real-world architecture, not competition-oriented
- **OA exists**: Usually no, take-home / case study replaces it

## 7. Pitfalls & Community Reviews

- Process **fast** (25-30 days) + offer 48h, efficient by EU standards
- Live coding 90 min is the killer — can't just write algo, must discuss trade-offs
- Frontend new process is friendly to those who like long take-homes
- French not mandatory but Paris team culture is somewhat French-style, completely no French = slow onboarding
- International student friendliness: full-time sponsor smooth, French zero-base engineering team also OK
