## Intern Track

- **Role names**:
  - **Data Engineer Intern** [Source (verified opened): https://supercell.com/en/careers/data-engineer-intern/7a4a0a38-18e1-4c89-8bd4-7a0f0fb0dc59/]
  - **Data Analyst Intern**
  - **Analyst Intern** (general business / strategy)
  - Investments Intern, Event/Office Ops Intern (the latter **does not sponsor relocation**, explicitly stated)
- **Duration**: **6-9 months** depending on project
- **Application window + deadline**: **2026-04-26 (deadline)** → 2026-08-24 (start)
- **Salary (stipend gross/mo)**: Levels.fyi summer 2023 reports **$19.38/hr = ~$3,359/mo ≈ €3,100/mo** (intern range)
- **Eligibility (education, local residency)**: enrolled bachelor's/master's (CS / Data / Stats); **default Finland residency**
- **Sponsor policy (intern)**:
  - **EU/ETA candidates**: relocation supported (including Relocation Team + family/pet assistance)
  - **Non-EU candidates**: only "truly exceptional" candidates are sponsored (cases rare)
  - **Event / Office Ops Intern**: **No** relocation, must be local candidate
- **Process**: Application → recruiter → take-home (Data roles) → technical / case → 2-3 onsite rounds
- **Conversion rate**: High — Supercell intern → FT is the core pipeline, many seniors started as interns

## 3. Interview Process

1. Application (CV + cover letter, Supercell really values cover letter)
2. Recruiter screen (30 min, culture fit-heavy)
3. Take-home (required for Data / Eng roles, high complexity)
4. Technical interview (60-90 min)
5. Cell visit / onsite (2-3 rounds + dinner with cell members)
6. Offer (Supercell offer decision is cell-level, doesn't go through centralized committee)

> Multiple sources (Glassdoor / Reddit): Supercell hiring process is "slow but deep", cell culture fit is decisive.

## 8. For UvA Students (NL Student Visa) — Specific Assessment ⭐

- **Core trade-off**: Already on NL student visa → choosing Supercell means **giving up NL zoekjaar (€2,801 reduced HSM)**, switching to Finland Blue Card / specialist permit
- **Intern feasibility**:
  - **Non-EU → low-medium** — Supercell explicitly EU/ETA priority; unless you are "truly exceptional" (ACM/IOI gold/top OSS), don't apply
  - Recommended strategy: if you meet "truly exceptional" signals → strengthen cover letter + apply to Data Engineer Intern (2026 deadline already passed, wait for 2027 cohort)
- **FT feasibility**:
  - **Helsinki Data Engineer / SWE → high** — sponsor explicit, starting salary €80-100K far exceeds Finland Blue Card threshold
  - Difficulty lies in extremely few reqs + cell culture fit
- **Estimated friction**:
  - Intern → high (non-EU default reject)
  - FT → medium (sponsor easy, but cell fit + extremely low admission rate are bottleneck)
- **UvA advantage lost**: this company isn't in NL, no zoekjaar benefit
- **Recommendation**:
  - **If user is ML/Data + top academic background + wants to do gaming → Supercell is the strongest culture + salary but hardest to get in among the 7; worth as stretch target**
  - **If not meeting "truly exceptional" signals → switching to Wolt FT or King Kingternship (Sweden) more realistic**
  - Intern track only worth trying for EU/ETA + top background
