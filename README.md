## 📌 阅读指南

- **信息丰富度** (⭐ = 极少 → ⭐⭐⭐⭐⭐ = 极丰富): 直接反映公开面经/薪资/流程数据的可获取程度, 不等于"这家公司好不好"
- **非 EU 签证**: 是否对国际学生 (中国/印度等非欧盟护照) 提供 intern visa sponsorship 或允许已持 student visa 的人申请
- **面试难度**: 综合考察 LeetCode 题目难度 + 多轮考察深度 + 录取率, 1 颗星 = 简单, 5 颗星 = 极难
- **Stipend 范围**: gross 月薪 (税前), 已转换为对应城市本币; 数据可能来自 Levels.fyi / Glassdoor / TechPays, 见各公司文件
- 凡是单一来源的 stipend / 流程数据均在原文档中标注; 二次核对前**勿用于薪资谈判**

### D. 关键 Insight (2026-10-10)

1. **在 Amsterdam 本地可投的 2027 new grad 主要是量化**: Optiver / IMC / Jump (QR / QT / Systems) / DRW (Associate Trader) / Flow Traders (Graduate Trader), 都在 IND sponsor 名单, zoekjaar → Kennismigrant 可直接衔接. 科技公司 Amsterdam 的工程 entry 岗几乎为零 (Google / Meta / Uber / Databricks AMS 都没有 new grad SWE).

6. **签证门槛 (2026, 已更正)**:
   - NL reduced Kennismigrant (应届硕士 / zoekjaar) = **€3,122/月** (此前全仓库写 €2,801, 已按 IND 官网更正); <30 岁 €4,357; ≥30 岁 €5,942; NL Blue Card €5,942 (reduced €4,754)

```
job_seek/
├── README.md                  ← 你正在看的总览 + 对比表
├── _template.md               ← 单家公司情报模板
└── companies/
    ├── <company>.md           ← 各家公司 8-section 详细情报
```

4. 真实面经 (table)
5. Offer 案例 (table)
6. 申请渠道与建议

8. 所有引用链接
